### 持久化兼容及回退

D13 的可选下一步只进入原选择事件，不创建行动、不授权、不改 Case 全局下一步。旧事件、旧输入规范化及重放摘要保持，未迁移数据库。

独立兼容检查覆盖旧 schema1/4/6 与新7、旧操作重放、事务回滚、准确 HTTP 和消费端三态。旧 reader 对 schema7 明确拒绝且数据库字节保持，**没有自动降级**；未来回退须使用兼容 v7 的读取器，保留新增观察，不能用旧库覆盖新数据。本轮仅操作隔离合成库，未迁移用户设备或真实业务资料。

仍保留一个通用草稿 hook 的已证实限制：若未来在同一个 hook 实例内直接把 owner 从“已结束且脏”的 A 换成开放 B，旧清理可能读取新 readOnly 标志。当前 Case 取舍/反馈的实际消费者按 owner key 重挂载，独立合成探针验证了这些消费者的 keyed 重挂载边界，相应回归通过；不能将其结论外推为任意原位换 owner 均安全，也未把原探针 FAIL 删除。
