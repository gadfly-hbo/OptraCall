## 建议走查

1. 首页“待处理事项”查看原请求，进入扩围事项保存关联取舍，再返回首页。另看访谈观察请求和分开的外部门店等待。
2. 首页写一句话并“整理与查找”。演示候选需手选“职业探索示例”等正确场景；固定会员复购不是正式推荐逻辑。继续后检查既有草稿和独立待带入片段，追加后可折叠回看原文。
3. 直接准备新 Case：人工填写，或使用模拟候选；选已采纳 G/S、已有 Case 的 G/S、新候选，分别体验创建、继续、明确采纳并创建。
4. 在“更多演示分支”体验采纳已保存但 Case 未完成，再从首页准备草稿恢复。放弃草稿时已采纳结果仍保留。
5. Decision Case → Case 总览／全部项目；查看独立、共享和归档项目，进入关联 Case 再返回，核原位置和筛选。
6. Case 内切事项列表／树，查看多个前驱汇入；切项目／成果范围、返回当前工作，检查草稿与手选范围。查看来源版本和历史。

Demo 会话状态仅保存在当前浏览器标签，重置演示会清除模拟数据。正式产品的持久草稿、原生历史、权限、归档准入和真实模型接入以 [spec.md](spec.md) 为准。
