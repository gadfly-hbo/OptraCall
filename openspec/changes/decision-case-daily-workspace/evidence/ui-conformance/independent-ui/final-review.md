## 四原则与保留范围

Host在当前可达路径管owner、权限、版本/CAS、输入保全、导航及原保存；不从观察/完成任务/图边推达标、净贡献或因果。Agent沿原business-role/goal-draft/Case profile自主使用工具，不增加强制分析步骤。官方Pi1.4.0/Interface v3及原Store/Board/目标权威继续复用，没有新Runtime/模型重试循环/待办完成库。必要人的操作集中为明确采纳创建、取舍或一次原观察保存；取消保输入，UNKNOWN先核原操作。g以原真实SPA脚本关闭重复反馈焦点问题，未增加额外确认。

v7迁移、旧operation hash、旧reader拒绝的另非作者backend审查由PM独立发布，本报告不冒称自执行其30项扩展检查。另一非作者保留的 [GENERIC-HOOK-OWNER 复核原件](cross-review/backend-independent/modal-controller/b3/delta-review.json) 与 [原 FAIL 日志](cross-review/backend-independent/modal-controller/b3/generic-owner-risk.log)（[消费者报告及候选转换说明](cross-review/backend-independent/feedback-consumers/review-candidate-e.json)，原件按字节复制，不冒称本人执行）：通用hook同实例未key原地换owner可能旧owner写；当前IssueWork/FeedbackForm按owner/request key重挂路径通过，未证明当前产品可达，原FAIL不擦除。旧reader不能读新v7，回退须保留新增数据，不能旧快照覆盖新观察。

真实模型专业质量、用户明确截图确认、完整设备体验/设备采用、Git/CI分别核定。此报告只证明所列候选、输入、视口、路径和错误注入范围。
