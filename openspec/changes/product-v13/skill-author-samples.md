# 五个专业 Skill 的作者样本

夹具的任务、输入、预期及禁止结果见 [四类场景](skill-selfcheck.json)。以下为作者在已知夹具和候选正文的情况下完成的试答。每行分别保留交付正文及与预期的人工对照。独立模型是否会选择该 Skill、是否比无 Skill 做得好，仍由留出测评判断。

## business-requirement

| 夹具 | 本次交付 | 对照 |
| --- | --- | --- |
| A · 两仓缺货 | 本季度要决定的是，两仓缺货时增配晚班，还是跨仓调拨。先以分仓缺货日志核实缺货发生的订单、仓和时段，再用排班核同一时段的在岗情况。现有资料可以定位缺货集中在哪里。要比较两种处置，还缺晚班追加人时与费用、可调库存和调拨到货时长。验收时应能说明哪类缺货能由各方案避免，以及为此付出的代价。 | 对齐仓、季度、缺货及两种处置；所列缺口会改变决策。未从排班与缺货同期发生推导增班有效。 |
| B · 再投诉 | 本次仅承接 RAP v3 中已定义的二次投诉。按原定义筛出复发个案，用约定的处置时限判断每宗是否及时，并列出超期原因待核的个案。首诉及原 RAP 的其余范围继续保存在 v3。 | 范围从全部投诉收窄，沿已有定义及时限，可以直接交付；保留 v3。 |
| 边界 · 转化 | 这张表能分别读出下单率和签约率。若你在决定是否改善售前分流，验收标准应落在下单环节；若在决定是否调整合同流程，就要看签约环节。这次希望通过“够好”决定哪个环节的行动？先保留两种指标及各自分母，待指明决策后再定标准。 | 对会改变委托的歧义集中澄清一次；未捏造阈值。 |
| 相邻 · 同比 | 已有可比两期时，按指定口径直接报告同比增幅及基期。计算为（本期数减上年同期数）除以上年同期数。合成夹具没有列具体数值，因此此处交计算口径；原任务的实际数字由 Analysis 读取日报后给出。 | 路由至定义清楚的查数任务，保留基期，未凭空给出数值或触发 RAP 梳理。 |

## business-plan

| 夹具 | 本次交付 | 对照 |
| --- | --- | --- |
| A · 退件积压 | 建议先在复核工位试行两周。班长从同班次调一人，在退件集中到达时支援，保留原工位轮换记录。以班次为单位记录到达、完成复核和转出时间，与相同星期、相近到件量的班次比等待时长，同时看原工位是否新形成积压。备选是在现有人力内错开复核时段。若等待未缩短或原工位出现持续积压，退回原排班，改试错峰。 | 给出对象、人力、责任、两周窗口、可比观察及退出；备选沿已有资源。 |
| B · 新服务 | 可做一次志愿者小范围试用。先由待确认的组织者说明试用场景和退出方式，再请志愿者尝试核心流程，记录在哪一步请求帮助、放弃或独立完成；试用结束当日回访原因。访谈只提示了潜在需求。若关键步骤多数无法独立完成，先修流程再招下一批；如果体验顺畅，下一轮再比较复用意愿。试用人选及组织者确认前不作排期承诺。 | 访谈证据对应探索性动作；用可见事件核假设，候选责任与实际承诺分开。 |
| 边界 · 两区推广 | 先选同一地区、同一分母且能取得前后基线的门店，核实改善动作和观察窗口后做局部试行。另一地区先对齐期间、分母和样本覆盖，再判断能否复用。预算尚待批准；当前可交试行设计，全面推广和统一阈值均待补证。 | 明确可独立推进和受阻部分，未用不可比数字作扩张承诺。 |
| 相邻 · 多项共用资料 | 在 Project 的共用约定中列出各任务须沿用的资料准确版本、可读范围和已知限制。由用户确认这一版约定。 | 只处理 Project 约定，没有创建 Task 或经营计划。 |

## business-decision

| 夹具 | 本次交付 | 对照 |
| --- | --- | --- |
| A · 短租或外协 | 对原事项 Q1，先排除超过预算上限或赶不上交付时点的选项。可行时，短租要求自己承担设备停机后的补救；外协能否转移这项风险取决于尚未确认的故障补偿和交付条款。建议先取外协书面条款再作终选，注明等候答复会占用交付准备时间。当前保留两个候选，交责任人取舍。 | 两个约束和一个可改判条件均可追溯；没有签约或授权记录。 |
| B · A 改 B | 同一事项追加一次改判。先前试行的是 A/v1，保留当时选择及观察。责任人本轮明确选 B/v2，理由引用所附原观察；原观察若未提供完整数值，当前不补造效应大小。B/v2 的实施范围和授权仍待回原行动入口确认。 | A、B 版本与原观察均保留，承接明确人的选择，不推定执行许可。 |
| 边界 · 看着不错 | 记录为仍待明确选择。请负责人指出要选的是 A 还是 B、哪一版，以及授权范围是否另有记录。在这之前可以保留两案的已有比较和原话。 | 原话所指不明，未生成选择或行动。 |
| 相邻 · 登记启动 | 将实际开始时间、负责人及偏差交 Do 对原行动回录，保留行动与已选方案的引用。 | 不重复发起备选评审。 |

## business-do

| 夹具 | 本次交付 | 对照 |
| --- | --- | --- |
| A · 甲线首班 | 看板行动 A 的回录稿：甲线白班，班长报告实际试行 3 小时，原定 4 小时，少 1 小时。其他线别和班别没有执行依据。本次先登记有效时段及报告人，偏差原因待班长补充，效果待原观察窗口结束。 | 4 − 3 = 1 小时，授权对象、报告来源和未观察效果写明；未声称已经成功写入看板。 |
| B · 供应延迟 | 原行动未启动。责任人已决定因供应延迟暂缓，尚无对外动作。记录供应到货这一后续观察条件，待事实更新后回原事项决定。 | 正确保留未执行与原因，未将决定当作已执行。 |
| 边界 · 付款中断 | 保留原付款请求编号与金额待核。先查原操作回执或对账凭证。现有信息只能登记 UNKNOWN；未取得明确结果前维持这一状态。 | 识别重复付款的副作用，未补发、猜测余额或声称付款成功。 |
| 相邻 · 增产路线 | 交 Plan 写出两种增产方案，再由 Decision 对照约束和风险。当前没有选定方案和执行授权，执行层无需开展业务动作。 | 没有冒造回录、启动或授权。 |

## business-teach

| 夹具 | 本次交付 | 对照 |
| --- | --- | --- |
| A · 试点无改善 | 甲组 A/v1 的执行达到原约定，观察窗口内同口径指标没有改善。同期另一活动可能影响该指标，目前无法把结果归因于 A。可先比较没有参加同期活动、基线相近的观察组，或在活动结束后补一次同口径观察。把无改善、替代解释和改判条件交回原事项，是否改选由负责人决定。 | 可核的实际、观测、归因和改选分开。无改善没有被改写成恶化或已改选。 |
| B · 等待供应恢复 | 原选择为暂不加急并观察交期。观察期结束时，实际交期恢复，期间没有加急。原判断在这次窗口内可以保留并结轮。若交期再次越过原服务条件，回原事项重新比较等待与干预。 | 有真实观察和清楚的结轮理由；未从“不行动”推断执行失败。 |
| 边界 · 拟下月试行 | 当前只有预计下月试行的记录。先保留原预期；待核实际启动、实施范围及观察结果。此轮状态仍为待反馈。 | 等待真实后续，不把预期作效果或结轮依据。 |
| 相邻 · 录入时间 | 将昨天试行的实际时段交 Do 写到原行动。尚无效果观察，本次对话不产生复盘结论。 | 回录与判断分开，缺观察不填零。 |

作者按夹具的可接受和禁止交付逐行核读，20 项对照符合各自判据。样本是受指导的作者示范，独立测评仍须用保密夹具、按准确版本实测模型选择与业务结果。
