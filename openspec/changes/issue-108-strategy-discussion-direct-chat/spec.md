# #108 重排战略共创对话区，让首次使用者直接开聊

[开发任务 Issue #108](https://github.com/gadfly-hbo/OptraCall/issues/108) · 基线 `8f6bec2e977e783d8075c0425db3c9598c790d37` · 任务分支 `work/antigravity/issue-108-strategy-discussion-direct-chat`

## 1. 背景与目标

在基线 `8f6bec2e977e783d8075c0425db3c9598c790d37` 的「战略选择 → 战略共创」（[`StrategyDiscussionPanel.tsx`](../../../src/host/ui/StrategyDiscussionPanel.tsx#L238-L253)）中，首次进入页面时输入框上方同时平铺了「本次：未设置，仍可工作」「重读原讨论」「复盘、调研与诊断（上期复盘／行业与竞品／SWOT 分析／五力分析）」和「地图模板」下拉框，输入框下方又分列「调整本次背景、模型与资料（按需）」和「参考方法（可选）」两个折叠区。首次使用者需要穿过多个专业术语与配置入口才能找到输入框。

本变更按用户已确认的产品方案重排「战略选择 → 战略共创」对话区：
1. **首次开聊直达输入**：让输入框、`＋ 添加资料` 和 `发送讨论` 优先可见，首屏只留一个默认收起的「提问示例」入口（使用业务语言示例，点击追加到草稿并聚焦，由用户手动发送）。
2. **继续已有讨论清晰可控**：在当前讨论选择器旁放置「刷新讨论记录」与简短说明，支持在正在回复时刷新，保留原请求与未发送草稿，并区分「记录读取成功」与「实时连接恢复」；已绑定的目标、地图版本或连线显示在输入框附近，保留「回到当前版本」。
3. **按需设置集中收起**：输入框下方只保留一个默认收起的「讨论设置（选填）」，集中收纳「讨论用途（选填）」「地图输出格式（选填）」「指定参考方法（选填）」、本次模型与资料范围；已设用途可显示在折叠摘要中，仅调整设置不触发 Agent 或产出。

## 6. 四点产品原则前置检查

| 原则 | 本变更前置核对结论 |
| --- | --- |
| **1. Host 管环境** | Host 负责提供对话输入框、附件选择、讨论记录刷新、实时流重连状态提示以及按需设置（用途、地图格式偏好、参考方法偏好、模型、资料授权范围）的保存与交付；不硬编码分析步骤，不在仅修改设置或点击提问示例时触发模型。 |
| **2. Agent 自主执行** | 用户发送问题后，Pi Agent 在已获准资料范围内自主理解问题、选择或组合分析方法、决定是否及如何整理战略地图候选；`地图输出格式（选填）` 与 `指定参考方法（选填）` 明确作为发送时交给 Agent 的偏好而非强制死板模板。 |
| **3. 优先复用 Pi 已有能力** | 继续锁定并复用官方 `@earendil-works/pi-coding-agent@1.4.0` 与统一会话 Interface v3 的 `strategy-discussion` 通道、已有 `readStrategyDiscussion` + `watchStrategyDiscussion` 读取与流式投影能力，零新增平行状态机或轮询器。 |
| **4. 减少人的操作** | • **最简正常路径**：进入「战略选择 → 战略共创」→ 直接在可见输入框输入问题（或点一下「提问示例」追加）→ 点击 `发送讨论`。相对基线消除了首屏的术语干扰与多余表单。<br>• **按需渐进披露**：讨论用途、地图输出格式、参考方法、模型与资料范围全部默认收起于单一「讨论设置（选填）」，不阻塞开聊。<br>• **反例核对**：① 点击「提问示例」不自动发送，防止误触消耗模型；② 展开或修改「讨论设置（选填）」中的用途／格式／方法不自动触发 Agent；③ 点击「刷新讨论记录」只读拉取记录并重连 SSE，不重发原消息、不覆盖用户正在输入的未发送草稿。 |

  3. **刷新状态区分（成功／实时断连／读取失败）**：一键模拟并对照：① 记录读取成功且实时连接恢复（`role="status"`）；② 记录读取成功但实时连接断开（`role="alert"`，最新落盘消息已展示且草稿保留）；③ 记录读取本身失败（`role="alert"`，原画面与草稿保留）。
  4. **按需调整「讨论设置（选填）」**：展开验证「讨论用途（选填）」（设置后同步显示在折叠摘要中）、「地图输出格式（选填）」（自动／条目表／目标与策略树／平衡计分卡）、「指定参考方法（选填）」、本次模型与资料范围；实时计数器验证仅修改设置时 `Agent 请求触发次数 = 0`。
  5. **响应式与主题**：支持宽屏（`1280px`）、窄屏（`390px`）无横向溢出、深色模式（`data-theme="dark"`）、`放大对话` 抽屉，以及与旧版基线（`8f6bec2`）的一键同屏对照。
