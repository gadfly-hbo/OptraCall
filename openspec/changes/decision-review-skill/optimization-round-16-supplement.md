### 一、P2 4.3 个月正例（双路径精确复算）

**原始输入**：累计贡献 28.7 万、月度门槛 6.3 万/月、实际统计期间 4.3 个月。

**路径 A（Python Decimal）**：
```python
from decimal import Decimal as D
m = D('28.7')/D('4.3')
# 月均 = 6.674418604651162790697674419
# 精确比较: 28.7 vs 6.3×4.3 = 27.09 → 28.7 > 27.09 = True → 达标
# 展示值(2位): 6.67 万/月
```

**路径 B（bc）**：
```bash
echo "scale=10; 28.7/4.3" | bc    # → 6.6744186046
echo "scale=10; 6.3*4.3" | bc     # → 27.09
```

**判定（精确比较）**：28.7 ＞ 6.3×4.3（27.09）→ **达标**。展示值 6.67 万/月（单列）。

**恰界精确比较**：边界＝28.7÷6.3＝4.555555555555555555555555556；28.7 vs 6.3×边界＝28.7000 → |28.7−6.3×e|＜0.0001 → **达标**（相等）。

**超界精确比较**：28.7 vs 6.3×4.6＝28.98 → 28.7＜28.98 → **未达标**。

**结论**：整数分档（≤4/≥5）会把 4.3 个月（达标）误判为未达标。互补条件「≤4.5556 达标」「＞4.5556 未达标」覆盖完整。
