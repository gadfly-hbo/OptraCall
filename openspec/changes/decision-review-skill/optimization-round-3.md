## 修改文件与段落

**SKILL.md**
1. §三「回本类测算的指标链」升级为「**（分方案层级）**」：试点与全国铺开各自列出自己的投入／月增量贡献额门槛／月新增销售额门槛；试点门槛只用试点投入与试点回收期计算，**试点投入或回收期未知→试点门槛保持未知**；验证指标只与**同一方案、同一门店范围、同一周期、同一单位**的门槛比较，不跨层级；**单位纪律**——金额用元或元/月、百分比用"销售额增幅"等比率口径，不写「增量销售额 ≥ X%」（应为「销售额增幅 ≥ X%」或「新增销售额 ≥ X 元」）。
2. §三「来源分级」追加：**一组前后对比不等于一个样本点**——原材料只说"一组前后对比"时样本范围、门店数量、同店关系全部保持未知，不写成单店/少数门店/N=1；建议用同店/同期对照验证时标为**拟议设计（待执行）**，与原材料事实分开。
3. §四.3：例外清单加入"**用现有设备**"；两项齐备后"**提交决策人审议**"，**获得决策人明确批准后才可启动**；**每段可单独转发的摘要、汇报话术与备选方案都要自带当前审批状态**（待批／已提交审议／已批准），单独读任何一段不能误以为已获批或已启动。
4. §六 自检三问同步扩充（分层门槛与单位错位／现有设备非例外、只提交审议、单独读误判／一组对比与拟议设计）。

**templates/decision-brief.md**
1. 「方案后果」：追加**试点与全国铺开分列**（各写一行三指标、各带单位；试点投入或回收期未知→试点门槛整行未知；同方案/同门店范围/同周期/同单位比较；单位纪律含「增量销售额 ≥ X%」修正形态）。
2. 「验证与调整」：试点与全国的验证指标各自对齐**本层级**门槛，不跨层级比较。
3. 「取舍与建议」：分级更新（用现有设备入非例外；提交**决策人**审议；获决策人明确批准后才可启动；每段可单独转发内容自带审批状态）。
4. 轻量版建议：附当前审批状态（待批/已提交审议/已批准），缺一前提只给补证与待批方案。
5. 「事实与证据」：一组前后对比条款（样本范围/门店数量/同店关系未知；一组对比≠一个样本点）。
6. 「假设与未知」：拟议设计（待执行）与原材料事实分开成句，读者能分清"材料说了什么"与"我们打算怎么验证"。
