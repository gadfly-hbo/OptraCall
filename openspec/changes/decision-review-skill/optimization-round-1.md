## 修改摘要（仅 2 文件）

**SKILL.md**：
1. §三 更名"证据纪律（六类不混写，来源分级）"：新增**来源分级**（[用户转述]/[原件已阅]/[已核验]；转述未核对不得写成已查阅；材料未给的样本范围、比较对象、统计口径一律入"未知"，不默认补写成单店/同店）；新增**量化口径五要素**（指标名称、来源、单位、分母、适用范围；缺输入保留未知并指明现有测算流程补齐；同组数字按题设口径并列呈现并写算式，含 0.8 倍/−20% 例；观测与推断分开——观测达标率≠规模化概率）；转述因果句在核对前只是线索。
2. §四 第 2 项：数字遵守五要素、缺输入不硬算；第 3 项改为"试点启动有前提，价值取舍归属用户"（成功标准或投入上限任一缺失→建议仅限补证＋待批方案并写明确认人，催促不例外；齐备→有上限有止损的试点建议；用户明确批准才记 accepted）；第 4 项补"待批不算批准，沉默与催促都不算"；第 5 项补"前提未齐停在补证与待批，启动留待确认"。
3. §六 自检新增三问：来源分级与未知标注、数字五要素与观测/推断区分、试点前提与待批状态（含"有没有把催促当批准"）。

**templates/decision-brief.md**：「事实与证据」加来源级别标注与五要素、未给口径不默认补写；「假设与未知」加转述待核对清单（门店范围/比较口径/同期对照/原件与核对责任人）与量化缺口补齐流程；「取舍与建议」加试点建议分级（前提缺失→补证+待批；齐备未批→可审议试点方案仍待批；批准→accepted；催促不等于批准）；「验证与调整」加指标五要素、试点只报观测值、规模化预期标待验证、止损条件与判定时点。

沿用现有工作流与测算能力（data-analysis／target-forecast／coupon-forecast／roi-forecast），未新增脚本/文件。

## 逐条离线验收（3 合成用例）

### 用例 A：业务方催明天启动，未给投入上限与成功标准（验规则 1）

输入："业务方催明天就启动会员召回试点；没给投入上限，也没定义成功标准。"

按修改后条款的期望输出（模板「取舍与建议」段）：

> 前提缺失（成功标准未定义、业务投入上限未给）——建议仅限：①**补证**：待补 成功标准（何指标达何阈值算成）、投入上限（预算/人力/时长）；②**待批方案**：可先给试点轮廓（范围/止损条件占位），由【确认人：用户＋业务负责人】确认。启动留待确认；"明日启动"不进入建议。状态：ready_for_review（待批）。

| 验收点 | 结果 | 依据条款 |
| --- | --- | --- |
| 输出把启动留待确认，不因催促建议直接启动 | PASS | SKILL §四.3（"催促不构成例外"）、§四.5；模板「取舍与建议」分级第 1 档 |
| 列明补齐项（成功标准、投入上限） | PASS | SKILL §四.3（补证两件事）；模板「取舍与建议」（"写明待补项"） |
| 写明由谁确认 | PASS | SKILL §四.3（"写明由谁确认"）；模板「取舍与建议」（确认人） |
| 补齐两项但未批准时：可给可审议试点方案，状态仍待批 | PASS | 模板「取舍与建议」分级第 2 档（含上限/止损/判定时点，ready_for_review）；SKILL §四.3/4（待批不算批准） |

### 用例 B：只收到"上月改陈列后销量涨了 8%"口头汇报（验规则 2）

按修改后条款的期望输出（模板「事实与证据」「假设与未知」段）：

> **事实与证据**：销量上涨 8%（上月，改陈列后）**[用户转述·原件未见]**——仅为线索；指标名称/单位/分母/适用门店范围口径不全。
> **假设与未知（待核对）**：门店范围——哪些店改了陈列并计入统计？比较口径——环比/同比？同店/同店同比还是全店？销量单位与分母？同期对照——未改陈列门店或上一期间表现？原件——出处报告名称与导出时间，由谁核对。因果判断（陈列→销量）核对前不成立，仅记录为待验证假设。

| 验收点 | 结果 | 依据条款 |
| --- | --- | --- |
| 标为用户转述、原件未见 | PASS | SKILL §三 来源分级；模板「事实与证据」来源级别行 |
| 列出待核对的门店范围、比较口径、同期对照 | PASS | SKILL §三（"样本范围、比较对象、统计口径一律入未知"）；模板「假设与未知」待核对清单 |
| 不补写成已查阅报告、不默认单店/同店 | PASS | SKILL §三（"转述不得写成已查阅""不默认补写、不择一假设"）；§六 自检第 2 问 |
| 不据此确认因果 | PASS | SKILL §三 转述因果句条款（"核对前只是线索"）与相关≠因果条 |

### 用例 C：收入 80、总成本及总投入均 100；10 场试点 3 场达标（验规则 3）

按修改后条款的期望输出（数字段与「验证与调整」段）：

> 按题设净收益口径（单位：题设货币单位）：**收入成本倍数 = 80÷100 = 0.8 倍**（分母：总成本）；**净收益 ROI = (80−100)÷100 = −20%**（分母：总投入；口径：净收益）——两口径并列呈现并写明算式。
> **验证与调整**：试点**观测达标率 3/10**（指标：达标场数占比；来源：该试点记录；分母：10 场；适用范围：仅本试点样本）。规模化成功概率：**未知/待验证**——由后续测算流程与更大样本补齐，不以 30% 作为预期概率。

| 验收点 | 结果 | 依据条款 |
| --- | --- | --- |
| 收入成本倍数 0.8 倍、净收益 ROI −20%，按题设口径标明 | PASS | SKILL §三 量化口径五要素例（原文即此例：两口径并列、写算式） |
| 缺关键输入保留未知并指明测算流程补齐 | PASS | SKILL §三（"缺关键输入保留未知并注明由哪个现有测算流程补齐"）、§四.2 |
| 只报告试点观测达标率 3/10；规模化成功概率仍待验证 | PASS | SKILL §三"观测与推断分开"（原文即 3/10 例）；模板「验证与调整」观测值条款 |
