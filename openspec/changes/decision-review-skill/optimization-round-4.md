# decision-review 定点修改 · 第 4 轮（个案收敛为跨场景通用规则）与独立出题离线验收

日期：2026-11-08 · 触发：用户第 4 轮指令——把本轮发现的问题收敛为**可跨业务场景使用的规则**；v4 的业务场景、数字和措辞不进入规则或验收用例；首行状态沿用现有契约只做回归核对；离线验收用**改写时未见的独立场景**，先冻结修改稿，再由**未参与改写的审阅者独立出题并确定预期**。不重跑测评、不调用真实 Provider；测评器 v0.3.3、v4 题集、冻结快照、历史记录与原判定全部保留。本轮仅改 2 文件：`SKILL.md`、`templates/decision-brief.md`（examples/references 未动）。

## 修改位置

**SKILL.md**
1. §三"量化口径五要素"：删除原内嵌的个案数字示例（收入/成本/投入组与 ROI 算例、观测达标率具体分数），规则保留为通用表述。
2. §三 新增"**比较先对齐**"：观测值与门槛比较前确认同方案、同对象范围、同期间、同指标与单位；需汇总或换算时写明换算依据并复用现有测算能力（脚本复算）；缺任一关键输入保留未知、**暂不判定是否达标**；各方案只用自己门槛。
3. §三"回本指标链"：改"分方案层级"为**各推广层级**通用表述（本层级投入或回收期未知→本层级门槛未知；按"比较先对齐"比较，不跨层级）；单位纪律改为"金额指标不配百分比阈值、比率指标不配金额阈值"（去除个案措辞）。
4. §三"来源分级"：未知清单改通用（样本数量、覆盖范围、比较对象、统计口径）；新增"**计数不等于样本量**"（记录条数、汇总组数或对比次数不能直接推成样本数）与"**拟议验证单独标明**"（与转述、已阅原件、已核验事实、假设分别表述）；删除"一组前后对比"个案措辞与门店类举例。
5. §四.3：升级为"**启动条件三要素：成功指标及阈值、投入上限、决策人批准**"；施压例外清单通用化（催促、用现有设备、成本低、可逆、时间紧迫）；**方案名称、编号与审批状态与正文一致**（不得出现正文没有的方案变体或编号）。
6. §六 自检三问同步通用化（对齐/换算/暂不判定；计数→样本量；三要素与名称编号一致）。

**templates/decision-brief.md**
1. 「方案后果」：新增"比较先对齐"段；"试点与全国铺开分列"改"**各推广层级分列**"（本层级门槛整行未知、不跨层级）；单位纪律通用化。
2. 「验证与调整」：各推广层级对齐本层级门槛（同方案/同对象范围/同期间/同单位）；换算依据缺失或口径未对齐**暂不判定达标**；观测值示例改通用占位（X/Y）。
3. 「取舍与建议」："启动条件分级"（成功指标及阈值措辞）＋可单独转发段自带审批状态＋**方案名称与编号与正文一致**。
4. 轻量版建议：附审批状态与方案名称编号。
5. 「事实与证据」：五类标注（**转述／已阅原件／已核验事实／假设／拟议验证**）；"计数不等于样本量"通用条款；去除门店类举例。
6. 「假设与未知」：拟议验证设计与四类既有证据分开表述。

## 实际核对结果（按验证方式分类）

- **静态检查**（冻结稿文本，机械）：首行契约回归 4/4 PASS（模板两块＋两示例首行为纯状态行）；v4 残留清零 PASS（15 类个案标记在两文件中 0 处，含个案数字组、门店类措辞、"一组前后对比"等）；通用规则条款存在性 11/11 PASS。
- **机械核验**（独立用例的确定性部分，脚本）：16/16 PASS——A1 算术 663000÷150000＝4.42 元/单；A2 算术 840000÷10＝84,000 元/月；B1 三段状态/无弱化语/无越权启动建议；B2 三段待批+编号一致+无 accepted；C1 转述与未知贯穿、次数未推成样本数、无代填样本；C2 口径随引、拟议设计分离、未写成预期概率。
- **人工走查**（按冻结稿条款推导期望输出骨架）：6/6 用例的期望输出骨架均可由冻结稿条款直接推出，无一处需要冻结稿之外的补充规则；出题与走查相互独立（出题者未参与改写、未见历史用例）。
- **实际离线执行**（真实 Agent 跑用例）：**未执行**——本轮不调用真实 Provider；无可用离线 Agent 执行路径。
