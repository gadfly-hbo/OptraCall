# 前端工具链移除 picomatch

## 实现与复用

原链为 Vite → picomatch，同时 Vite → tinyglobby／fdir → picomatch。生产清单保持原 SDK 和运行依赖；开发构建改用官方 esbuild 0.28.2，原测试直接使用的 Rolldown 1.2.15 由传递依赖改为显式开发依赖。保留包的版本、下载来源及完整性逐项一致。依赖锁回归用例检查顶层、嵌套及别名安装位置，现行 GitHub 工作流继续执行完整依赖审计。

构建继续签章，正式 Host 继续校验并提供静态资源。开发 JS／TSX 整页刷新，单独替换 CSS 时保留页面 DOM。前端预览使用同一签章读取逻辑。17 个 UI 测试文件沿用实际 React 组件和既有断言，三个浏览器环境改用新 CLI。两个冻结 Demo 直接回放原有经摘要确认的静态输出，原源码和历史记录保留。
