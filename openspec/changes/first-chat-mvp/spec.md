## 第 1 项：目录与职责

| 目录 | 职责 / 原因 |
| --- | --- |
| `src/host/` | 产品启动、装配、环境与运行侧接缝；载体未定，暂不拆 server/main/renderer |
| `src/host/ui/` | 对话、消息与 LLM 配置等界面归属，不预设框架 |
| `src/agent/` | 全产品唯一 Pi SDK 接入的代码归属，不复制 SDK 分析循环 |
| `extensions/analysis-assets/` | 分析资产可以是代码或声明性材料，按产品分类放在根 extensions 下 |
| `extensions/connectors/` | 连接器归属；按后续任务接入，不自建 Agent Runtime |
| `extensions/business-plugins/` | 业务插件归属；共用产品统一 Agent 入口 |
| `tests/` | 永久测试入口，产生实际测试后再细分 |
| `openspec/changes/first-chat-mvp/` | 本批次薄规格和结果，关联四项授权与验收 |
| `docs/` | 沿用长期产品和工程文档，本项不新增预设子目录 |
| `.local/` | 沿用被忽略的本地持久证据位置，不进入公开交付 |

单仓、单包起步；目录不等于独立包、插件市场或已实现能力。Host UI 经 Host 运行入口使用统一 Agent 接入；Extension 共用产品统一入口。具体 Interface 在第 2 项方案中讨论，实施按相应项授权进行。
