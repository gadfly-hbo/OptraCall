## 试走路径

1. 从项目地图进入「Q3 会员分层与流失归因分析」，打开「查看报告与依据」，进入关联 Case 后分别试「打开原任务」和「按此 Case 继续」。
2. 从「战略选择 → 战略发布 → 带入目标管理」勾选目标、选择归属范围，再核对来源、实际回执和候选状态。
3. 在桌面和窄屏切换设置、报告浮层及 Studio 体系工作台。检查焦点、草稿、用途和期间是否完整可见。

[打开 v0.4 可点击原型](demo.html)。原型和业务记录均为虚构样例，所有操作只发生在演示内存。产品实现时继续沿用现有控制器、Host 和 Pi 会话。正式开发依据用户确认的版本发单。
