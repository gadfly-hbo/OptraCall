## 范围与做法

#95 限定在项目分析的回复正文和对应操作行，复用 #82 的 Marked 和中文强调规则，把结构展示在 Host 前端。Agent 决定回复内容，现有实时投影、原生历史和操作回调继续处理数据。共享组件变更须回归已交付的战略讨论用法。

#96 统一顶部开关与文件栏挂载所用的可见条件。结论复核仅在有实际任务归属时参与文件栏切换。项目级文件 API、文件栏及现有上传校验继续负责文件读写。建项目、上传和建任务相互独立，上传流程保持现有的免模型调用行为。

允许修改上述 Host UI、必要的共享 Markdown 展示与样式、针对性回归和本记录。沿用现有 SDK、URL 边界、项目文件布局和存储契约。

## 复现与 UI Demo

在与 `main` 同树的隔离产品中，使用真实 Host、浏览器和一次合成模型回复复现 #95。已保存回复直接显示标题和表格源码，两组操作按钮的间距均为 0 px。#96 通过浏览器正常创建零任务项目复现。面板未挂载，顶部显示 `aria-expanded=true`，点击后状态及页面都没有变化。

[分析回复 Demo](http://127.0.0.1:4222/?issue=95)支持原效果对照、实时回复重放和深浅主题。[项目文件栏 Demo](http://127.0.0.1:4222/?issue=96)支持开关、选择上述两个目录、模拟上传和创建首个任务。示例数据只存在于演示浏览器，复现与 Demo 点验结果已留存。用户明确回复「两项都通过，按此实现」。原规格与 Demo 文件清单的 SHA-256 为 `8b9aaea125f0e8571702c9b0924e1147d8b135c720b2e54317b89c3a4c4f2ed9`。
