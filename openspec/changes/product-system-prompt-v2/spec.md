# OptraCall 产品内置系统提示词 v2

用户确认采用会话中已审阅的 v2 完整正文。遵循[工程规范 v1.10 的 IN01–IN07](../../../docs/engineering-workflow.md#统一会话接入规范当前interface-v3兼容v1v2业务子集)。范围为 Interface v3 的 `project-tasks` 域，owner 绑定真实项目及其任务，由 [Host 注册](../../../src/host/server.ts#L185)。普通和受管普通项目主任务共用产品正文，沿原 `appendSystemPrompt` 接入官方 Pi 1.4.0。专用会话和受管准入沿各自既有规则，委派角色继续由原接缝附加到父会话指令。

- PP01 首次任务发出的 Provider 请求包含一份完整 v2，目录变量取当前任务。沿用 Pi 默认开头及其既有自定义覆盖规则。原有工具声明、实际可用范围和按会话提供的上下文继续由原入口管理。
- PP02 打开本产品现有 Pi 1.4.0 格式的原生会话时保留路径、身份、旧字节和历史，打开本身不发模型请求。显式续聊的实际请求使用当前 v2 和该会话适用的工具声明，旧任务不因打开或恢复获得受管资格。
- PP03 Host 提供角色、资源和环境边界。Agent 自主选择方法、工具、核验及修正方式，在影响结果的未决事项或新增授权处才请用户决定。新用户沿原入口使用，无需新增设置。

修改范围为项目提示词正文、既有注入点、请求级测试和本变更记录。现有共享证据标准涉及固定材料作者修订等专用消费者，作为原有补充保留。SDK、公开接口、权限、会话存储和界面沿现有实现，UI Demo 不适用。以隔离本地模拟 Provider 验证实际 Host／Pi 请求，完成本地回归和非作者复核。真实模型回答质量和运行采用分别验收。
