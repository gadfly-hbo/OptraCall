# v0.3 Demo体验说明

打开 [ui-demo.html](ui-demo.html)，保存为HTML后用浏览器打开；全部为合成静态演示，不连接账号、模型、GitHub或MCP。旧v0.2位于0ff6030，本版独立v3存储不覆盖旧演示。

1. 从首页继续→Decision Case项目与任务→原Task；也可从全部项目进入。原事项/页签/手选范围/草稿/焦点返回保持。
2. 点“在OptraCall内完成”：原Task继续，已有草稿保留，不发布Issue、不触发外部执行者或开放资产。可把演示场景切到未配置，再体验内部路径，确认外部设置不阻断内部工作。
3. 点“通过GitHub外派”：默认通用Agent接单。确认仓库/允许执行者/资产/资源后自动演示发布、认证领取、MCP查读、回交/保全、原Task核验。默认WorkBuddy无配置、零触发；其选项未验证不可用。可选“等待通用Agent领取”场景观察未领取前不读资产、不调用WorkBuddy。
4. 可选适配：设置页先模拟API和Connector单项，仍不能启用；再“模拟该配置联合测试通过”，返回授权界面主动选WorkBuddy。仅切换合成已验证配置以体验远程触发，绝非完成实号验证。清除WorkBuddy后纯GitHub仍可使用。
5. 核对通用/WorkBuddy两种授权快照和额度分开；缩小资产、取消、发布UNKNOWN、重复领取、补充v1.1、缺件/仅链接、busy/暂停/恢复/迟到等沿原工作核验。外派后改走内部先核取消/在途，不能静默重派。
6. 回Case查看原待回应/项目等待/轮次/目标/成果不被外部接受更新。候选仍待原发布流程，不自动成为正式资产。

按1440/1024/390亮暗、Tab/Escape与返回焦点点验；事件切换是演示控制，不是日常产品步骤。原型重开只保留已知合成状态，没有持久后台/真实字节保存；恢复工程仍待实现。本轮采用内部HTTP验证，file协议实跑尝试被环境管理员策略阻断（ERR_BLOCKED_BY_ADMINISTRATOR），按BLOCKED记录，不把localhost当用户托管入口。

后续领取者须亲自浏览器渲染/操作本次确认版Demo、查看画面/截图、读DOM/CSS并建立生产映射；真实产品截图与用户确认是未来开PR前的独立门禁，不能由本演示替代。
