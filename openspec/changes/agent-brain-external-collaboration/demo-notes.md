# 外部协作静态原型说明

本文件仅配套 `ui-demo.html` 的审核与点验，不是正式 UI 实施或真实协作可用证明。

- 入口：离线打开 `ui-demo.html`。默认从项目地图进入原分析任务；Task、Case、报告、草稿可来回阅读，浏览不会创建 Task。
- 正常路径：进入分析任务 → 查看外派建议 → 在同一个抽屉确认目标、工作范围、指定执行者、私有仓库与可缩小的只读资产权限 → “允许在此范围自主推进”。随后原型自动演示工单发布、WorkBuddy 本机助手 API 触发、Host 唯一有效领取、MCP 读取/续租/交付、Agent 核验/接受及沿原保存工具形成成果。没有每次必须由用户点击的“接受成果”闸门。
- 演示控制：顶部切换正常、未完成接入、需补充、必要业务取舍、发布 UNKNOWN、重复领取、身份变化、离线、到期、回传失败、模型忙与迟到回传。切换会重置这次合成场景；这些控制不是产品正常必做步骤。
- 首次接入：在“未完成接入”场景检查 API 授权/在线、MCP Connector 授权，再模拟完整联通测试。单项通过不能显示可自主执行。采用通用协议与 WorkBuddy 本机助手官方 API，云任务不做；API 与 MCP 联用仍待实号验证。
- 权威与来源：Host 原子工作台账承载有效领取、交付和验收；GitHub Issue/评论是通信和证据。同一远端 MCP 将资产只读与工作领取/续租/交付分组授权。外部附件保留外部来源，Agent 接受后沿原保存工具形成新增任务成果；原报告与 UNKNOWN 保持。
- 补充：仍属同一 work，原 Issue 追加；新 revision 获得新的单一有效领取，旧 delivery 和未通过理由可查看，原授权不扩大。
- 暂停与取消：“暂停本 Task 续接”仅暂停本地自动处理，外部工作及原授权保持；“取消外派”撤回后续访问并请求对方停止，对方是否停止和已有副作用保留待核。迟到材料隔离保留，不恢复权限或自动接受。
- 资产：可查看四类准确版本、出处、范围与实际读取记录。高级演示控制可模拟跨任务、错版本、已撤回、离线和过期；拒绝保留原文、报告与历史引用，不静默取最新版。
- 接收后的沉淀仅可“提交资产候选”，候选待既有流程核定与发布，不直接发布正式资产。

原型无外部依赖、外部图片、字体或网络调用，含 `connect-src 'none'`；所有企业、数据、地址和回执均为合成资料。状态只尝试写入本页独立 sessionStorage 命名空间，失败时使用内存。重开页面保留已知阶段，不重发外部动作；没有模拟持久后台。可用顶部按钮重置。支持明暗主题、Escape 关闭以及对话框焦点返回。

点验脚本、截图、原始失败和最终结果位于未纳入产品源码的 `.local/agent-brain-external-ui/`。当前环境的 Chromium 管理策略阻止 `file://` 导航，未修改全局策略；因此本环境对 `file://` 启动保留未验证，另以实际本机 HTTP 加载文件及无网络上下文完成交互检查。内部 HTTP 地址仅供此工作环境测试，不作为用户可访问链接。
