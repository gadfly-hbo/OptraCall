# v0.3 原型边界与检查

本版对应用户“内部可完成、GitHub为基础、WorkBuddy可选且真实联调后启用”的决定。当前只是待整包确认的单文件合成原型；没有Issue领取、产品代码/SDK修改或真实账号调用。

默认WorkBuddy未配置/未验证，核心GitHub/MCP/通用执行者为合成已配置状态。未配置场景将全部外派条件清空，但内部入口仍可用。WorkBuddy“模拟联合测试通过”按钮只展示未来真实已验证配置的UI，不是实号回执，不证明MacBook可承接。实际产品必须证明API触发会话使用相同获准MCP完成领取/查读/交付及原Task核验后才启用。

原型用v3独立sessionStorage，保持旧v1/v2字节；存储失败使用内存。重开只有已知状态，没有持久后台，不重演外部操作。所有文件/摘要/身份/Issue均合成；不下载真实产物，不发网络、不调用模型或变更正式资产。

旧v0.2全部批准/原FAIL/复核在0ff6030及原evidence目录保留；旧241/196等检查不证明本版新路径通过。当前候选摘要、实跑命令、截图与结果以result.md及evidence/v0.3为准；本轮没有产品实现可提供PR前真实产品截图，该门禁属于将来E07，不用Demo冒充。
