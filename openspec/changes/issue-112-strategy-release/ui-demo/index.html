      确认正式发布战略地图

      正式发布只冻结这次核对过的地图准确版本；不会创建目标、采用目标、启动 Case 或项目。后续编辑会生成新的候选版本。

      撤销这次发布？

      撤销后，这个版本不能再被带入目标管理；地图版本、发布记录、已保存目标候选和历史引用都保留。

      如需恢复承接，需要重新确认并发布同一准确版本，生成新的发布记录。
