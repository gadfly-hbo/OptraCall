# db-link UI 与完整使用流程

v0.1 · 设计评审候选 · 配套[规格](spec.md)、[交互状态](interaction-states.md)和[可点击 Demo](../../../docs/prototypes/db-link-ui-demo.html)。

## 设计依据与呈现

沿当前 OptraCall 产品导航、项目选择、主 Agent／资源并排、数据说明、Studio 与核算的同源入口。根级 DESIGN.md 缺失，本轮使用现有界面证据及 AgentOps 中央 SaaS 标准作为 fallback，不新增全产品设计规范。简体中文，balanced 密度，默认浅色／可切暗色；中性表面，现有紫色强调，仅状态使用语义色。正文约14px，标题20–24px，8px间距体系；细节渐进披露，窄屏纵向排列。

本 Demo 是自包含文件，无网络请求、无真实凭据／模型／数据库／Host、无持久化；刷新恢复合成种子。顶部持续提示“合成资料／交互模拟”，评审场景入口与产品操作分开。原型控件与产品实现可用性分层说明，所有图表／查询／核算成绩为预置合成演示。

## 信息架构

左侧：OptraCall 导航、三个项目（“月度经营复盘”“会员复购诊断”“促销效果评估”）、连接管理入口。主区：当前项目／任务、自然语言问题、Agent 活动、结果／报告。资源面板：连接与授权、数据说明、Studio、核算。连接配置、SQL／来源详情和正式发布预览按需打开原生 dialog，不将管理作为正常提问的必经步骤。

| 面 | 首要目标／主动作 | 关键辅助信息 |
| --- | --- | --- |
| 共享连接 | 添加／配置命名连接 | 可用性、测试身份、被哪些项目引用、类型／组件待定 |
| 项目来源 | 选已有连接并授权本项目 | 数据范围、模型出口、任务继承／排除、有效资格 |
| 主对话 | 直接提问／发送 | 已可用资料、实际模拟活动、取消及异常 |
| 查询结果 | 查看采用的结果及出处 | 完整／截断、SQL、对象、时间、结构／结果身份 |
| 数据说明 | 查看／准备并保存说明 | 粒度／时间／单位、推断／未知、映射与固定输入 |

## 正常路径

1. 进入已授权“月度经营复盘”，直接发送合成问题；无需先打开配置。初始共享连接及此项目授权已就绪，便于体验最简日常路径。
2. 展示 Agent 自主发现、查询及解释的合成活动。活动表达一次演示发生的事实，不是可配置的强制阶段向导。用户可以取消。
3. 结果卡可看行数／完整性，展开来源与SQL；采用结果固定到本项目材料后，直接转到已有数据说明；按需查看报告 R01 与输入 E01 的准确关联。
4. Agent 准备说明，保存成为本项目说明修订。完整字段映射不是分析前置，推断／未知均可保留。
5. 有复用价值的定义可形成 Studio 候选，经预览及有效发布意图正式发布。发布后仍分别进行本项目／其他项目采用与图刷新；回看 R01 继续显示其旧依据。
6. 默认沿现行报告计算复核（父请求内一次，无开关）及结论建议审查（明确开始）。也可在评审中明确选择“数据库独立核算（设计候选）”或其自动衔接：固定足够原始数据与事前语义，先形成独立依据，再揭示作者报告／SQL；意见回原 Agent，自主修改／保留判断，新稿另存后知情复查。计算核算与取数验证边界同时可见。
7. 切到未授权“会员复购诊断”，仍可看到可管理的共享连接，但不能查库或读月度项目结果。一次引用并授权后，本任务继承资格；可采用已发布定义，再自主取本项目自己的数据。项目切换本身不派发模型。

## 关键操作合同

- 连接表单的示意地址／凭据引用只代表配置形态；数据库类型与组件选择保留“后续选型”。模拟测试对应确切配置，改动使旧测试失效；失败保留输入，允许修正后明确重测。
- 项目授权明确“结果等内容会进入所选任务模型”，正常查询无需再次弹窗。任务排除仅收窄，不改变共享连接或其他项目授权。
- 模型数据出口变化、源身份变化和撤权的真实执行留后续验证；原型中应有相应说明与拒绝状态，不能显示虚构的网络隔离证明。
- 连接撤权／任务排除／无权限不自动删除旧材料；当前项目的历史回看沿原资格，其他项目不会获得明细。
- 结果截断可用于探索，采用／核算时显著注明其不足，不能当完整总体。重查产生新结果版本，旧报告不自动刷新。
- 结构变化显示映射待核验，旧说明与报告仍可查；不把连通测试成功当映射已核。
- Studio 的候选、发布预览、正式发布、项目采用、图刷新与实际使用分别展示。候选操作不暗中发布；共享定义不改变数据库授权。
- 核算阶段区分“固定材料”“首次依据”“作者对照”“意见交回”“新稿”“知情复查”。修订由原 Agent 处理，核算意见可有误、可保留分歧，不设置专业 PASS。
- 现行报告计算复核无开关，结论建议审查沿原入口；历史自动设置只读。原型中的“数据库独立核算自动衔接”是本次新增候选，默认为关闭，与当前默认计算复核在同请求择一；当前实现受管禁 MCP、动态源接缝待补，原型上的自动贯通均明确为设计目标模拟。缺失受管能力时显示不可用原因及现有手动路径。
- 归档项目保留查看／追溯，禁新增查询、授权、固定材料、说明保存、Studio写入与新核算；不借项目切换或弹窗绕过。
- 取消未知不会进入结果成功或核算下一段；迟到仅补原查询事实，不能恢复派发；原型的重置是评审控制，不等于真实重试。

## 合成资料与版本示例

合成场景使用非特定数据库的“订单明细／退款事件／门店目录”。一份最小固定源集含东城订单1000、退款事件100和50，西城订单800、退款事件100；东城净额850、西城700、合计1550。订单关联仅表达示例，数据库类型后续确定。全部数值为合成；Demo可展示预置正确稿与明确受控错误稿，不能称真实模型首次质量。

输入 E01、作者稿 R01、修订稿 R02、说明 D01、Studio候选／正式版本及项目采用分别记录。结果集足够复核上述合成金额，不证明SQL完整抽取真实库或业务口径已获确认。若作者只给聚合表，应提示核算范围不足。固定结果hash仅示意身份；真实hash与来源完整性待实施。

## 可访问性与响应式

按钮／链接使用原生语义与可访问名称；表单外置label，错误关联对应字段；状态变化有非颜色文字及live播报。dialog管理进入、焦点限制、Esc关闭与返回触发项；归档／忙碌禁用说明理由。支持键盘、长中文换行、局部表格滚动与减少动效。桌面约1440px主区＋资源并排，窄屏约390–420px纵向，导航与主操作仍可到达。

## 评审边界

本轮核查的是用户路径、状态一致性、四原则、键盘／主题／窄屏和规格对应关系。浏览器／内存检查不能证明权限、真实数据库取消、类型精度、持久化、SDK兼容、来源抽取正确或专业验收。原型未覆盖的真实契约继续按spec保留待验证，不用预置成功状态填补。
