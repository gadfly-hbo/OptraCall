本次复核对象是方案、规格及 Demo 的设计与表达；真实产品尚未实现该增量。结论不替代实际 Host 调用路径、行为回归或真实模型验证。用户截图展示的是两项功能与四个大类并列的导航问题，本轮将层级要求记入同一变更，先更新规格和演示。

## 原则结论

方案的责任划分符合“Host 管环境，Agent 执行分析”。再次复核没有发现应当推翻方案的实质设计，但发现并修正两处容易被实施为流程约束的表达。严格遵循的含义是在已授权的环境和工具范围内，不由 Host 指定分析步骤、方法、字段、公式、结论或修正循环；原有资源权限、会话归属和显式取消仍属于环境责任。

| 核对项 | 应满足的边界 | 本次结论 |
| --- | --- | --- |
| 开始分析 | 不必先创建 Case／RAP、关联资料或填齐表单 | 原方案已有明确要求；继续保留 |
| 资料取得 | 手动附带和 Agent 自主检索是两条可用路径；后者仅依赖真实授权 | 本次重点补清，勾选不作读取白名单 |
| 方法与执行 | 相关资料、场景、skill 是参考；读什么、何时读、怎样算由 Agent 决定 | 无 Host 强制方法表或业务流程匹配 |
| 前提与字段 | Agent 识别前提、解释业务含义和数据对应；不足时自主澄清／条件分析／保留未知 | 不设前提表、字段绑定表的通关条件 |
| 来源冲突 | 原文及范围并列，Agent 解释适用性，用户确认真实业务决定 | 无“SAP／Case／最新文本自动胜出”裁判 |
| 输出与修正 | Agent 按任务解释重要依据并自修正；Host 保存实际结果 | 不因缺少一段模板自动补写、补算或拉第三裁判 |
| Runtime | 复用 Interface v1、原 project／task owner 和公共生命周期 | 不另建 SDK 接入、运行台账或分析循环 |
| 评估 | 固定题目及评分留在工程验证中 | 不向产品运行器注入通关规则 |

现有附属 fixed-draft 出稿资源的无执行工具策略属于此前单独确认的保全范围，不扩大到普通分析。本文也不借“自主性”改变既有资源授权或经营副作用边界。

## 本次发现与处理

### 主动提供不等于读取许可

原 Demo 的本轮候选来自 Case 引用／补充，目录又提示“本轮是否提供仍由任务勾选决定”。在没有真实 Agent 接线的 Demo 中，这不能证明已经发生读取限制；但容易被实施为“先 Case 关联、再勾选，才能读取”。

统一澄清为：**勾选只决定随本轮消息主动附带的材料；Agent 在既有授权范围内可自行检索和读取公共资料，无需先关联 Case 或逐份勾选。**

方案、EB07／EB09、Demo 任务材料和目录提示保持这一含义。实际产品验收增加“无 Case、零主动附带，仍可发现和读取获准公共资料”的反例；当前纯 Demo 不冒称已跑通这一真实能力。

### 示例不暗示固定分析顺序

原 Demo 背景写“先检查期间和数据含义，再自主选择分析路径”。没有对应状态门禁，但措辞暗示了前置步骤。本次改为开放式关注点，由 Agent 自主决定是否及何时检查。

以上是设计表达澄清，保留原用户通过记录；不能把文字修正描述为已修复实际产品 Runtime 限制。

## 分类页入口与推荐理由

| 侧栏分类页 | 页内方块功能 | 决定来源 |
| --- | --- | --- |
| 分析资产 | 企业业务资料 | 已确认方案 |
| 分析资产 | 指标体系 | 本轮推荐，Demo 按此展示 |
| 场景组合 | 保留原规划方块 | 四类之一；规划能力明确标未接入 |
| 连接器 | 保留原规划方块 | 同上 |
| 业务插件 | 需求梳理 | 用户明确指定 |

推荐指标体系归“分析资产”，原因是用户主要在这里管理可复用指标的定义、粒度、业务口径、版本及 SAP 发布物，并供不同项目／Case 选用。模型辅助建模、编辑、审核和发布是维护资产的手段；有这些工具不意味着该入口必须按工具实现归入业务插件。

需求梳理则是围绕本次诉求展开的专门交互工作台，生成并确认 RAP，归“业务插件”更贴合使用方式。RAP 产出可以继续作为任务资料引用；入口归类不改变其原权威。

如果未来出现独立的“指标建模工具”与指标资产库两个用户入口，可分别归业务插件与分析资产。当前不拆出双入口、不重复维护同一对象，也不为侧栏分组迁移 `extensions/business-plugins/metric-factory/` 代码。

## 后续验证要求

本轮修正后检查：桌面／移动侧栏只有四类能力入口、没有功能树；分类页方块能找到正确功能，已有功能与灰色占位在状态和动作上明确区分；企业资料列表可回分类；切换不丢任务草稿。实际产品实施时再核对原功能路由、运行观察、工具和会话配置均未改变。

指标体系和需求梳理正常显示，因为既有产品存在实际入口；Demo 只预览位置。纯规划方块灰显且标“规划中／未接入”，没有正常进入动作。新增企业业务资料单独标“本轮新增·演示”，不借正常颜色冒称真实存储已完成。
