## UI 范围、入口与交互约定

### UI00 演示性质

[独立 UI Demo](../../../docs/prototypes/enterprise-business-context-ui-demo.html)使用现有 OptraCall 侧栏／顶栏与克制的中性、紫色强调。界面持续标识“UI Demo／合成资料／未接入”；内存交互刷新重置，无网络依赖、产品 API、真实文件读取、模型调用或 localStorage／IndexedDB 等持久化。

本次演示要回答：公共资料在哪里维护、怎样引用某一版、本案例外怎样补充、任务怎样按需取得材料及回看来源。沿用既有产品方向，不制作脱离现有工作台的多套审美重设计。

### UI01–UI04 公共资料

- 公共列表提供搜索、分类、可用情况与详情；至少包含启用、存在新版、仅文件登记且正文不可读、来源不详和停用等合成样本。
- 新建／编辑有明确标签和可读错误；保存草稿和显式启用分开，已启用修订保留原文。
- 详情提供正文、来源、适用范围、时间、修订及关联 SAP／RAP／Case 说明；历史可切换。
- SAP／RAP 跳转仅预览其合成原来源，不在公共资料表单编辑其合同；其他规划目录不借本 Demo 冒称实现。

### UI11 四类目录与方块入口

- 能力侧栏只有分析资产、场景组合、连接器、业务插件四个普通入口，点击进入对应方块目录，不展开功能树；原工作区／Case／项目入口保持原职责。
- 分析资产页方块：企业业务资料、指标体系；业务插件页方块：需求梳理。填入适当功能位置，不另留同名／同义的独立侧栏入口。指标体系归资产的理由仍为管理可复用定义与 SAP，生成／编辑／审核是资产维护能力。
- 分类改变不要求迁移 `extensions/business-plugins/metric-factory/` 源码；需求梳理仍走已有插件和统一会话入口，不因归类改变流程或模型行为。
- 分类页复用既有卡片网格、搜索／空结果与详情表达，窄屏降列。场景组合／连接器沿用规划卡片，不冒称能力已接入。
- Demo 默认打开分析资产方块页；企业业务资料方块进入现有维护列表，列表能返回分类。指标体系／需求梳理在 Demo 打开只读原功能入口说明，不克隆真实工作台。
- 桌面和移动侧栏都不出现企业业务资料／指标体系／需求梳理，键盘可进入分类及卡片，切换保留任务草稿。

### UI12 正常功能卡与灰色占位卡

- 指标体系、需求梳理：正常表面／图标与正常入口按钮，文字说明已有功能；Demo 点击说明明确这是入口位置预览，真实工作台仍为既有产品功能。
- 纯规划占位：灰色表面和图标，正文保持可读对比，明确“规划中／未接入”；不显示正常“进入／运行”，最多提供低强调“查看规划”。
- 企业业务资料：标“本轮新增·演示”，可进入维护交互；不标为已接入真实存储或模型。
- 三类在亮／暗／窄屏保持同一语义，颜色、状态文字与动作一致，不用全局 Demo 标识掩盖各卡能力差异。

### UI05–UI06 Case

- 展示“引用的企业资料”和“本案补充”；公共引用可以选择具体修订、取消并查看新版提示。
- 本案补充可编辑短说明、来源、适用范围和确认情况；文件只从预置合成项目列表选择，Demo 不调用操作系统文件选择／读取真实磁盘。
- 公共规则与本案例外可并列查看，提示需要解释的差异，不预选自动覆盖关系。
- 本案补充语义范围与项目文件物理共享范围分别说明；不用补齐本案背景才能进入任务。

### UI07–UI08 项目任务

- 保留原项目任务位置、草稿和对话式入口。材料选择是可展开的辅助区，不是必经向导。
- 明确哪些是可检索资料目录，哪些正文／摘要拟随本轮提供；可清空本次选择并模拟发送普通问题。
- 勾选只控制主动随消息附带；Agent 在已授权目录的自主检索／读取无需先关联 Case 或逐份勾选。本页只能演示该语义，真实 Agent 检索路径仍须后续验证。
- 模拟发送只写入本页内存的用户消息及演示回执，回复明示为预置演示文案；不让用户误认为已连接 Agent。
- 可展示 Agent 自主澄清／保留未知的示意文本，不能出现“Host 已验证前提”或“字段匹配后才允许执行”。

### UI09 来源回读

- 提供一份预置历史报告，显示其引用的旧公共资料修订、SAP 版本、RAP／Case 来源及数据／计算产物示意。
- 启用公共资料新版后，预置报告继续引用旧版；停用来源不清空原引用。
- 显示 Agent 声明采用与用户显式采用的不同含义，不能用资料齐全或报告生成显示正确认证。

### UI10 可访问性和响应式

亮／暗主题使用一致层级；桌面保留侧栏，窄屏可折叠导航且无正文横向溢出。按钮和字段有可访问名称、可见焦点，表单错误关联字段；对话框支持 Escape、初始焦点和关闭返回。对话框、搜索空结果、停用及未取得正文等状态有文字说明，颜色不是唯一信号。

## 结构与兼容合同的原停止线（五项 A 已整体确认）

方案和 Demo 不冻结生产字段。下列事项已由 [structure-decisions.md](structure-decisions.md) 整理为完整合同，用户整体确认五项 A 后实施；列表保留原停止线的来由：

1. 公共资料身份、修订、启用／停用和原文保存方式、实际数据根、受控读写入口及保留范围。
2. Case／任务公共引用的归属和生命周期。当前 Case Artifact 只引用真实项目文件，不能直接伪装为已支持全局资料。
3. 新公共资料提供回执的可选兼容合同。当前 `providedContext` 只有已有 RAP／Case 输入和 worker 补充 SAP 信息，尚不支持任意资料来源。
4. 资料片段、全文与读取时点的表示，旧读取器和未知字段兼容、失败／中断语义。
5. 是否保存选定数据副本及保留期限；未固定副本不能承诺历史完整复算。

本轮不在 RAP／SAP 0.2、Case SQLite、项目 schema 或 JSONL 中临时加字段，不解析备注暗号，不另建事实总库、会话库或固定统计注册表。实现前遵守 IN06 及适用的持久结构确认要求；不得将本 spec 或 Demo 验收当作未定结构已获批准。
