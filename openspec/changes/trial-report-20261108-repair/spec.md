## 实施范围

复用现有 App 导航、CatalogPage、目录数据、筛选、动作和 Case／项目看板使用的 BoardViewSwitch。现状是四分类同时出现在侧栏和目录页，目录只有方块。允许修改 Host 前端导航、目录组件、显示控件及样式，更新受影响的使用说明和浏览器回归。市场沿用应用现有页面内导航和返回约定。项目／任务、Studio 的 URL 语义沿用当前行为。

四原则检查：Host 负责导航、视图和既有能力入口。Agent 自主执行流程、Pi 1.4.0、会话接口及插件访问策略沿用基线。本轮无 SDK 或持久化改造。进入市场直接见首个分类，其他分类需要一次点选；视图切换按需操作，同一窗口内无需在四页重复设置。无新增业务配置或审批。
