## 实施与验证顺序

1. 固定差额、结构／兼容／来源合同，完成确认包只读复核；用户整体确认前不创建产品schema、存储布局或接线。
2. 按已确认范围TDD完成数据登记／必要固定内容和分义说明的最小切片。
3. 复用资料修订与SAP消费接入字段映射，再接同一任务提供／成果声明和原文件栏UI。
4. 以合成制度→原任务追加数据→原生工具计算／新稿→保存重开的正常路径验证，覆盖反例和兼容；模型仅用本机合成Provider，专业质量仍待另行真实验证。
5. 适用完整检查、固定候选非作者复核、结果记录与模块验收；不自动推进后续模块。

这些是工程安排，不是产品Agent的分析步骤。Agent在每个turn内继续自主选择方法／工具／内部迭代；Host只管理材料、权限、技术校验和保存。当前状态见[result](result.md)。
