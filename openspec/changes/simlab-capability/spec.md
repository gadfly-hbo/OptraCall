## 可观察结果

用户在项目的"经营推演"页创建与管理推演草稿：填写参数与任意多个方案变体，随时运行探索性推演（零模型费用），查看逐日账本、多方案对比与自定义扰动分析；把某个草稿状态+推演结果经一次性确认固化为不可变快照（SNAP-xxx，含口径、参数、结果与引擎身份），快照关键指标可被 Case/决策板引用为决策证据。项目任务中的 Agent 通过 5 个推演工具自主创建/修改草稿、运行推演与扰动分析、读取快照证据，并在对话中给出固化建议；固化动作本身由用户在页面完成，Agent 可读回执。探索性推演无任何确认门槛；固化是唯一人工介入点。

## 范围

- 扩展 `extensions/business-plugins/sim-lab/`：引擎（`kernel/`，本仓原生，v1 数学参考原仓 FIFO 日账并重实现）、推演服务与存储（`storage/`，草稿/变体/运行结果/快照，CAS 与幂等按本仓存储模式实现）、Agent 工具定义（`tools/`，5 个正交工具）、API 路由（`api/routes.ts`）、页面 UI（`ui/SimLabPage.tsx`）与类型。
- Host 接线（Codex 归属）：`src/host/server.ts` 挂载路由并分配 `dataRoot/sim-lab/`；`src/host/ui/App.tsx` 增加视图与能力目录入口；`src/agent/project-session.ts` 工具注入接缝（`customTools`/`extensionFactories` 机制，随 `agentOptions` 传入）。
- Agent 工具默认不进入全部任务的默认工具集（启用策略见关键规则 R5）。
- 新增测试：引擎守恒与确定性回归、存储/状态机、工具合同、Host 路由、浏览器点验。

## 不做

- 不做独立进程/端口/CLI、探活协议、跨机部署、公共云 SaaS；不迁移原仓 `src/pi` 层与 vendored 依赖。
- 不设 Agent 固化工具：固化仅页面用户操作（C7）；不设探索前置口径门禁。
- v1 不建模：多仓、账期、退货退款、概率分布、随机仿真、外部数据源；超能力请求结构化拒绝，不输出错误结果。
- 不新建会话域/profile/owner，不建平行 Runtime，不为推演建独立模型配置。
- 不改变既有四个插件行为；不预设快照指标的业务解读（指标为引擎汇总数据）。

## Interface 接入记录（IN01）

- 工程规范 v1.2；Interface v3（`src/host/agent-sessions.ts`）；**复用项目任务域 `project-tasks`，不注册新域**。
- owner/profile：项目任务既有 owner（projectId+taskId）；推演工具作为该域任务的可用能力注入，不改变准入、模型选择、历史与续接策略。
- 修改范围：`src/agent/project-session.ts` 工具注入接缝与 `agentOptions` 传递（Codex 维护）；扩展侧只提供工具定义与纯执行体（Qoder 维护），不 import SDK、不接触会话管理。
- 工具执行体为进程内纯计算（读写插件存储），不经受限执行文件边界；受管执行任务内的可用性在验收 SIM12 专项核对。
- 事件/日志脱敏、凭据与资源权限全部沿用 Host 既有路径；插件不新增对外网络与凭据需求。

## 关键规则

- R1 引擎确定性：同一参数+同一引擎版本结果逐字节一致；引擎带版本标识（`optracall-sim-1` 起步），快照记录引擎版本与输入摘要；引擎变更走受控变更+回归。
- R2 守恒纪律：逐日库存/队列/现金残差校验进入引擎实现与长期测试基线（参考原仓 417 次守恒回归的方法）。
- R3 探索自由：草稿与变体任意修改、任意次运行，结果标注"探索性"，无门禁。
- R4 固化从严：固化=口径+参数+结果一次性冻结，用户页面确认，生成不可变快照；快照不可改写，重新推演产生新快照。
- R5 工具启用：推演工具默认不在普通任务默认工具集；任务级显式开启（入口与交互随 Demo 确认细化），Agent 开启后自主选择调用与否。
- R6 工具报错结构化信封（参数越界、草稿不存在、引擎能力不支持等），供 Agent 自主纠错。
- R7 扰动参数化：扰动维度与幅度由调用方指定（引擎能力范围内校验），不预置固定清单。
- R8 资源边界：窗口 7–90 天；方案变体 ≤8 个/草稿（超出引导拆分草稿）；存储归 `dataRoot/sim-lab/`，项目内隔离。
- R9 页面为用户直接通道，不提供"替任务内 Agent 补跑推演"的路径；任务内推演由 Agent 用工具完成。
- R10 诚实边界：UI 与快照持续可见假设模型声明（非预测/概率/优化/因果），未建模清单可见。
