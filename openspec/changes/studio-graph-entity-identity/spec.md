# Studio 同名实体的图身份修复

## GR01 构图身份

已发布的合成 ontology rev5 声明了两个不同本地键。两者显示文字相同，分别引用各自关系。正常图刷新将它们分到同一个 Statement ID，在 Semantica 构图调用之前失败。原 HTTP 500 与 UNKNOWN 保留。

沿用 Studio 当前结构化投影合同。本地键唯一，关系按本地键引用。文字相同且键不同的声明，派生图应保留独立身份、原关系和准确来源。Host 以本地键区分冲突的派生 ID。单独名称的既有身份生成保持原样。既有 V1/V2 快照按原记录读回，新 V2 快照可保存冲突节点的本地键以核验身份。无需重写或迁移快照。

## 范围和验证

修改限于 Studio 构图、派生 ID、V2 读回校验和对应图契约与回归。Host 管投影和准确来源，Agent 仍负责定义实体及关系的业务含义。继续使用官方 Semantica 0.7.0 原包，沿用现有 Pi 和会话入口。现有操作路径适用，UI Demo 不适用。

验证最小双键同文输入、原关系保留、相关 V1/V2 检查、非作者复核，并在隔离 Host 用同一正式发布资产发起新图刷新和快照回读。原图失败、D3 供给、业务修订与专业再用分别记录。
