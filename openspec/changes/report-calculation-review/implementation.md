## 已实现的接缝

- 普通父消息准入固定 `foreground-report-calculation-v1` 或原旧自动 observation。旧开关开启／旧请求已准入时不开放新复核工具，报告未变化也不补跑。命令和 Studio 建设请求不获新资格。Agent 决定是否为有关键计算的正式报告发起复核。
- 明确指定主报告和相关020资料后，Host 固定原始字节及实际送入的 RAP／框架、企业片段。原件位于 Host 私有快照，附 SHA-256、准确 owner 和 UTF-16 交付范围。个人、Studio、Case 补充及非文本数据无法安全交付时有明确缺口。默认空工具子会话只收到最多20,000字符的固定包。
- `review_report_calculations` 复用前台 Pi 子资源的同一创建、等待、取消与清理权威。新资源只加载复核角色，使用原模型与 thinking，独立内存历史及私有空目录。子意见通过原工具回执交回原主 Agent。非法／缺失选材可自主纠正；真正启动子资源时消耗一次名额。实际启动失败、取消或 UNKNOWN 均不重派。
- 固定材料和意见回交在既有 Host 写入门闩内重核并发送，撤权与回交有明确先后。UNKNOWN 收尾阻断后续父模型派发，保留失败清理供显式重试。没有实际委派时记录 `not_delegated`，不猜测哪份报告应复核。
- 当前／历史意见按原材料权威读取，合法 codemode 仅返回意见正文时仍通过原生工具调用身份定位。原生 branch 切回终态记录之前，也按分支上独立的真实复核记录核对权限。源撤销后隐藏相关意见，续发得到明确拒绝，草稿、上次运行和原生字节保留。
- 既有结果区增加默认收起的实际记录和固定初稿回读。它只表明真实技术状态及所审初稿，修订稿不会继承已复核结论。人的经营采纳仍沿原入口。
