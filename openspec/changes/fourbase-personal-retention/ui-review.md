## 建议审阅路径

1. 在“个人资料”用关键词／别名查找，切换概念、知识、经验、项目数据；打开“含正文关键词”“含未保留草稿”“含归档条目”查看范围变化。
2. 新建人工笔记，填写标题和正文，保存草稿，再核对并明确保留。未保存修改不能直接保留；没有外部来源时如实显示人工记录。
3. 打开已有知识／经验，编辑并保存新草稿。默认查找继续展示旧保留版；明确保留新版后再读历史，核对旧内容及当时来源仍保留。
4. 从“原入口示例”分别阅读资料修订、固定报告／附件、原生回复、反馈修订，再发起人工整理；已有资料可直接保留其精确修订，不改原工作草稿。
5. 查看归档／恢复与原资料另行启用的独立含义。归档不删源，也不撤回另行启用；恢复不用最新草稿。
6. 在独立“演示状态与边界场景”选择UNKNOWN、冲突或来源缺失／损坏，核对旧保留版仍在、同请求显式重试、明确结束与旧失败回执保留。

本期只查找／阅读和回原入口，新增保留内容的第二事项使用留M4。原工作台外壳沿已有紫灰样式；个人查找页、详情／编辑抽屉及保留确认是本次待确认界面。
