邮箱类型、授权码与读取方式

QQ／Foxmail 在官方设置开启 IMAP／SMTP 并生成 16 位授权码；腾讯企业邮箱按安全登录及管理员策略生成客户端专用密码。两者不使用 OAuth，使用 IMAP 993／SMTP 465 SSL。

正式产品在专用凭据输入中接收授权码，先核验邮箱身份与服务。本演示只有固定只读占位值，不接收密码或真实授权码。

读取使用 IMAP PEEK 行为，避免因读取正文自动标记为已读。本机草稿属于普通任务编辑，不代表已存入邮箱草稿箱；远端草稿和特殊文件夹另待实际能力验证。发送回执未知时保留原请求，不自动重发。

默认使用飞书官方托管远端 MCP（mcp.feishu.cn/mcp）和浏览器 OAuth，普通用户无需自行创建 App ID 或密钥。组织管理员须先安装 officialMCPApp 并允许对应账号与工具权限；用户只能访问自己实际获准的资料。

本轮以实际发现且管理员允许的云文档、消息与群会话工具为范围，不承诺多维表格或日历。缺少管理员准备时不能完成连接；不会改用机器人身份或其他账号。
