## 核实事实与取舍

- 现有设置、任务能力和 Interface v3 可承接入口与生命周期。个人账号需新增明确的账号／权限绑定，防止全局账号更换或方案继承扩大任务访问。
- GitHub 官方远端 MCP 提供所需的仓库、Issue、PR 与 Actions 能力。账号使用自己的访问令牌或注册应用，与当前会话所在平台的授权分别建立。
- Gmail 官方新目录已包含发送、回复和转发，上轮可行性答复中的发信范围按新资料修正。官方新交互协议和 Pi 1.4.0 之间存在实际版本差额，选用公开传输接缝的自有适配方案。
- Google 官方 CLI 的动态命令及交互需要额外桥接，当前未发现直接标准 stdio MCP 模式。当前方案以公开传输接缝为主，官方包版本保持本次基线。
