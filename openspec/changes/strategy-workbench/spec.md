## 任务目标与验收清单

| 项 | 正常入口与完成条件 |
| --- | --- |
| W1 战略共创 | 续接原战略讨论，Agent 按需运用上期复盘、行业调研、SWOT 或五力形成具名候选；普通问答保留对话与草稿。 |
| W2 资料 | 独立讨论或已关联项目可添加本机资料。按实际选用、读取、引用及保存追踪 PDF 页、Word 段、Excel 行或文本行，检查同名换版、失读与撤权。 |
| W3 共编 | 选择条目表、目标与策略树、BSC。用户或 Agent 的修改形成同一业务地图的新版本，原值和旧版可追溯，过期提交不覆盖人工值。 |
| W4 审查 | 审查有因果声明的具体连线，记录机制、必要条件、其他解释、风险、证据范围和检验办法。由原版本原连线进入模拟并返回。 |
| W5 模拟 | 两种模式比较同一口径下的具名方案和假设。可比模型可调整条件、观察结果翻转、保存及复查试算；资料不齐时支持定性比较。 |
| W6 来源 | 回查准确版本的原讨论、原文件位置和修订原因，按版导出离线 HTML。旧文稿、采用关系和原生消息可回读。 |
| W7 导入与承接 | 地图/目标表通过实际 Excel 预览、映射后保存草稿。分清零与待定、基线与目标；准确 G/S 经独立采用后承接不同 Case。 |
| W8 回归 | 隔离数据下走实际 UI、Host 和 Pi；验证重开、冲突、重复提交、权限、明暗/窄屏和焦点。分别记录工程验证、模型质量及运行采用。 |

## 责任与变更面

沿用工程规范第 2–4 节、统一会话 Interface v3、原 strategy-discussion owner/profile 和锁定的官方 Pi SDK 1.4.0。Host 在原权限内提供文件、地图、身份、版本、模型出口和原子写入。Agent 在同一对话内读取材料、自主选择方法、提出因果意见并修订候选。已有项目报告、研究或 Case/Teach 优先采用其授权来源；已有专业能力按业务入口使用。手工编辑、交接、采用和 Case 均有各自的用户动作。历史采用和正式运行另行记录。

变更范围为战略/目标/Case 受影响的 Host、Pi 工具契约、UI、导入解析与对应测试，不改变第三方 SDK 或正式项目文件。验收使用合成资料；数字示例仅供回归使用，工作台以所选版本的实际参数和适用范围为准。
