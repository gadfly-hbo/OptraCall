讨论profile专项边界沿A05/A10/A14合并检查：无Project只得本轮说明和准确获准Goal；选Project不继承普通Task全工具或queryRequirement全局默认范围；窄source-reader实际find/read/trace与来源范围可核。验证封闭resource配置、工具白名单及禁任意路径/扩展/Skill脚本/MCP旁路；停止/模型出口/来源Task排除/旧lease拒绝。验证同一真实discussion native多轮和重开，不能把现fixedInput拒绝历史的路径算作已支持恢复。需执行型能力的工作沿原Plan/Task，不把正常战略讨论强迫转成Plan，也不在确认前提前取业务明细。

## 贯穿材料与独立预期

主线使用合成服饰零售会员复购下降；在相同框架下加入：无企业锚定的会员部门重点、个人事业/家庭目标。改变问题与证据条件，不仅换公司名/数值。含已有GSA、旧BSC历史、目标/方法换版、外部前提变化、缺资料/替代解释、成熟窗口不足。

专业判据不预设必须找到根因/提高复购。先从材料独立推预期，再看Agent成果；核方法实际采用、事实/金额/分母/期间、因果必要性/贡献/充分性、预算现金与费用、样本/概率/显著性、观察窗口及真实行动依据。未授权模型时保持NOT_RUN，不用合成答案证明专业正确。

## 原七模块受影响兼容

| 模块 | 本轮回归锚点 |
| --- | --- |
| 战略与目标 | 原Goal/GSA/BSC同源、来源/采用/修订/CAS/三层反馈、旧目标无需重填 |
| Project需求与任务 | 轻量准备仍不取明细；原purpose语义不变、两种确认/单多Task/综合/归档恢复 |
| 分析与综合 | 精确目标/方法/资料和权限、混合文件/聊天成果、必要交付/自查、停止 |
| 审查与决策反馈 | 准确报告版本、原作者意见承接、原Case/Board选择授权/反馈/撤回，不由Goal采用授权行动 |
| 方法与资产 | SAP/IR/Studio/记忆原来源和人的治理、固定引用/错误版保护、data-analysis本体及原免测不动 |
| 自动模式 | 唯一全局节点原值/开始前读取/关闭不强杀/停止不续跑/不唤醒历史/IR不绕道 |
| 导航与市场 | 原入口、准确旧定位/配置/权限/历史/异常可达；不加战略平台或回造市场 |

运行时/权限/持久化/共享上下文改变需届时完整适用check，以及对应真实Host/SDK/浏览器路径。旧测试只作复用，不冒新候选PASS。完整候选由非作者干净上下文独立复核；设计检查、工程、合成Provider、真实Agent、专业、运行采用、用户验收和经营效果分别结论。
