## 用户查看的重点

1. 在原任务输入问题并发送，直接看到“原稿规则、支持证据、后来变化”。正常新增必做动作0。
2. 按需查看依据，分辨“原稿明确引用”“截至当次留存记录”“现在回看”；11月补录10月生效通知不会改写10月旧稿的引用。
3. 打开具体来源仍是准确旧版；查看缺失、未声明引用和冲突时仍说明未知，不用latest顶替。
4. 可选择追问／纠正，只带回原任务草稿；不直接修改正式定义或自动发送。无需日常维护新的语义资产表单。

## 原型与当前产品的差额

沿现有任务工作区、紫灰色调、深浅主题和资料／来源详情方式设计；增加回答的依据／变化按需展开。不是重做导航、图编辑器或增加组件管理页。当前产品已有M2来源保存、M5卡片／引用、M6来源查看；没有本版聚合查询与三种时间含义的整合展示。D05新增的是Agent使用原citation保存的资格，不新增普通用户必须点的确认。

Demo全部资料、日期、金额、ID和回答为虚构预置内容，刷新清空；没有模型、产品API、业务库、Semantica／Graphiti或可持久保存。Demo场景开关、暂停／故障预设仅供审阅，不进入正常产品流程。原型演示不会证明实际历史查询、业务适用性或计算正确。

## 验证与确认

准备阶段进行静态、实际浏览器、移动／桌面、深浅主题、键盘／焦点、失败和未知路径核查；具体候选与结果按[result](result.md)落档。实现后重新在真实产品入口检验原型与产品差异。用户尚未确认本包，不能标记UI已批准；原M2保留的历史展示差异也不因此消失。
