# L1→L2：组件最小范围与采用条件

2026-11-04 · 方案范围；**没有组件安装／产品接线／性能或中文查询实测**

## 1. 当前与以后各做什么

L1 本版只沿原权威对象回答精确引用、原时间声明和显式关系链。存量SAP、Enterprise、M2、M5／M6和Pi原生历史继续持有事实；不先建一套图／双时间历史来等组件替换。

L2 新session先验证 Semantica 所需最小模块；将同一组L1定义和普通证据映射成可重建的派生图，提供简单引用链难以经济完成的关系／时序查询。若最小 Semantica 路径足够就不扩选型；若episode演变事实／实体对齐或动态失效仍有具体缺口，再与Graphiti比较。不是默认维护两个引擎，也不因尚无真实受阻案例拒绝准备明确的问题基线；用户这轮提出的三问可先形成合成工程样例，真实收益仍待证。

## 2. 官方核验与最小候选

本次刷新官方文档（2026-11-04），结合[既有固定研究](../fourbase-optional-engines/research.md)。官方文档是能力依据，不是本产品已集成证明；原固定Semantica源码0.8.0／Graphiti-core0.31.2记录保持，不冒充已安装或未来采用版本。实际POC前再固定发布包／源码／API／后端版本。

| 候选 | 官方已有、应优先复用 | 最小拟验证范围 | 当前不默认启动 |
| --- | --- | --- | --- |
| Semantica | 来源、BiTemporalFact有效／记录时间、时点／区间查询、TemporalVersionManager版本快照；本体／SHACL另有模块 | 一个业务域，显式结构化来源与关系，精确源ref、原生时间／版本／必要路径查询，持久重开及可重建验证 | 全量原文抽取、自动建本体、GraphRAG、embedding、LLM生成／重排、全OWL与图谱管理平台 |
| Graphiti | episodes、事实有效窗口和记录／过期等时间字段、时间搜索及事实演变 | 仅在Semantica最小范围未满足的明确问题上，选择一个适配图后端及真实模型配置，比较同内容／同问题 | 默认OpenAI调用、全量episode摄取、两个图后端共建、并行自建时间库 |
| Pi1.4.0 | 会话、entry树、工具循环、分支／恢复／压缩、customTools与原生toolResult | 继续唯一Agent运行入口，由Agent自主选择调用／对照方法 | 组件获得第二套产品会话权威、Host查询规划循环或消息镜像 |

Semantica时间能力依据：[Temporal Intelligence](https://docs.getsemantica.ai/reference/temporal/)；本体／SHACL能力依据：[Ontology](https://docs.getsemantica.ai/reference/ontology/)。Graphiti时间与运行要求依据：[官方仓库](https://github.com/getzep/graphiti)。Pi持久历史依据：[Session format](https://pi.dev/docs/latest/session-format)及本地锁定随包文档。以上是概括，不保证具体配置天然保存全部历史／原件，也不承诺中文时间解析与本产品兼容。

Graphiti当前官方列图数据库与模型配置要求，默认推断／embedding走OpenAI，允许替代路径；不得假设继承Pi Provider，也不得笼统称所有路径必须远程模型。Kuzu已在官方标为deprecated，不能用旧资料将其当默认个人嵌入式方案。组件的telemetry、后台写入、下载／embedding／抽取／模型及网络行为按实际选定路径核定，不用“本地框架”概括为零副作用。

## 3. 源与投影的最小合同（L2 POC待细化，不是本轮新增持久schema）

输入分三类：①权威已发布定义（如SAP）；②有来源但未必已核实的事实／制度／观点与用户陈述；③明确标识的推断／候选关系。②③可成为证据，不能因未发表就不可查询，也不能自动升级为①。图谱不复制可独立编辑的正式公式。

必须能还原：原对象身份／修订／hash及可回读位置、关系方向／适用对象与时间、来源声明／推断性质、不确定性和当前准入。把 valid-time 与 recorded／known-time 按原生能力逐项映射；记录时间不能补造人或Agent已知，历史实际采用另从原稿／运行证据定位。

映射结果逐项标 `mapped/partial/unsupported`，列出原限制／有损原因、组件版本／配置／源版本、重建依据。组件能保存快照不证明源文件旧字节存在；图索引重建不等于业务数据回滚。不得让automatic fact invalidation自动改写SAP、旧报告、M5判断或人的选择；图派生状态变化只供Agent／人复核。

## 4. 进入／继续／退出条件

1. **有固定问题与基线。** 沿本版三问，至少加入跨资料同名对象、反证和回溯生效通知；固定同内容、同模型／权限／预算条件，比较L1与最小L2。不能给L2额外知识再归因于图技术。
2. **原生能力实证。** 固定版本验证原始来源／时间映射、冲突、缺失、持久重开、更新／失效、从源重建及有损投影；组件源码／官网声明不代运行证据。L1不做并行图历史引擎。
3. **环境与副作用明确。** 个人Mac运行依赖、后端、磁盘／内存、启动／停止／取消、升级回退、费用／外传及provider独立配置可核对。所需安装、真实模型／材料、网络及服务运行按届时有效授权实施。
4. **确有增量价值。** 至少一个固定关系／时间问题较现有查读减少错误或重复取材，且维护／资源负担可接受；先测基线再定量门槛，不写凭空提升百分比。无收益、语义有损不可接受或停用后主任务不可用则不采用／收缩。
5. **采用决定单独落档。** 只有上述范围及缺口被实证且后续spec／UI和必要结构获确认，才进入正式L2接线。当前确认D07只批准准备边界，不批准安装全部框架、正式依赖、后台全量建图或真实经营试验。

不满足时保留当前L1准确追溯；缺失／无收益／失败仍落档。L2的完整本体、SHACL、实体对齐及团队治理依具体问题另细化，不能借“为将来预留”要求当前先完成全部。
