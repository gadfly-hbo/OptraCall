## 本轮目标与明确顺序

先完成统一 Studio 的通用产品能力：企业基础层提前建设，Case／项目／任务贡献持续演进，企业资料与 SAP 指标／方法站内整合，普通 Pi 分析任务真实取得并使用合格资产、解释依据、有限决策与回补。验收以[已确认 spec SU01–SU24／D01–D09](review-v0.3/spec.md)和[已确认 UI Demo](../../../docs/prototypes/studio-phase2-v0.3/index.html)为基准。

门店会员运营主题随后在建成产品中落地：获准资料→企业基础层建设→普通任务使用→任务演进贡献→核定合并基础层→新版再用与历史。当前产品工程使用隔离合成资料验证通用路径，不把演示口径或计算器内置为真实企业标准，不提前生成会员主题正式资产。

用户确认记录：“此版方案spec和UI demo确认，按照开发规范需要有目标任务清单同步输出，在实施过程中进行跟进。”及“先按照上面已确认的方案spec和UI demo完成产品建设，门店会员运营主题的落地按照上面我们确认的二层建设流程再落地。”

## 跟进规则

每个P项随真实完成条件更新，记录测试命令、准确候选、失败和证据链接；部分完成不勾成全部完成。新增问题先对照SU和本项完成条件，修直接回归／阻塞，范围外记录后继续主任务。已确认原包不改写，实施合同、任务与结果在本目录单独维护。
