# Studio 二期建设与实际使用交互状态矩阵

版本 v0.3 · 2026-11-12 · 配套[完整设计规格](spec.md)与[新版可点击 Demo](../../../../docs/prototypes/studio-phase2-v0.3/index.html)

本表将建设管理和普通任务消费并列核对。产品期望、原型状态模拟与本地确定性计算分别记录：新版 Demo 不调用 Pi 或模型，资产发现／读取投影与分析文案为演示，本地合成数据计算可以实际执行，二者均不能证明真实 Pi 自主使用或专业正确性。本版覆盖结果在[准备结果](result.md)记录，旧版结论不移作本版通过。

## 场景与状态转换

## 普通任务消费状态

| 场景 | 前态 | 用户或模拟动作 | 可观察后态 | 禁止副作用 | 对应需求 |
| --- | --- | --- | --- | --- | --- |
| UI21 直接任务提问 | Case／项目已明确 A 企业及普通任务 | 从 Case／项目打开分析，直接输入原会员问题并开始演示 | 进入原任务消费界面；企业范围和目录沿上下文提供，无需进入 Studio 或勾选资产 | 不把资产建设或手选设为分析前置，不借其他企业／任务材料 | SU03、SU15 |
| UI22 自主发现与准确读取 | 有适用正式指标、方法及来源目录 | 正常消费演示，展开依据 | 目录、准确正文／版本、读取覆盖和适用条件分别可查；本地模拟与真实调用身份清楚区分 | 不把目录或模拟步骤当真实 Pi 读取，不自动注入所有正文 | SU16、SU21 |
| UI23 采用与拒用 | 可见多个资产，其中部分不适用 | 查看本次依据及未采用项 | 采用的指标／方法有用途与版本，拒用或待核有原因；正式资产不必全部使用 | 不为了使用率强行采用，不把资产勾选当正确应用 | SU17、SU19 |
| UI24 本地合成计算 | 定义和必要正文完整，获准合成数据可用 | 开始演示并查看分子分母、资格和明细 | 实际本地计算展示队列、截止、观察资格、去重、退款处理、样本量及公式；结果和可核输入对应 | 不说成真实 Pi 调用，不由预置比率替代明细计算，不将观察不足记为零复购 | SU18、SU19 |
| UI25 分析与有限建议 | 本地结果与适用条件成立 | 查看回答并形成核查建议／Case 草稿 | 门店比较、排序和限制与结果一致；建议或草稿保持未采纳、未执行，解释何时应改变判断 | 不由相关性断言原因，不派发行动、发券或填实际效果 | SU19、SU20 |
| UI26 关键资产缺失 | 企业合格目录没有必要定义／映射 | 选择消费 missing 场景并提问 | 明确缺什么及影响；有充分临时依据才可在原范围限定计算，独立工作可继续 | 不编造正式口径，不自动借用 B 企业或让用户关闭权限 | SU15、SU22 |
| UI27 正文读取失败 | 目录可见，实际必要正文未取得 | 选择 read-failed，查看提示，再按可用动作重查 | 读取失败和未采用明确；重查成功后才显示足够正文及后续计算 | 不把可见标题标已读，不静默用旧缓存／猜测定义出重要结论 | SU16、SU21、SU22 |
| UI28 部分读取补读 | 必要正文 partial／有 continuation | 选择 partial-read，查看范围，再继续读取 | 未读范围和原因可见；必要定义补齐后才进入对应计算，已有片段不被冒称全文 | 不拼接不同版本片段，不因初次成功调用宣称全读或全局失败 | SU16、SU22 |
| UI29 定义或范围冲突 | 同名定义／时期／映射前提冲突 | 选择 conflict，查看两方依据 | 保留冲突和受影响结论，Agent 先核来源及用途，资料不足才求必要业务决定 | 不任取较有利口径、不把候选强转正式、不默化为零结果 | SU17、SU22 |
| UI30 临时依据 | 当前正式依据不足，存在任务内获准且可说明的临时材料 | 选择 temporary，在明确用途和限制后继续本次分析 | 回答标明临时来源、准确输入、用途与限制；与正式资产采用区分 | 不把临时结果纳入企业默认库，不伪造正式发布或专业验收 | SU17、SU18、SU22 |
| UI31 拒绝或失效 | 来源 forbidden／disabled／受治理限制 | 查看原资格状态及历史依据 | 当前不合格来源不进入新结论；历史按权限可查，其他合格依据仍可使用 | 不泄露跨范围标题／正文，不通过旧图或旧选择恢复当前资格 | SU10、SU13、SU22 |
| UI32 真实使用证据边界 | 回答有实际本地计算及模拟来源记录 | 展开依据，查看作者声明与核验状态 | 提供、读取、计算、作者引用声明和独立核验分开；未做独立核验保持未核验 | 不从声明保存推断正确采用，不用模拟原生记录冒充真实工具回执 | SU21 |
| UI33 新版普通任务再用 | 指标已从 `1.2.0` 正式修订为 `1.3.0` | 进入新的普通任务再次分析，查看旧 R01 与运行任务 | 新任务发现并采用当前合格版，本地计算依据随之变化；旧报告及运行中任务保持旧准确依据 | 不自动改历史值、复制旧成绩到新版，失效来源不能继续用于新结论 | SU10、SU18、SU23 |
| UI34 消费反馈回建设 | 普通任务发现源定义缺陷或可复用增量 | 查看反馈贡献，进入候选 | 来源任务、报告、输入和准确版本与差异关联；候选待核，继续走原正式发布与再用 | 不把本次计算错误都改写标准，不由贡献保存声称问题解决 | SU07、SU08、SU24 |
| UI35 无 Case 或写资格 | 普通任务未绑定 Case，或本模式未授 Case 写口 | 查看有限建议和可用动作 | 普通分析可继续；建议可留原报告，Case 草稿保存不可用并说明范围 | 不猜 Case、不扩大模式权限，不因不能写 Case 阻断原分析 | SU15、SU20、SU22 |

本表 UI21–UI35 的读取和资格状态在原型中最多模拟，UI24 的合成计算可以实际执行。真实工具准入、全部分页来源、精确字节、原生工具轨迹及专业判断，仍需后续获准 Pi 验收；原型只核对应的界面和本地数据契约。

## 原型评审控制

评审场景控件单独折叠，正常用户路径不要求选择场景。预期稳定入口为：

- 三视图：`tab-foundation`、`tab-evolution`、`tab-publication`。
- 企业切换：`company-select`，A 企业（合成）与 B 企业（合成）；B 企业显示空库。
- 分类、搜索与详情：`category-<id>`、`asset-search`、`asset-<id>`。
- 主路径：`create-foundation`、`open-task`、`open-candidate`、`prepare-preview`、`confirm-publish`、`query-receipt`。
- 场景选择：`scenario-select`，支持 `success`、`partial`、`unknown`、`conflict`、`archived`、`unassigned`、`empty`；切换场景会重置内存种子状态。
- `reset-demo` 恢复原型种子状态，不能影响业务数据。
- 合成旧报告 R01 固定指标 `1.2.0`，企业修订候选目标 `1.3.0`。
- 消费入口：`nav-cases`／`nav-projects` → `usage-open-analysis`，或 `usage-nav-analysis`；直接提问为 `usage-question` 与 `usage-run`。
- 消费场景：`usage-scenario` 的 `normal`、`missing`、`read-failed`、`partial-read`、`conflict`、`temporary`；企业 B 的隔离与空库仍由企业切换核对。
- 依据与补证：`usage-evidence`、`usage-read-more`、`usage-retry`、`usage-temporary`；有限决策与贡献：`usage-create-decision`、`usage-contribute`。


具体控件和场景与原型作者核对后，以实际候选及浏览器记录为准；DOM 调试状态仅辅助检查，不能代替点击路径。

UI19 中真实取消、迟到 owner 与持久化副作用，以及 UI17 中真实来源准入，本轮最多验证其界面表达；公共生命周期和访问拒绝不能凭演示状态标记产品通过。

## 后续产品验收需要补证的范围

| 范围 | 原型能核对什么 | 真实产品仍须证明 |
| --- | --- | --- |
| 企业身份与旧资料归属 | 可见范围、待核状态和候选归属体验 | Host 的准确准入、跨企业拒绝、历史兼容及来源字节保全 |
| 候选和版本 | 页面状态、差异、历史引用及分项结果展示 | 原专业库真实写入、CAS、并发、幂等回执和失败恢复 |
| Agent 与公共生命周期 | 主工作台、任务出处和运行状态的预置投影 | 原 SDK 原生会话、owner/profile、取消、迟到和关闭行为 |
| 新任务与运行任务 | 新旧版本显示及默认目录体验 | 准确来源资格、运行快照不漂移、实际读取和使用记录 |
| 会员专业质量 | 口径和限制应怎样展示 | 获准资料下身份、首购、观察期、复购计算、解释和修订再用正确性 |
| 普通消费链 | 从 Case／项目直接提问、精读状态、适用性、本地合成计算及有限建议体验 | 独立普通 Pi 新任务的实际目录发现、准确正文读取与正确应用；不能由手选或模拟记录代替 |
| 修订后再用 | 新版计算与旧报告／运行任务版本显示 | 准确发布后另一个普通 Pi 新任务真实使用新版、独立专业复核及历史依据保全 |


原型未模拟的接口、安全和专业行为不列为浏览器通过；实现后的适用验证仍按[规格](spec.md#会员场景与验证分层)与工程规范独立执行。
