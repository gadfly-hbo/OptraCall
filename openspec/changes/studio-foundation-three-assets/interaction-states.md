版本 v0.1 · 2026-11-12 · 与 [spec](spec.md)／[目标清单](tasks.md)一并审核

本表约定可点击 [Demo](../../../docs/prototypes/studio-foundation-v0.2/index.html)应表达的观察点。场景使用虚构企业 A、参考和预置回执；按钮只改变本地演示状态，不能产生真实构建、核查、读取、发布或模型结果。实际浏览器已验／未验项由根 Agent 在最终审核记录按准确候选补记，不能因列入本表就记作通过。

| U08 | 正文部分返回／续读 | 显示真实读取范围和未取得内容；可继续读或限制结论 | 以目录、片段、成功调用冒充完整读取及正确使用 | FA11、FA16 |

| U11 | 新版再用 | 受控“正常＋宽限”→“仅正常”修订后，新的演示任务指向1.1.0及相关规则，说明适用范围与结果差异 | 只换版本标签就说业务已验证，或影响运行中固定版本 | FA07、FA12、FA16 |
| U12 | 无图或图未刷新 | 独立合格主数据／SAP／源正文仍可读；依赖图用途限定，不恢复失效来源 | 强制先构完图才能使用全部资产 | FA12 |
| U13 | 权限／企业范围矛盾 | 限制受影响引用并给明确原因；普通 profile 不获得建设写权，不暴露跨企业正文 | 将参考身份或企业关联当数据访问许可 | FA05、FA15 |
| U14 | 检查 PASS 但业务未核 | 显示结构检查事实、Agent 作者声明及独立核验各自状态 | 一键“检查完成”被称企业全部业务正确 | FA07、FA16 |
| U15 | 取消／关闭／迟到 | 预览取消不发布；真实取消或失效 owner 不获得后续写入，迟到仅补原技术事实；Demo返回原上下文 | 关闭后继续隐式派发、迟到回执复活发布 | FA09、FA15 |
| U16 | 技术加载或读取失败 | 错误与原准确身份保持；可返回、重查，只读失败不换用 latest；其他独立可用材料继续 | 失败后补造已读取、已核验或自动换源 | FA11、FA14–FA16 |

U03、U12、U13、U15 的真实 Host／权限／取消性质无法由静态 Demo 证明。Demo 只审核可见状态与动作边界，未来工程阶段必须有对应真实调用／禁止副作用证据。U08 的演示续读不能作为实际工具续读证据；U10／U11 的预置报告不能作为真实模型使用验收。

## 原型行为与无副作用边界

情景切换放在独立的审核辅助区，不是用户正常使用前提。查看详情、切换三类、查看来源和返回应保留上下文；页内关键动作可键盘操作。抽屉／对话框有标题、初始焦点、Tab 范围、Escape 关闭和返回触发点；未保存变稿要明确继续编辑或放弃，已保存历史不变。

桌面与窄屏下，主动作和必要状态可达，表格局部滚动，页面不整体横溢。亮暗主题保持信息层级和语义状态，颜色配文字。源 ID、长中文及部分失败文案可换行或展开。
