## 原型首轮发现与修订

以下是本轮原型问题，不能据此推断已上线产品存在相同缺陷。原发现保留，本轮修订另述结果。

| 发现 | 修订及读回 |
| --- | --- |
| 空白企业可进入 A 的预置任务／发布；创建时暗切 A；评审空态与当前企业不一致 | B 各视图独立空态，建设保留 B；空白情景明确切 B，切回 A 恢复正常情景；非作者与浏览器读回 |
| 候选保存只增修订号、正文和范围未保留；修改后仍显已核定 | 内存保存准确新稿／范围及历史，受影响状态待核、旧预览失效；浏览器改稿后重开读回 |
| 自定义内容可能继承受控样例检查 | 自定义内容保持业务待核，预览禁用；只有明确另存受控样例才能查看其预置检查 |
| 贡献来源随当前新任务变化 | 捕获原 sourceTask、报告、源修订与 SAP 版本；浏览器新建 A-2 后贡献仍指 A-1 |
| 发布后总览／详情／准确来源仍混用旧版，后续编辑基准也硬编码旧版 | 当前合格组合、源详情和当前正式基准一致；历史 R-01 独立固定 r1／SAP1.0.0；非作者与浏览器读回 |
| 失效预览的返回动作没有到达核查 | 沿原型已有关联核验导航返回，显示新候选待核且预览禁用；浏览器读回 |
| 冲突限定预览选门店定义，正文却仍为会员资格规则 | 正文、范围、选中源及分项结果统一限定独立门店定义，排除会员计数；浏览器及非作者读回 |
| 缺少明确读取失败恢复分支；同候选可重复发布 | 增加准确版本读取失败→只读重查仍失败；同候选已有结果只读回看，UNKNOWN 保持原请求，不重发 |
| 窄屏左栏只有图标名称 | 补显式导航可访问名称，390px DOM 检查可读 |

浏览器使用中出现一次字段精确标签定位失败及一次尝试点击已禁用预览；均为操作定位／预期禁止动作，随后用真实标签和 enabled 状态核定，没有将其计为产品执行或业务失败。最初预览服务器目录导致完整模板链接不可达，已改为只读 docs 路由并实际打开模板确认；未修改正确的模板相对引用。
