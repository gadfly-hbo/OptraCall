# UI Demo 审阅路径

v0.1 · 2026-11-04 · **虚构内存原型，供审核，未接产品或模型。**

打开[可点击 Demo](../../../docs/prototypes/sap-analysis-methods-ui-demo.html)。所有分析、方法、来源和结果均为合成示例；保存／发布只改变页面内存，刷新后恢复示例。演示情境是审阅辅助，不是产品增加给普通用户的操作。

## 1. 建议先看这四条路径

1. **后置提取**：从分析窗口已完成任务开始，点击提取分析方法；查看运行和保存反馈，再进入SAP方法。结果应为已保存未发布，尚不可供后续任务参考。原报告始终保留。
2. **正式采用**：查看方法的逻辑、适用条件和来源，按SAP规则发布确定版本。发布后才显示可供后续任务参考；普通参考不另加逐次审批或IR采用入口。
3. **修订**：编辑已发布方法并保存新版本。原发布版继续可参考，待发布新版独立显示；发布新版本后才按SAP版本策略采用。
4. **两类来源一致**：切换来源筛选，查看非IR方法的未发布与已发布状态；同样只有发布成功的版本才可供后续任务参考。

## 2. 再看失败、历史与最少操作

| 路径 | 预期 | spec |
| --- | --- | --- |
| 保存失败 | 输入／结果保留，不显示已保存或已发布；原分析完成状态保持 | SAM06、SAM10 |
| 发布失败 | 已保存未发布的新版本保持，原发布版不消失，不把部分成功写成全部成功 | SAM07、SAM08、SAM10 |
| 完整复用／无可提炼内容 | 关联准确原版本或说明无新内容，不生成空方法／重复方法 | SAM03、SAM08 |
| 未完成／忙／归档来源 | 说明来源局限或项目不可提取，不停止原任务；无关全局SAP管理不因此冻结 | SAM02、SAM10 |
| 纠错与版本 | 错误提示可查，纠正版须发布后才参考，旧报告和来源仍能查看 | SAM09 |
| 搜索、筛选、空列表 | 来源标签与发布状态独立；无结果能清除条件 | SAM05、SAM13 |
| 编辑未保存／关闭浮层 | 不静默丢编辑；键盘焦点进入、关闭和返回正常 | SAM13 |
| 亮／暗、窄屏 | 主操作和状态可读，筛选可换行，列表不覆盖正文 | SAM13 |

原型不能证明真实提炼内容质量、权限隔离、长Session按需查读、公共会话取消／关闭、文件保存重开或兼容迁移。这些仍须在获准产品实施后按spec验证。Demo若未模拟某项工程反例，不等于该验收已通过。

## 3. 风格与职责前置检查

- 当前根目录无`DESIGN.md`；沿已有工作台与原型，并采用中央SaaS规范，中性表面、克制蓝色、平衡密度及亮暗一致信息层级。本次不扩大为全产品改版。
- 普通分析新增必做操作0。提取是自愿的一次动作；发布是确定版本进入后续参考的必要业务动作，沿SAP统一规则；可选“保存并发布”合并操作，但不合并事实。
- Host只展示环境、归属、状态、版本及保存结果；Agent整理逻辑和方法，后续使用由Agent按需判断；界面不要求用户安排内部工具步骤或填写机器身份。
- 版本、来源、问题与限制按需展开；UI不把工程profile／owner、传输上限和SDK实现细节放入普通产品路径。

实际浏览器检查及独立复核结果见[result](result.md)。当前“可体验”只指该合成原型；仍需用户审核交互和规格，不宣称产品验收。
