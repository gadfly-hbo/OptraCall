# 报告框架覆盖复核

v0.1 · 评审稿。细化[报告计算复核 RCR04、RCR07 和 RCR08](../report-calculation-review/spec.md)。[可点击流程演示](../../../docs/prototypes/report-framework-coverage-flow-demo.html)使用合成资料和内存状态，展示现有对话、停止和报告文件入口。

## 1. 触发与核对范围

**FCR01｜同一次委派。** 适用的普通任务形成正式初稿后，原主 Agent 在最终答复前沿现有计算复核委派一次子 Agent。子 Agent 在同一回执中报告计算与框架覆盖发现。范围沿原 RCR01，只有框架的纯描述报告、短答和临时文件继续走普通交付。无需新增入口、开关、额外确认或子 Agent 会话。

**FCR02｜只核对本轮可证的要求。** Host 将固定初稿和本轮实际提供给主 Agent、已确认且当前仍获准读取的框架或 RAP 内容交给子 Agent，绑定父请求、初稿、来源版本及实际提供范围。可沿本轮框架确认后送入的回执，也可复用旧任务中可证实际送入的已发布 RAP。仅给出目录、标题或部分片段时，按可证的内容核对。缺少确认或送入证据、版本冲突、撤权及截断应明确范围。后来发布的版本、当前资料全文和未送入的草案不能补造当时的输入。[框架确认与送入](../requirements-analysis-framework/spec.md#3-框架内容确认与-ui) · [既有 RAP 接入](../requirements-elaboration/spec.md)

**FCR03｜检查问题是否得到回应。** 子 Agent 对照框架中的关键业务问题、已确认范围和约定交付，指出影响报告可用性的差异。本轮有可证的用户范围调整时按调整后范围核对，明确哪些原问题已移出范围。Agent 因证据不足提出的限缩单独说明。框架中供参考的分析路径可由主 Agent 调整。证据能否推出结论和行动建议，归[独立结论审查](../conclusion-recommendation-review/spec.md#3-证据判据与交付)。

| 意见 | 识别例子 |
| --- | --- |
| 已回应 | 框架约定按渠道和品类拆解，初稿分别给出两项结果，或在同等覆盖的表格中可定位。 |
| 未说明的遗漏 | 初稿只有渠道拆解，品类完全未回应，也未说明调整范围或缺口。 |
| 明确限缩或待补证 | 报告说明品类字段缺失、本轮只能核对渠道，并指出哪些判断需等补证。意见可提示该缺口对交付的影响。 |
| 覆盖未核实 | 框架不可读、身份无法核对或实际只交付了部分内容。对可证部分照常复核，剩余范围保留未知。 |

## 2. 意见回交与修订

**FCR04｜沿原生回执交回原主 Agent。** 重要意见给出具体的框架要求、初稿位置或缺口、实际依据及影响。Host 保存实际回执与版本。主 Agent 自主核实、补做、说明限缩，或据实保留原稿。借鉴红→绿，先用明确要求定位差异，修订后主 Agent 用同一要求和材料自查。修订沿既有保存方式保留原稿，覆盖意见按实际处置记录。复查属于主 Agent 自查，无第二次自动委派、逐项放行或覆盖率评分。

## 3. 接入、交互与四原则

沿[工程规范 v1.9 IN01–IN07](../../../docs/engineering-workflow.md#统一会话接入规范当前interface-v3兼容v1v2业务子集)及[统一会话接入](../../../docs/agent-session-integration.md#接入验证与工具读取)。复用 Interface v3、原 `project-tasks` 的 `projectId/taskId` owner、同一父请求与锁定官方 Pi 1.4.0 的前台 `subagent` 和父工具回执。Host 负责授权、提供准确只读版本、取消及记录。两位 Agent 分别自主选择核对与处置方法。普通用户沿原提问、查看报告路径，额外必做操作为零。实现范围限 RCR 已批准后适用的委派材料、意见契约、回执及相应检查，新增只读接线仅用于可证的实际框架交付。此增量无产品 UI 改动，流程演示用于评审正常、补证、无框架和取消情形。

## 4. 后续验收

| 标识 | 可观察判据 |
| --- | --- |
| FCR-A1 | 有实际送入的确切框架版本时，父原生回执只出现一次子委派。初稿漏品类可定位，主 Agent 能据源补齐并用同一要求复查，原稿可回看。 |
| FCR-A2 | 已说明品类缺失及影响时记录待补证。等效但不同的分析方法仍可判为已回应。主 Agent 能核实并保留有依据的原稿。 |
| FCR-A3 | 缺少框架、仅目录、部分内容、撤权、原输入身份不明或之后发布新版时，限定实际核对范围，计算复核仍可继续。只凭已存在 RAP 无法触发本功能。 |
| FCR-A4 | 取消或迟到意见沿原父请求资格处理。新稿、旧意见、首答的实际版本可回读，无覆盖判断自动放行或自动再跑。 |

评审检查覆盖遗漏补齐、已说明待补证、未送入框架和取消保留初稿。Chrome 桌面及 390 像素布局通过，框架来源与一次委派边界经非作者复核。检查限合成原型，工程接线及专业验收待授权。
