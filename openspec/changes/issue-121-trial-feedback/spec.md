- 错误提示复用现有控件和状态入口；三层授权表单仅补齐 #111 已确认规格要求的用途/期间字段，属于既定合同缺漏，不新增布局、导航或权限交互流程，沿用原批准设计，无需另出 Demo。若后续出现其他明显 UI 变化，先停止受影响实现并提交可点击 Demo 审核。
