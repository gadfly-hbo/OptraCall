# Decision Case 工作台 v5 演示说明

从该确认提交下载 [demo.html](demo.html)，用浏览器打开即可。以下 `#` 开头的片段可直接加到本地文件地址末尾。预览使用合成门店、模拟 Agent 和浏览器会话数据。Agent 建议、凭证、连接和授权都可以在原型中试操作。

右上角的「已有基础建设」和「从零开始」各有独立状态。「从零开始」展示尚未做四项基建的用户，仍有示例项目可进入。浏览器允许会话存储时，在同一标签刷新可以恢复所选目标和已保存草稿。要复演初始状态，关闭此前的无痕窗口，再从新的无痕窗口独立打开该文件；普通刷新会保留本轮修改。

## W06 目标管理

1. **候选如何变成可拆解计划。** 在成熟场景打开 `#foundation/goals?goal=first-visit`。先读 GSA 工作表，再点「补齐 GSA 后开始拆解」。让 Agent 推荐计划 A，手动改一项，再撤销建议，核对手改仍在。取消编辑会还原此次编辑会话的确认人和说明。保存候选后重新打开，明确确认才进入拆解。
2. **草稿与正式版。** 打开 `#foundation/goals?goal=east-annual`，默认读冻结表。对照正式目标 30%、可达测算 28%、差额 2 个百分点。点「修订拆解草稿」修改责任人，退出再打开，读回草稿；冻结表仍显示原负责人。再试同一目标修订总 GSA，明确承接后原草稿才绑定新版。发布预览只读，确认发布才新增冻结版本。
3. **实绩与复盘。** 从冻结表点「开始阶段跟进」。依次选用完整、部分出数或缺截至日期的报表，查看原句、范围和所对照的冻结版本；部分出数时整体偏差待补。在「到期复盘」修改、舍弃或恢复结论，勾选要带入下一期的结论。要回送战略，先「保存到期复盘记录」，从「历史复盘记录与战略回送」打开「回送战略重审」，勾选这条原证据并填写说明，然后回战略讨论核对原证据和原适用范围。恢复已舍弃项后仍需手动勾选。
