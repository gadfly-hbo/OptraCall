Pi 可以问什么

6 类操作供自主选择，不是 6 个强制步骤。
操作取得的内容边界
find相关概念、指标／方法版、字段和条件声明当前有权有限图按词组子串匹配，按准确 ID 稳定排序，不承诺通用 GraphRAG
definition业务定义、准确版本、条件、限制与性质未知与争议保留，不自动认定企业口径成立
neighbors一跳完整关系、方向、平行边及各自依据不按同端点折叠，不造反向来源
dependencies金额操作数和方法所需指标有界依赖遍历，不执行公式
impact字段→指标→方法的有限影响关系每步保留准确边 ID、遍历方向与来源，平行边不折叠；路径不当经营因果
source已授权来源句柄对应的准确语义片段不返回交易明细、控制／参考答案、企业原附件或磁盘根

建议资源合同：页缺省 20、最大 100；遍历深度缺省 2、最大 4；单次最多处理 200 合格节点／500 合格边；模型 content 完整 JSON 不超过 24KiB UTF-8。达到边界明确不完整，不截断 JSON、不暗中丢关键条件。

权限与使用体验

  • 模型不传 owner、目录、凭据、会话文件或任意查询代码。Host 从实际 run 核资格，并在回包前再次检查。
  • managed ordinary 只加 graph 可信只读包装，不顺带开放旧目录动作、M2 写工具、任意 MCP／扩展；专用 protected、fixed-draft／text-only、核算／修订、业务 workspace 和子角色不扩权。
  • 来源禁用／错误治理对新查询即时生效，历史准确引用保留；缺失 hash 按原合同保留限制，不补造值。
  • 同一工具说明列出获准 graph 能力，调用顺序仍由 Agent 选择；原依据详情补新结果类型的必要投影，不建新页。主回答由 Agent 解释关键口径／冲突；正常新增必做操作为 0。
  • L1 继续提供原资料与分析工具，图不可用时可继续有权分析；兜底不能绕过撤权或版本要求。
