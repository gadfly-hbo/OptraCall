L2：以后端本体与知识图谱支撑 Agent 理解语义

L2的主要价值在后端。优先借Semantica本体表达概念／范围／关系类型与明确规则，用知识图谱组织具体对象／事实／关系／来源／版本，经原工具资格供Agent按需取得、理解和正确使用。来源／规则、关系／事实演变和检索服务该目标；语义理解是否改善仍须实证。原SAP、资料与Case保留权威，Pi承担会话与自主分析，用户正常新增必做操作为零。

用户直接看回答即可取得关键解释。Agent应在正文主动说明相关关键口径、适用范围、重要冲突／未知及其对结论的影响。原“查看依据”详情中的业务含义／口径说明仅供自愿深入核对，不增加独立页面、一级导航或必做查看步骤。不打开详情也能继续任务；Host不强制每轮查L2、固定分析顺序或代Agent处理冲突。

Semantica／Graphiti怎样参与

两者是实现L2的候选组件。Semantica优先评估语义／本体、关系、来源、规则约束及时间模块；Graphiti在持续事件输入、实体对齐、增量事实更新和历史检索出现明确缺口后针对同题比较。能力有重叠，Semantica也有时间能力，Graphiti也支持类型与来源；不默认两套一起安装或按“语义／时间”机械拆分。

OptraCall补业务引用／身份映射、权限、Pi工具接入、保存及必要展示。前端解释窗口不构成语义权威，也不把常规理解和冲突识别交给用户。组件约束校验不等于业务真值／专业正确，事实失效不自动改SAP、旧报告或人的选择。

本版确认后端定位与主答／可选依据交互；实施建议仍仅先开原P1。
P1保持固定Semantica 0.7.0最小来源／显式关系／时间／SQLite快照与同源L1对照，只验接入底座，不证明Agent语义理解增强。Graphiti不安装、不摄取、不运行。完整本体治理、抽取／对齐和持续更新按后续切片细化，核心增益要看Agent理解、口径适用和冲突处理的实际改善，不能以图节点数、页面或预置回答代替。P2接线另定范围，不等于完整L2一次做完；组件安装、运行或开发仍须先获本版整体确认。

P1结构摘要与后续事项

P1只提出可重建的派生ReadModel：实体对应原修订，边对应原有向声明，字段逻辑组直接映射原引用／组件原生字段。不建业务表、迁移、统一ID或第二消息库。13类结构完整性已在决定包逐项归属；完整L2的本体／规则、增量事实／实体对齐等尚未提出生产持久合同，不能因确认方向就视为具体schema、模型或后台摄取获批。

关键风险：发布包API的文本查询、双轴不同截点、默认时间、平行边比较和跨两库一致性均有边界。业务样例沿Case→引用清单→SAP，不新增直接Case/SAP关系；精确时间原语单独验证，不为业务未知时间补值。浏览器旧v0.1曾因Work设置禁用受阻，此前v0.2直接打开本地HTML被URL策略拒绝file协议（仅HTTP／HTTPS）；v0.3未再尝试或绕过，实际桌面／375px／主题／焦点／交互与请求观察均NOT_RUN。组件安装、运行、Agent理解与专业收益未证，全部原FAIL／UNKNOWN／NOT_PROVED及旧WIP保留。
