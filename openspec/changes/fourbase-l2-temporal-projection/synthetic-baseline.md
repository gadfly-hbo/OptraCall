## 1. 题面与时间约定

事项：门店 C-17 的一次小范围促销建议。三个独立问题：

1. 2026-10-10 的 R-10 第2稿明确引用哪版规则？同名渠道指标是否等同？
2. J-1 有哪些明确支持／反对及依赖来源？列出方向和准确版本，哪些不能证明因果？
3. 今天回看，哪些前提有新材料需要重核？11-02 才保存、声明 10-01 生效的通知能否证明报告当时已知？

全部明确到秒的样例时间均为 Asia/Shanghai（+08:00）。“10月1日起”是日期粒度声明，不能自动当作通知被知晓的时刻。未知时间标“未知”，没有隐含当前时间或无限期。界限问题按原生 API 运行后记录实际开闭区间，不在本文件预断其实现。
