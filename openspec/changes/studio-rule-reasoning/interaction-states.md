## 必须覆盖的分支

| ID | 状态／操作 | 必须观察到的行为 | 禁止误呈现 |
| --- | --- | --- | --- |
| U01 | 正常受控样例 | 原版r1宽限可计，候选r2仅正常；4条虚构样本在两个版本的明确资格变化 | 预置结果当SDK实跑或企业政策 |
| U02 | 自定义规则编辑 | 保存成新候选，旧检查／预览失效，定义／映射／计算待核；仅显式恢复受控样例可看固定检查 | 任意改稿一键变PASS |
| U03 | 缺时间／事实 | 显示具体缺项及未知，不输出完整有效总数；可预览独立定义用途 | 缺失当不符合或零 |
| U04 | 冲突规则 | 并列来源／命中前提及受影响项，规则执行用途不能发布，独立门店定义可继续 | 优先级或最后一条自动裁政策 |
| U05 | 不支持表达 | 保留原文，说明当前执行子集不支持；不调用或不生成成功结论 | SDK不识别后自解释或静默换LLM |
| U06 | 来源撤回／失权 | 当前调用受限，保留准确引用和失效原因；原历史保持但不恢复当前资格 | 换latest或复用旧缓存结果 |
| U07 | 推导未完成／取消 | 实际范围及未完成清楚，不当作0条不符合；可继续独立分析 | 超时或取消当完整空结果 |
| U08 | 预览后变稿 | 原准确预览失效，不得确认；新候选检查待核 | 旧指纹发布新稿 |
| U09 | 发布UNKNOWN | 保留同一演示请求及分项，按钮只查原结果；仍未知不重发，相关执行用途受限 | 成功徽标覆盖未知或重复发布 |
| U10 | 跨企业／无权限 | 不展示另一企业源文、事实或结果；返回受限原因 | 企业名称相似就复用 |
| U11 | 空企业／无图 | 空态可看范围和建设入口；无图不阻断准确正文／规则工具的独立用途 | 自动认领旧合成资产或全图强前置 |
| U12 | 未读／未调用 | 普通任务开始前没有结果；预置轨迹明确实际读取与调用身份 | 目录可见或引用出现就算执行 |
| U13 | 仅本案贡献 | 保存本案候选及来源，不变企业正式指针，不自动启动维护 | 反馈按钮直接并入标准 |
| U14 | 新版与历史 | 发布r2后原报告仍r1/SAP1.0.0；新任务才发现r2/SAP1.1.0；输入与样本结果可解释 | 静默修改旧报告或运行中组合 |
| U15 | 归档只读 | 历史可读、候选保存及发布禁用；说明新获准任务可接续同一资产 | 自动解档或复活旧写权 |
| U16 | 引擎／加载失败 | 清楚标失败、准确身份及未输出结论；恢复只读查看，不编造成功 | 当作业务不符合 |

正常业务路径不要求先操作审核场景。Demo底部的折叠场景选择器仅为评审方便，切换明确重置页面内存；它不是产品用户新流程。实际Host权限、SDK执行、取消及版本正确性仍需未来工程证据，Demo不能证明。
