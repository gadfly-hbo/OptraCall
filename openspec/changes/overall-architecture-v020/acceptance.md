# 七模块及联合验收矩阵

版本：v0.2 · 2026-11-15。依据[spec](spec.md)及仓库外固定v1.1；补现有产品UI继承核对。下列是待实施后的验收要求，**当前全部产品验收 NOT_RUN**；准备材料检查另见implementation，不把测试计划写为通过。批准后工程实现的逐项事实及缺口见[实施验收记录](validation.md)；工程检查与用户产品验收继续分开。

每模块同时核：要求完整、原功能兼容、上下游接通。一次代码提交、局部单元测试、按钮存在或SDK多会话支持均不等于模块完成。公开样例只用合成/明确获准公开材料。

| A12 M3项目综合 | 指定Task读准确子成果，核分歧、交叉影响、重复归因、遗漏，用户直接回源 | 旧稿/新稿/未知范围分开；单Task不引用未参与Task的虚构成果；部分证据只作阶段成果；不以多会话或subagent工具存在判通过 |
| A13 M4报告版本 | 原owner/060绑定、Agent决定内容/时机/未指定文件名；同源同内容复用、实质修订另存 | 不覆原稿、不猜文件即完成；保存失败/可能已写UNKNOWN原样留存并准确回读 |
| A14 M4逐稿审查 | 审查绑定准确稿/材料/范围，意见获准接回原作者，作者自主核实，复查有独立状态 | 新稿不继承旧PASS或旧稿意见已接回状态；未审稿不能声称已有本稿意见；不同意见/未委派/未执行不算通过；无进展交限制不无限返修 |
| A15 M4原话代办 | 明确选择准确方案时记录原话/来源/版本，GSA引用Case及原看板，事实一次维护 | 无Case工作不能猜C-01或写其他Case；含糊表达集中澄清；只有策略选择不推经营授权；旧Case草案工具不冒充人的决定 |
| A16 M4事实权威 | 选择、行动授权、实际发生、效果验证各留证，跨Store部分成功准确回执 | 不重复写入选择/行动/反馈，不把用户采纳或写入成功当实际执行、因果效果；人最终经营取舍保留 |
| A17 M5提炼价值 | 真实固定来源/截止位置，已有方法完整沿用、实质改进修订、真正新建或无价值 | 参数变化不建新法；不造隐藏思维/未做检查；Agent判价值，Host只核技术重复 |
| A18 M5原治理 | SAP/IR未发布候选、正式发布/查读，Studio和记忆候选原路管理 | 发布保留明确决定和写权限；不建平行IR库；候选不冒充正式依据 |
| A19 M5纠错 | 报告回原Task、真实受影响候选/方法/资产/记忆分别处理，错误版停止默认推荐 | 区分当时错误和后来业务变化；记忆纠正/排除沿人的治理；失读/无权/未知具体待办，不全历史扫描 |
| A20 M5后续复用 | 新Task实际识别已知错误依据、读适用准确发布版并合理使用 | 固定旧引用不静默升级也不绕过已知错误；未发布纠正版不可正式替代；未真实使用保持待验证 |
| A21 M6全局同源 | 首次五节点全关、持久沿用；总控/分控/局部同值，部分开状态清晰 | 不逐Task重置或启动快照；A局部修改影响B尚未开始动作，不为提示反复确认 |
| A22 M6生效与停止 | 动作实际开始前读当前值及授权/适用性；关阻后续不杀在途，停止撤后续并真实收尾 | 开不补跑/唤醒历史；停止后不整理/提炼；失败关闭保busy/UNKNOWN，明确恢复不盲重放 |
| A23 M6职责和边界 | 交付保存/自查/所选必要检查不被节点关取消；手动原操作仍可用 | 开关不扩大权限/发布/预算；IR关资产开不变相回看提炼，原已发现问题反馈可保留 |
| A24 M6结束与去重 | 正常约定交付/明确结束整理后按当前值处理，回执简短准确；重复操作复用原结果 | 切页/沉默/断连/文件/单轮结束不独自触发完成；未完整理标限制，变化中会话不当最终来源；UNKNOWN先核实 |
| A25 M7导航过渡 | 一级市场取消，设置过渡准确跳转，仅移除场景组合及S01–S06展示 | 六项不换名搬迁/建任务；其他能力/规划/配置/历史不删、不变已实现 |
| A26 M7业务与管理 | 各原能力业务入口、低频设置、SAP/Studio专业归属和准确返回路径可达 | 不把PPT/运行配置全部塞Studio；不要求用户重新安装导入或重关联 |
| A27 M7授权和旧定位 | 缺配置/禁用/权限不足/失读可回原工作；旧定位准确对象版本并核当前权限 | 配置存在/可用/获准/启用/实际读取不混淆，导航不能扩大数据库/天气/商圈权限 |
| A28 M7最终退出 | v1.1 §6.2全部退出判据逐项有使用/管理/异常/历史证据 | 任一关键路径未接通保留过渡，不靠改名保市场，不以设置页或链接存在判完整退出 |

## 2. 联合场景

| ID | 合成输入/操作 | 联合预期及关键禁止副作用 |
| --- | --- | --- |
| J01 会员复购多维 | 目标复购/经营贡献，清单含交易/人群/商品/渠道/访谈/外部资料；开放维度、重点选择及多Task | 主目标→轻量方案→一次开始→真实方法→准确综合→审查→明确选择→原看板/目标引用；不预设缺货根因或业绩增长 |
| J02 单Task及轻量 | 同一Task足以综合；另做无Case简单查询及Studio建设 | 单多Task均完整；无强增会话/Case/全组织目标表/RAP发布；Project有效需求复用 |
| J03 分歧与重复解释 | 两Task对同客群下降各有解释，竞争因素跨分支、样本窗口不一 | 综合回源核共同原因/口径差别/重复贡献及遗漏，保留有据分歧，不简单相加原因或拼报告 |
| J04 资料不足/方法失效 | 首购历史缺失、方法必要前提不成立，另有独立可行分析 | 主动指明需何资料/期间字段/用途，限制受影响结论并推进独立部分；不伪前提、不把允许受限当事实满足 |
| J05 成果换版 | 稿v1已审，作者修v2；原选择仍指v1，材料也有修订 | 新稿审查范围独立，原选择/报告和口径历史不覆；关键变化只确认受影响经营取舍 |
| J06 跨Task开关 | A/B同时获准工作，A局部修改审查/IR节点，B相应动作尚未开始；另有在途动作 | B开始前采用新全局值，在途不强杀；无补跑/历史唤醒/立即提炼；唯一设置读回一致 |
| J07 停止与恢复 | 分析/审查/修订/收尾阶段停止、断连、重启；显式续接与浏览对照 | 原stop撤派发并等待匹配资源，停止不续跑；浏览/开关不启动；恢复先核原任务/稿/请求，旧资格不升权限 |
| J08 重复及UNKNOWN | 重复确认/保存/审查/提炼；服务回执丢失但可能已写；多Store部分成功 | 不重复Task/请求/文件/候选/行动，先读原请求和准确结果；不能换ID重试抹掉UNKNOWN或伪跨Store原子 |
| J09 IR与资产开关 | IR关资产开，已有方法问题；再明确手动提炼 | 自动只沿已发现问题反馈，不后置回看会话变相建/修方法；手动授权独立办理，候选/发布/使用分开 |
| J10 纠错后新Task | 关联交易重复执行错误 vs 方法缺检查；含已发布法、记忆与Case引用，另有后来业务规则变化 | 区分执行错/方法错/业务变化；只处理实际影响，人的记忆控制和原决定保留；新Task实际避错及适用版采用留证 |
| J11 市场退出与异常 | Skill/SAP/IR/连接器/RAP/看板/PPT/推演/模型包及旧链接；缺配置/失权/错版 | 不经市场完成业务，管理/异常返回原工作，原会话/版本/配置完整；退出前任何未通项仍待集成 |
| J12 兼容和四原则 | 旧Project/Task/native/Case/RAP/SAP及未来未知字段副本，公共入口原消费者+第三合成接入 | 旧字节/指针/发布/人的选择/FAIL保留；权限/配置变化/迟到结果正确，无平行Runtime/Host专业补算；必要人操作最少 |

## 3. 验证方法与结果分层

准备阶段：先实际查看现有运行产品并核构建身份，再从真实组件/CSS导出保留项，对照[UI基线](ui-baseline.md)核Demo的原界面及增量落点；同时做文档引用/条款覆盖/允许路径/范围审核、原型静态检查及实际浏览器桌面/窄屏关键交互。旧v0.1状态PASS不覆盖本次保真要求，原失败保留。准备检查无需安装产品依赖或运行全量产品测试；不制造产品RED。独立准备复核与最终实现复核分开。

| UI准备核对 | 必须可观察的证据 |
| --- | --- |
| UF01 原壳与主题 | 原品牌、侧栏/顶栏、项目Task树、分析决策/文件/帮助/明暗入口和实际响应式；不用七模块重建一级导航 |
| UF02 原Case和Project | Case-Star-Map/常规与详情、Project Map卡片/列表/详情实际切换，目标和方案在原位置增量加入 |
| UF03 原Task与审查 | 原四入口、对话/composer/模型/停止/背景、文件与右侧审查互换；新增综合在原结果区，稿件状态准确 |
| UF04 原管理与决策 | Studio三视图/SAP专业管理、原决策看板及设置原页签实际可达；不能只提示保留或返回新摘要页 |
| UF05 v1.1边界 | 市场仅按范围迁移、既有综合Task可复用、无Case/单Task/归档继续/逐稿意见/全局开关反例保持，无新增产品分期或确认配额 |
| UF06 固定来源 | CSS原样复用及来源/副本SHA一致，旧原件不覆盖，新版身份独立；合成资料离线内存，不连产品或使用真实记录 |

实施阶段：确定性要求先真实行为RED，最小GREEN；通过公开入口检查真实持久化/重开/失败/取消和禁止副作用，适用隔离真实Pi SDK及合成Provider/工具。模型质量不能伪造确定性断言，只有获准后另列试验条件与原始失败。广泛运行时/权限/持久化/共享接口变动按届时完整适用check及CI，不缩成只跑自写测试。

每项记录源码候选、输入/配置身份、方法/稿件版本、实际命令/退出码、证据路径、覆盖、结论和缺口。使用 `PASS / FAIL / NOT_RUN / UNKNOWN / NOT_PROVED` 及必要的部分完成描述；失败不被后次绿色重跑覆盖。

最新工程基线3ebaa01的记忆基础纳入A18–A20/J10/J12兼容：新旧候选准确读取、合法nested与UNKNOWN保存确认、经验直接来源治理提醒、被排除自由文本不泄漏、经验自身版本/治理独立、相关变更续页拒绝及有界提示、旧历史不回填。复用已存在机制，不重新建设；本轮正式改动影响到它们时才按实际映射执行适用回归。上游旧PASS不自动覆盖本轮实现。
