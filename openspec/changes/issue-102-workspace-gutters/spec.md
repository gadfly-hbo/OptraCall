# 工作台页面与侧栏的间距

[Issue #102](https://github.com/gadfly-hbo/OptraCall/issues/102)。正式版本 `577dff1` 中，从项目协作的「共用约定」打开「原方案与历史回执」，标题和空状态文字与侧栏分隔线的距离为 0。独立打开「方案比较与经营推演」和「预测模型与原注册表」也能复现。项目协作、目标管理和决策星图在宽、中、窄屏的对应间距为 28、20、16 CSS 像素。

## 验收

- 通过三个实际入口，验证正文与项目工作区按相同断点留白。历史页的加载、空状态和已有记录共用同一个内容容器。
- 长项目名和展开的历史回执保持在可用宽度内，内容较长时可以滚动到末尾。返回项目及进入原任务沿用已有控件。
- 设置里的业务模型包继续使用设置页自身的内边距。项目、Case、设置及主要导航页面保留原有内容位置。

## 实现边界

历史页沿用项目方案编辑器的页面容器与滚动规则。经营推演和模型注册表在主工作区独立挂载时复用与 Case 页相同的水平内边距。调整限于 Host 展示层，不涉及业务存储、会话、SDK 或新增用户操作。

## 核验结果

- 隔离 Chromium 从真实入口对照 `577dff1` 和修复版。1500、960、390 像素宽度下，三个入口的左距由 0 分别变为 28、20、16 像素。390 像素下，旧版长标题越界 162 像素，展开回执横向溢出 182 像素。修复版可完整换行，展开后仍可读回原请求。
- 非作者独立点验覆盖六个主导航页、项目协作、设置、帮助、PPT 精修与需求梳理。设置内嵌模型包与设置分类对齐。32 条合成历史回执中，展开连续 1400 字符的原文后，各档宽度都能滚动到最后一条并返回项目。
- 31 项相关回归、构建和会话边界检查均通过。浏览器复现与回归脚本见 [browser-workspace-gutters.mjs](../../../tests/browser-workspace-gutters.mjs)。
