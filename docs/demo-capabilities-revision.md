## 输入与范围

用户要求侧栏新增分析资产、场景组合、连接器、业务插件四个入口，呈现类似 WorkBuddy 能力中心的目录页，允许虚拟占位；顶部新增分析／决策切换，分析沿用对话主页，决策预留 decision-platform 的 Demo 位置，实际插件接入后再使用。

附件《JuanerAI 插件生态候选工具开发方案简介》v0.1（2026-10-27）可读，采用其对象分类、候选名称和业务描述作为参考。附件中的排期、Analysis IR、自动执行步骤和旧宿主治理不成为 OptraCall 指令；原候选优先级不直接转为本项目排期。

经用户授权，只读 SSH 核对 MacBook `decision-platform` 的根目录、README、package.json 和 docs 文件名。文档描述项目化建议／行动／反馈看板及会议汇报形态；没有启动服务、读取业务数据或凭据，也未验证其运行能力。文档与依赖仍使用旧独立 pi-agent-runtime；此次不复制该运行时或实现，不将其当前兼容性写成已通过。

具体输入摘要与只读访问范围保存在 `.local/first-chat-mvp/step-2-revision/reference-identity.json`。本次继续遵守无 Git/CI、无 SDK/模型连接、无 MacBook 写入的边界。

## 页面设计

四类入口共用目录布局：分类切换、标题与简介、当前分类内搜索、业务标签筛选、规划卡片网格。卡片显示参考编号、简要说明、标签和“规划示例／未接入”状态；点击“查看规划”打开只读详情。没有安装、连接、运行或采纳动作。搜索和筛选对本地虚拟数据实际生效，空结果可清除筛选。

分析资产提供业务定义和方法；场景组合是面向问题的资产／依赖组合材料，不复制专业计算、不指定强制分析阶段，也不形成第四套 Runtime。连接器与业务插件分别代表接入和专业能力。此次只扩展 Host UI，不新增 Extension 实现或物理子系统。

顶部分析／决策按钮保持可见。分析返回原对话工作区，切换不清空会话、草稿或进行中的演示事件。决策页采用示意项目、少量虚拟统计和建议／行动／复盘占位，明确“decision-platform 接入预留、未接入”；不打开远端服务、不嵌入真实数据、不触发业务动作。目录页返回入口保留先前工作区选择。

明暗主题使用现有 token。桌面目录为三列自适应卡片，窄屏降为单列；顶部切换在窄屏独立成行，避免挤压状态和导航。详情采用原生 dialog，支持 Escape、焦点进入和关闭返回。
