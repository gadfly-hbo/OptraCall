# 主分析与子复核：真实模型配对测试

2026-11-11。被测候选 `15f40455083c144a185bed4aef6715c7891085dd`，承接[五项工程基线](analysis-decision-workflow-baseline.md)。用户在工程交付后另行授权真实模型案例测试。本轮完成了冻结的小样本观察，**发现局部改善，也发现新增错误，不能据此认定模式稳定提高准确性**。

## 实际条件与对照含义

使用当前已保存的 MiniMax-M3.1-Flash / minimax-cn / anthropic-messages 配置，原生 thinking 为 high，官方 Pi SDK 1.4.0。普通 Host、统一会话入口和工具保持原能力；每次独立项目、任务及原生上下文。实际 wire maxTokens、compat 等未由公共记录完整暴露的参数保持 UNKNOWN，不以源码摘要冒充 wire 参数。

子复核角色沿当前产品使用固定文本，没有执行、文件或网络工具。

- **A：** 同一次正常父请求内，子复核前 Host 固定的完整主报告初稿。
- **B：** 同一次 RCR/FCR 子意见返回后，原主 Agent 自主查证、处置并实际交付的最终版本。
- 六个全新合成业务题，另预定重复 case02、case05 各一次，共 **8 个父请求、16 个计划阶段观察**。不是每组8个独立题或16次独立父模型请求。
- 这是“初稿→复核后”的配对观察。主 Agent 预知会复核，B含额外子调用及主 Agent 继续推理；没有独立随机、同总预算的主 Agent 最终稿对照，不能分离纯子 Agent 因果收益。
- 每次通过原需求入口由合成评估操作者确认、发布 RAP 1.0.0 并实际送入；不冒称运行过 RAF 需求生成模型或真实用户业务验收。子计算和框架覆盖复核共用一次委派；**未混入独立 CNR 结论审查或看板采用**。

六题覆盖跨期退款/去重、渠道品类加权、增量与边际ROI、会员窗口、重叠漏斗、利润与因果边界。案例作者封存70个数值目标及55条业务命题，另一非作者从源独立复算70/70一致；输入未改。评分前固定案例、容差、程序和模型身份；没有根据成绩换题、换模型或补跑。

## 子意见与主 Agent 处置

事后按冻结评分和仲裁逐条回读真实子原句、后续原生工具结果及最终报告。13组初稿重要问题中11组有明确子意见对应；这混合了自发业务解释、来源判断和数值问题，**不作为RCR统一检出率**。另有一处已提供的“翻倍”错误未被子 Agent 明确指出，但主 Agent 在最终稿删除；不能把所有最终改善都归给子意见。一处尾部问题未提供给子 Agent，不能记为其漏报。

有效处置包括纠正把局部区组数写成整体每单元平均的数字。子意见本身也会错：一处把210单预算结余错写为6300，主 Agent 实算为10800并拒绝该数值；一处把A10放入仅加购名单，主 Agent 按逐用户行为核对并驳回。

最终仍有两组重要问题：

1. case06的提价0.50可覆盖亏损建议仍不成立，210单条件下30天仍亏1050，所需单均贡献增量约0.6667。相关尾部没有完整提供给子 Agent。
2. case05预定重复新增错误统计解释。固定初稿的 Fisher 双侧 p=1.00 正确；子意见误把观测及镜像的两个中心点概率质量约0.65015当双侧精确p。主 Agent 后续虽复算得到1.00，最终稿仍将0.65写作另一种有效双侧口径；最终“不显著”方向相同并不能使此方法正确。

因此主 Agent 自主核实有实际收益，但并非每次都能挡住错误意见，也不能用子复核completed证明最终报告准确。

## 评分、分歧和结论限制

两位新上下文非作者按中性ID全文评分，16份原评分及报告SHA固定后再关联条件；第三位非作者对全部重要finding及关键语义/精度争议做独立补充，原评分不回写。7份有稿正文自揭初稿/最终/复核阶段，故不能声称完全盲评。

原始初评严格完整为0/8→2/8，仲裁主读为0/8→3/8。仲裁按整段正确贡献计算，将一处“销售不足覆盖广告费”判为语义省略；把明确位于建议节的收入双阈值主读为自设门槛，而非收入恒等式。若采用原严格字面读法，结果会不同。另有一份初稿对“执行/迁移收益”的完整描述性宽读可通过，但主读保留超出算术的执行排除及未决解释。显示舍入敏感性可使B严格完整达4/8，这不是主数；全部两侧读法均保留在仲裁补充中。

本轮支持的结论是：**这批初稿在一次子复核及主 Agent 后续处置后，报告重要问题总体减少；核心计算目标正确率没有提高，全文计算有改善也有退化，最终仍有重要错误。** 小样本、单一模型、非独立随机对照、额外推理预算、两次未交付和实际截断均限制外推。不升级为专业可靠性已解决、五项完整专业验收或经营采用结论。
