# Studio 二期使用说明

2026-11-12 · 产品实施候选 · 依据用户确认的 v0.3；实际验收见[执行清单](../openspec/changes/studio-phase2-unified-assets/tasks.md)和[实施记录](../openspec/changes/studio-phase2-unified-assets/implementation.md)。本说明不代表已更新正式服务。

## 提前建设企业基础资产

侧栏“语义与分析资产”统一进入 Studio。选择明确企业后，“企业基础资产”按资料、语义与主数据、数据映射、指标和方法查看原资产的准确版本及资格。原企业资料、SAP 指标和方法的专业编辑保留在同一入口内；原文、附件、来源、适用范围、版本、启停、IR 和发布仍由各自原主库保存。

点击“建设基础资产”，沿可写项目表达本轮要支持的问题、选择获准资料，即创建真实建设任务。名称与主题可按需调整；Pi Agent 在原会话自主盘点、精读、建设和检查，不依赖固定专家流水线。必要的业务取舍集中核定；准备准确版本的发布预览后，正式发布决定和各模块结果分别留证。保存候选、正式发布、项目采用、图刷新和实际使用是不同事实。

旧资料不会因打开某企业而被认领。展开“待核归属”可先只读查看准确原版，再决定是否关联；未决定可以返回。没有可核建议时直接显示缺口，不猜企业。跨企业冲突不静默移动资产。企业归属也不授予建设项目原始文件或其他会话权限。

## 从普通任务直接使用

从 Case／项目／任务直接提出分析问题，不必先打开 Studio 或逐资产勾选。明确企业的任务默认取得同企业合格正式目录及准确读取工具；目录只是线索，Pi 自主读取用途所需正文，检查企业、时间、粒度、前提和完整性，再选择原文件／bash／Python 等工具计算和检查。Host 不替 Agent 选择公式或计算业务结果。

“本次依据”区分目录供给、真实工具读取、完整或部分返回、作者采用声明和独立核验。没有记录时显示未知。实际工具结果与原任务、准确报告及版本保留；作者记录来源不等于专业验证。无足够依据的结论保留待核，其他独立工作可以继续；不会借旧图或全局目录恢复失效资格。

已有受管或封闭任务沿原 profile 的真实权限，普通只读 facet 不开放建设写入、受限 Case 或 M2 写入。未绑定 Case 时不猜目标，普通分析仍可继续；决策建议、人的采纳、行动及效果分别记录。

## 将任务发现演进为企业标准

普通分析中的结果错误先在原任务修正。需要共享的源资产缺陷、数据映射、方法增量或个案例外，可由获准 Agent 或回复旁的可选“反馈到资产体系”形成候选。Host 按真实原生会话／消息回读准确报告和实际读取依据；浏览器不能补造已读或已采用。

“建设与演进”保留来源任务、原报告身份、准确基础版本、范围、候选内容和处理。仅本案约定保留本任务；企业候选也需核对原基础及目标，关联准确候选后再经正式发布。来源或候选发生变化时拒绝沿用旧预览，不把“贡献已保存”当“问题已解决”。

原建设项目归档后保留只读历史。可“接续维护”到新的同企业获准任务，继续同一资产身份；不会自动解档原项目、复制正式体系或恢复原会话写权。

## 发布异常与历史

原专业发布需核准确草稿指纹；审核后变稿应重新校验，归档或跨企业冲突在写前拒绝。企业范围内首次指标发布在同一 Host 变更门内核归属并登记原指标身份，原内容权威保持不变。

UNKNOWN 表示原请求结果未知，先查原回执或准确目标，不盲目重发。原专业指标界面可“保留未知并离开”，在同一浏览器标签页恢复尝试元信息后只读核准确目标；暂存不含正文，也不是Host原发布回执，不承诺跨设备或关闭标签页后的恢复。“原主库目标存在”只能核定该目标的事实，不能证明原请求成功、当前企业可用或专业正确。历史报告保留原依据，新任务才按新的正式资格发现和精读新版。

## 后续门店会员主题

通用产品建设后，按以下顺序在产品内落地，当前工程合成资料不作为真实企业正式口径：

1. 核定目标企业及获准资料：会员身份与交易映射、门店、交易状态、退款关联、数据截止与完整历史；不足之处保留缺口。
2. 提前建设会员基础层：复用已核销售／退款资产和行业／领域候选参考，由 Agent 按本企业资料核定首购、复购、观察期及 SAP 指标／方法，完成人的必要业务决定后发布。
3. 在新的普通分析任务回答“哪些门店的首购会员复购偏低，值得优先核查？”，实际关联两主题，解释分子分母、观察完整性、排除项和限制；核查线索不冒充原因或措施效果。
4. 将一次实质修订按任务贡献、核查和正式发布并入基础层，再用新的独立普通任务实际读取并应用新版，保留旧报告和原正确依据。

真实模型自主性、该企业专业正确性及用户产品验收分别核定，不由工程测试或合成预览替代。
