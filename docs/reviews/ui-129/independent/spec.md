# OptraCall 前端视觉与布局改版规格说明书（独立设计方案 · Issue #129）

> **设计定位**：独立设计 Agent（Antigravity）方案，提交至评审 Issue `#129`，供 PM 与 PM v0.2 逐项对照并整合最终确认版
> **基线仓库**：`gadfly-hbo/OptraCall`（分支 `main`）
> **实际设计基线完整 SHA**：`7ef6ebb81b735ffecdad3753217a96f02cb95c76`（含 `#127`）
> **方案方向**：静谧层叠工作台（Layered Precision Workspace）—— 沿用 OptraCall 原版双圆 Logo、favicon 与 `#6550c9` 主紫，建立清晰的前景/背景层级与去耦语义色，统一 10 个正式页面的排版节奏、信息密度与窄屏抽屉交互。

## 1. 范围、约束、基线差异与打开方式

### 1.1 本轮范围（仅视觉与布局）
- **视觉令牌统一**：配色层级细节、深浅双主题、字体与字阶、4px 间距体系、圆角与轻阴影、组件态（悬停/激活/聚焦/禁用）。
- **布局与信息密度优化**：统一页头结构、标签栏样式、卡片弹性高度、抽屉/弹窗层次，压缩高密度工作区（尤其是「分析任务」「设置」「战略/目标」）的冗余垂直堆叠。
- **响应式容器升级**：重构窄屏（`≤760px`）侧栏与中屏（`≤1100px`）右侧面板的呈现方式，消除内容挤压与横向溢出。

### 1.2 强制保留与不做事项（Hard Constraints）
1. **沿用原版品牌资产与对话署名**：完整保留 OptraCall 原版双圆嵌套 Logo（`src/host/ui/BrandMark.tsx`、`src/host/ui/favicon.svg`）及原紫色主色（浅色 `#6550c9` / 深色 `#b7a7ff`）；各对话入口严格沿用现行署名行规范（`src/host/ui/conversation-collapse.tsx` `AgentAuthor`）：**原双圆 Logo + `OptraCall` + 对应会话配置的模型名**（流式状态沿用原规则）。
2. **保留全部既有模块与入口**：不增删主导航项，不合并或隐藏现有 9 个设置分类，不改变顶栏「分析 / 决策」工作区切换、项目三目录约定（`010_draw`、`020_clean`、`060_reports`）或帮助/主题入口。
3. **不改动业务关系与流程**：不改动任何后端 API、SQLite/JSONL 持久结构、Host–Agent 接缝（Interface v3 / IN01–IN07）、Pi SDK 依赖与运行时行为；不新增强制人工确认步骤或替人决策逻辑。
4. **评审交付隔离**：本轮交付仅限于评审分支 `review/ui-129-independent` 下 `docs/reviews/ui-129/independent/` 的文档、虚构数据独立原型及公开实测截图；产品源码与 `main` 保持原样。

### 1.3 实际设计基线与 PM v0.2 基线（`2f79a34`）差异核对
- **本方案设计基线**：`7ef6ebb81b735ffecdad3753217a96f02cb95c76`（`修复默认分析 Skill、工具诊断及会员包准确版本授权 (#127)`）

### 2.2 排版、间距、圆角与组件规范
- **字体栈**：沿用系统无衬线栈（`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif`）；版本号、文件路径（`010_draw` / `020_clean` / `060_reports`）、SHA-256 指纹及资产 ID 一律使用等宽字体（`.mono` / `.mono-pill`）；所有统计数字、计数、日期使用 `font-variant-numeric: tabular-nums`。
- **统一字阶**：页眉 Eyebrow `11px/600`、页标题 `H1` `22px/650`（窄屏 `19px`）、卡片标题 `H2` `15px/620`、子节标题 `H3` `14px/600`、正文 `13.5–14px/1.6–1.75`、辅助元数据 `12px`、徽章 `11px`。
- **间距与圆角**：统一 4px 网格（页内边距桌面 `24px 28px` / 窄屏 `16px 14px`，卡片内边距 `18px 20px`，栅格间距 `14–16px`）；圆角收敛为三档：控件/标签 `6px`、卡片/面板 `10px`、对话框/消息输入框 `14px`、状态胶囊 `999px`。
- **统一组件态**：全站收敛按钮为 4 种语义层级（`btn-primary` 主紫填充、`btn-secondary` 白底描边、`btn-danger` 柔红危险、`btn-ghost` 无框文本）；全部页内一级标签统一使用带底部 `2px` 主紫指示条的 `.underline-tabs`，次级模式切换统一使用胶囊分段器 `.seg-switch`。

## 3. 覆盖页面与逐页布局变化

本方案覆盖正式产品全部 **10 个页面**及**全局应用壳层**：

### 0. 全局壳层（侧栏 + 顶栏）
- **保留**：BrandMark + `OptraCall / 持续做出更好的决策`、`+ 新建项目`、可折叠「主导航」（6 项）、可折叠「项目空间」与「已归档项目」树、底部「设置」+ 配置状态点 + `中/EN` 占位；顶栏侧栏开关、当前标题、「分析 | 决策」工作区切换、项目文件开关、帮助、深浅色切换。
- **视觉与布局变化**：
  - 侧栏宽度定为 `252px`，选中主导航增加左侧 `3px` 主紫竖条 + 柔紫底，层次更清晰；项目行快捷「＋」按钮弱化默认透明度，悬停显露减少噪点。
  - 顶栏固定高度 `54px`、纯白底 + 底部细线分隔，页面内容区在微紫画布上清晰区分。
  - 窄屏（`≤760px`）侧栏改为**左滑浮层抽屉 + 半透明遮罩**，彻底替代现版「上下堆叠占 45dvh」的布局。

### 1. 战略选择（`战略选择`）
- **保留**：战略事项选择器、适用范围选择器、新建/编辑事项、`战略复盘 · 占位` / `战略重构 · 占位`、四标签（`战略共创` / `战略检验` / `战略发布` / `版本管理`）及 `BSC／战略目标关系（按需）`、`树形地图 / 条目表` 切换与 `带入目标管理` 交接弹窗。
- **视觉与布局变化**：
  - 将原零散内联 `.si-topbar` 收敛为带白色底板的**上下文工具条**（`.strategy-bar`），事项与范围选择器归左，占位入口移至页头次级操作区，避免单行拥挤。
  - `战略共创` 采用 `1fr / 310px` 桌面双栏，右侧 Sticky 资料夹与左侧开题/方案比较解耦。
  - `战略检验` 将因果/逻辑两道门禁改用清晰的步骤序号卡 + 语义绿通过徽章（不再与主紫混用）。
  - `战略发布` 以视觉化树形地图卡片突出可承接目标与 SAP 指标，主操作 `带入目标管理 →` 位于卡片右上主视觉焦点。

### 2. 目标管理（`目标管理`）
- **保留**：四标签（`目标与策略` / `核对与采用` / `年度决策事项` / `版本与反馈`）、目标列表、准确版本查看、战略来源回溯、G/S 变更对照、候选采纳、新建候选、创建 Case / 开始项目入口。
- **视觉与布局变化**：
  - 当从「战略发布」带入目标候选时，顶部呈现柔和紫底**交接提示横幅**并直达 `核对与采用` 标签，标签自带待核计数角标。
  - 上方为紧凑型可扫描目标总表（点击行即时切换下方详情卡），消除过长的垂直滚动。
  - `核对与采用` 使用双栏对照盒（左：原已采纳版本，右：微紫高亮本次待核候选 G & S），降低人工核对负担。

### 3. 决策星图（`决策星图`）
- **保留**：统计条、搜索/关系筛选、`星图 / 常规` 切换、`方块 / 列表` 切换、星图缩放/聚焦/节点直达、底部键盘与窄屏等价列表、Case 详情四分区抽屉（`当前工作与决策记录` / `关联项目` / `产物` / `历史`）及 `打开原任务 / 按此 Case 继续`。
- **视觉与布局变化**：
  - 星图画布增加极浅点阵背景，节点顶部按类型着色（紫 = Case、蓝 = 项目、绿 = 分析任务），一眼区分三层实体。
  - 缩放控制栏悬浮固定在画布右下角，不占用画布顶部空间。
  - 常规方块模式取消现版 `height: 360px` 僵硬定高，改为内容自适应弹性卡片，避免长判断被截断或短卡片大片留白。
  - Case 详情抽屉首屏置顶「当前关联分析任务」高亮横幅，一键返回原分析任务或按此 Case 继续。

### 4. 项目地图（`项目地图`）
- **保留**：搜索/归档筛选、`方块 / 列表` 切换、项目工作状态/承接人/工作范围/下一步、项目内任务列表、关联 Case 数、项目详情抽屉及归档/恢复入口。
- **视觉与布局变化**：
  - 取消现版 `min-height: 420px` 七行定高 Grid，改为柔和阴影自适应卡片，并将「分析任务」升级为整行可点击动作条（直接标明 `打开原任务 ↗` / `运行中 ↗`），同时卡片内保留 `关联 Case ↗` 直达链接。

### 5. 语义资产（`语义资产`）
- **保留**：当前企业选择器、新增企业、四标签（`业务语义` / `数据映射` / `企业资料` / `体系工作台`）、搜索栏、准确资产列表、只读原文来源抽屉、`待核归属` 折叠区。
- **视觉与布局变化**：
  - 页头右侧统一放置「当前企业」选择器与「切至分析资产」快捷跳转，两类资产视觉语法完全同源。
  - 资产列表升级为清爽表格卡：资产名 + 等宽 ID、等宽版本胶囊、语义色资格徽章（正式生效 = 绿，候选待核 = 琥珀），右侧明确「查看准确资产」抽屉入口。

### 6. 分析资产（`分析资产`）
- **保留**：当前企业选择器、三标签（`分析指标` / `分析方法` / `体系工作台`）、搜索栏、准确版本表格、只读来源抽屉、`体系工作台` 三子视图（`覆盖与缺口` / `建设与演进` / `发布与使用`）。
- **视觉与布局变化**：
  - 与「语义资产」共享同一页头、标签与表格密度规范；`体系工作台` 顶部加入 3 栏资产状态 KPI 摘要卡，直观呈现正式发布项、待核候选与关联项目数。

### 7. 设置（`设置`）
- **保留**：全部 **9 个现有分类**（`使用用途`、`个人资料`、`模型设置`、`网络检索`、`自动模式`、`Skill 资料与依赖`、`连接配置`、`业务模型包`、`领域资产包`）及 `← 返回原页面`。
- **视觉与布局变化**：
  - **桌面端（`>960px`）**：将现版 9 项水平溢出长标签栏重构为**左侧 `216px` 纵向分类导航轨**，按三组轻标题视觉分组（基础与模型 / 能力与连接 / 资料与资产包），全部 9 项一屏可见、零滚动遮挡；右侧表单区限宽 `780px`，阅读与填写更舒适。
  - **窄屏（`≤960px`）**：自动转为横向单行可滑胶囊栏，保持 9 分类一键切换。

### 8. 分析任务（`分析任务`）
- **保留**：4 步导航（`资料准备` / `需求梳理` / `分析对话` / `结果与审查`）、任务对话记录与过程折叠、消息输入框、模型切换、关联 Case / 需求上下文、右侧项目文件（`010_draw` / `020_clean` / `060_reports`）、报告计算依据与审查结论。
- **视觉与布局变化**：
  - 将 4 步工作条从 70px 高大方块压缩为紧凑单行横向步骤轨（窄屏 2×2），首屏对话可视高度提升约 25%–30%。
  - 对话区采用居中 `820px` 卡片流，区分用户微紫洗色消息卡与 Agent 白底卡；含已保存报告的回复直接内嵌「已保存正式报告条」，一键打开右侧「报告与依据」或跳转「关联 Case」。
  - 将右侧栏整合为统一三标签检视抽屉（`项目文件` / `报告与依据` / `审查结论`），`356px` 固定并排（`≤1100px` 切换为右滑浮层），使「项目 → 原任务 → 已保存报告与依据 → 关联 Case」全链路在同一视野自然衔接。
