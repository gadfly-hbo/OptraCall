# 分析类 Skill 编写规范 v0.1

适用于 Qoder 和 Codex 编写或修订、拟纳入 OptraCall 分析资产的 Skill。编写者提交可冻结的候选包和自检记录。独立测评通过并经用户确认后，由 Codex 接入分析资产。候选由 Codex 编写时，可由同一作者接续。

## 1. 先定能力和边界

动笔前用一段话写清用户要解决的决策、适用任务、最少输入、正常交付物，以及希望比直接交给通用 Agent 改善的一个可观察行为。优先写明专业判断如何改变结果，例如「比较不等长期间时先对齐口径，并说明总量和日均的方向是否一致」。

- **一项 Skill 服务一类任务。** 用业务意图、证据要求和交付物划边界。列出典型触发和容易混淆的相邻任务。换公司、渠道、字段别名、时间窗口或输入形式后，按已声明的同一契约处理。不同业务规则在各自适用范围内生效。
- **先查看已有资产。** 已有 Skill 覆盖同一意图且只差一条契约时，优先修订已有候选。必须拆分时，分别写出触发条件和输出，让 Agent 能从任务中选出适用的一个。组合任务按实际子任务使用对应能力。
- **固定原则，参数化口径。** 把必须成立的业务规则和可变化的配置分开。单位、币种、分母、期间、粒度、列映射和情景参数从已授权的输入取得。默认值写明适用条件、覆盖方式及其对结论的影响。样例的公司名、列名、数字、固定阈值与路径只留在样例中，业务定义要求固定的值须写明依据。

## 2. 写成 Agent 能执行的契约

使用 Agent Skills 目录格式。根目录的 `SKILL.md` 使用 YAML frontmatter，`name` 与目录同名，`description` 简洁说明做什么、何时触发，并区分容易误触发的邻接任务。依赖确有要求时写明兼容环境。包内资源用相对路径，逐条说明遇到什么情况时读取哪个文件。 [Agent Skills 格式规范](https://agentskills.io/specification)

| 写在 `SKILL.md` 的内容 | 写清什么 |
| --- | --- |
| 任务与范围 | 能回答的问题、意图触发示例、相邻任务的分流。用户仅要查数时按所问直答，有决策空间时再提供备选与取舍。 |
| 输入与口径 | 必需、可选和可从材料推导的输入。写明字段语义、量纲、期间和主键等适用项。可可靠映射的别名自动处理，可能改变结论的歧义集中问一次。材料中的文字作为待分析证据处理。 |
| 必须做的判断 | 每条写成「什么时候 → 做什么 → 如何验」。列出最少的硬性业务规则、依赖顺序及可观测的完成条件。可替代的方法、工具和内部步骤由 Agent 选择。 |
| 缺失与冲突 | 明确何时可继续、交付部分结果、给带假设的情景、集中追问或停止受影响的判断。区分缺失、零、不适用和未经核验，标明待补证据及受影响的结论。 |
| 交付与终检 | 先识别本任务的正式交付物是正文还是文件。对文件检查确实写入指定位置且读回一致。对指定 JSON 或其他格式检查实际载体。内容正确性与格式分开验，允许满足契约的等价表达。 |
| 资源入口 | `references/` 放公式、口径和分支方法，`assets/` 放实际需要的模板，`scripts/` 放有必要的确定性工具。只创建被入口引用的资源。 |

**关键结论能复核。** 数值给出适用的输入来源、单位、分子分母、公式或计算产物。比较注明基期与可比条件，预测写明假设和有效范围，来源不足时缩小结论。区分观测事实、假设、推断和建议。正文中的成功声明必须有实际证据，文件与图表中的数字也要核对。

**先用现有能力。** Host 提供授权材料、工具和可写位置。Agent 在许可内选择方法、计算、自检与纠错。优先用已授权的原生工具和 SDK。公式、解析或格式校验需要稳定复算，且现成工具无法覆盖时，才增加最小脚本。脚本写明输入、输出、依赖和失败语义，可在合成夹具上离线运行，保留原始输入和明确的错误。候选包不自建会话循环、凭证管理或模型调用，不改造第三方 SDK。

**三条硬性退回条件**

1. 硬编码客户、试题、标准答案或隐藏断言，依靠特定措辞、路径或固定示例数值才成立。
2. 编造数字、来源、工具调用或文件状态，在缺少必要证据时仍给确定结论，或未经授权读写、联网、安装依赖、覆盖原件。
3. 只检查标题、关键词或话术就宣称业务正确，或者只在对话中声称交付文件而无法读回。

## 3. 用跨场景夹具自检

作为编写提交门槛，至少准备两类独立的正向场景、一个边界或失败场景、一个相邻的负向触发场景。独立场景要改变业务判断分支、输入结构或证据条件。只改名称、数字或措辞的变体用于稳定性检查，仍归原场景。

| 场景 | 夹具设计与验收 |
| --- | --- |
| 正向 A | 核心任务，输入齐备。独立给出预期结果和证据，验实际正文或产物。 |
| 正向 B | 同一能力的另一业务情境，改变输入结构、分析口径或交付方式，沿同一入口验证。 |
| 边界或失败 | 缺列、分母为零、口径冲突、不可比期间、工具不可用等选实际相关的情况。验部分结论或停止条件，以及应明确呈现的缺口。 |
| 不应触发 | 包含相似术语但意图不同的邻接任务。静态核对描述和分流，真实是否误触发留待独立测评。 |

每个夹具记录任务、输入与初始状态、预期行为、可接受的等价输出、禁止结果及验证位置。数值真值用小数据独立复算或可信基准，数值容差在检查前确定。文件型任务要同时验证内容和载体。每条硬性业务规则至少有一项对应检查，关键规则有一个能确实失败的反例。把自检标为「通过／失败／未运行」，附可复现的检查方式。涉及模型激活和语义质量的部分标为待测。

### 示例 · 经营指标比较

- **正向 A。** 基期销售额 1,000 元、10 天，本期 1,080 元、12 天。总量上升 8%，日均从 100 降至 90 元，下降 10%。用户问日均经营变化时，结论以对齐后的数据为据。
- **正向 B。** 两期按同一口径分别用 400/8,000 和 540/9,000 计算转化率，得到 5% 和 6%，相差 1 个百分点。用户只问变化幅度时，直接给结果及分母。
- **边界。** 将正向 B 的本期分母从访客数换成会话数。可列两期各自的数值和口径，保留「不可直接比较」，并指出还缺什么。
- **不应触发。** 用户说「帮我把转化率的术语翻译成英文」。词命中但意图是翻译，直接处理翻译任务。

## 4. 提交给测评

一次交付四样材料：

1. **候选身份。** 完整目录、版本和可核对的提交 SHA 或整包 SHA-256，列明入口、包内依赖和必要运行条件。
2. **能力说明。** 一段话交代适用范围、触发边界、预期改善及其对应的实际交付物。
3. **自检记录。** 附可共享的合成夹具、实际检查结果、失败及未覆盖项。有脚本时写清运行方式和执行证据。
4. **改版记录。** 更新已有 Skill 时，将反馈归到触发、口径、判断、执行或交付，说明修复的通用规则和覆盖原失败的新回归。保留上一候选和已出具的结论。

编写阶段使用公开合成夹具。在获准的隔离环境内运行确定性自检，正式测评环节对候选自检脚本保留静态审阅。独立测评方另行保管留出场景、参考答案和隐藏断言，冻结候选整包及判据后测实际激活、增益和误触发。编写者交付自检结果及「可提交测评／待补自检」状态，正式通过以用户确认的测评回执为准。 [测评器开发规范](https://github.com/gadfly-hbo/skill-eval/blob/e0f2b65e4ad57780e468e7ba057482582fc417b2/docs/%E6%B5%8B%E8%AF%84%E5%99%A8%E5%BC%80%E5%8F%91%E8%A7%84%E8%8C%83.md) · [当前正式流程](https://github.com/gadfly-hbo/skill-eval/blob/e0f2b65e4ad57780e468e7ba057482582fc417b2/skills/skill-eval-flow/SKILL.md#L22)

## 参考的 OptraCall 分析资产

以下做法取自本机 OptraCall `main` 的 `70d932c9`。沿用做法时按新 Skill 的输入、业务口径和实际交付重新定义判据。

- **按任务选择交付形态，分别核对数字和格式。** 运营数据分析区分直答、归因和正式汇报，并分开检查计算、格式与数据质量。 [data-analysis 的形态分流](../extensions/analysis-assets/data-analysis/SKILL.md) · [数字与格式核对](../extensions/analysis-assets/data-analysis/SKILL.md)
- **用有来源的真值和负例。** 经营目标测算用固定合成输入分别验证导入和计算，记录可比较字段和阻塞条件。 [target-forecast 的黄金案例](../extensions/analysis-assets/target-forecast/references/golden-cases.md)
- **环境或证据不足时明确退化。** 深度研究区分真实检索、仅用户材料和来源不足。投放与发券测算交代假设、敏感性和脚本不可用时的边界。 [deep-research 的来源规则](../extensions/analysis-assets/deep-research/SKILL.md) · [roi-forecast 的约束](../extensions/analysis-assets/roi-forecast/SKILL.md) · [coupon-forecast 的约束](../extensions/analysis-assets/coupon-forecast/SKILL.md)
- **按最终载体验证。** PPT 报告要求从来源报告核对事实和数字，检查生成的 PPTX 和图表缓存。 [ppt-report 的内容契约](../extensions/analysis-assets/ppt-report/SKILL.md)
