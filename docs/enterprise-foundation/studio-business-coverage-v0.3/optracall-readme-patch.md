## 候选方法说明片段

```markdown
在原Studio内以“36格全景”作为首个主要页签，默认展示完整六行六列，每格有固定坐标、具体含义及可点击入口。首批建议关注14格高亮，其余22格仍可看含义、关联参考及本轮边界。不重点建设、不适用、缺资料和未调查分别表达，框架全貌不是填满门槛。

资料、片段、三类资产与格子是多对多关系。逐格只显示实际有该坐标及依据的条目，可从准确来源版本反查对应格，不按整列跳到同一片段。同一来源多格时，全局资料数按准确SourceRef／版本只计一次；资产修订与方法输入独立列数，不把资料份数、格数或局部数量相加。

资料中的同名、多版本或不同范围说法先回源比较，不自动认定冲突或限制正式源。定义参考、数据计算和规则执行按各自用途核依赖；纯概念无需被强制绑定实际字段。治理身份、四项作者状态及独立使用证据并列保留。
```
