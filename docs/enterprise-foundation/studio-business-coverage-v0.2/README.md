## 这版新增和沿用什么

拟新增的是现有business资产body中的可选派生盘点报告格式，以及其只读覆盖／证据／问题投影。报告是原资产修订，不设第四业务主库、覆盖率引擎或当前报告全局指针。

沿用原三类资产、两层、两条参考路线，原资料及SAP、来源／发布／工作项、普通catalog/read-source/reason及历史。未标坐标、无报告或关注格没填满都不阻断原分析。坐标不赋予资格，疑似冲突不直接停用正式源。

## 建议审核路径

先看方案与D1，核是否认可六问＋证据的默认阅读方式；再点击Demo的范围／证据、多版本核查、无报告普通分析及历史；最后看spec BC02报告载体与BC07–09权限／使用／历史，按清单决定是否批准具体包。需要修改时仅修本审核版，不改原稿。

全部Demo为合成预置、页面内存，无产品API、SDK／模型或实际业务动作。文稿和原型准备通过不证明产品已实现、目标企业正确或真实模型专业通过。旧专业FAIL／UNKNOWN按原记录保留。
