## 1. 本批目标和组织方式

形成同一家企业可被合格 Case／项目／任务共同使用的经营语义基础，重点支持会员运营。基础层先定义共享对象、度量结构、关系和规则，完成范围以企业证据及可用资料核定，后续再选择实际分析任务验证。

两条参考路线继续使用：

- 运动鞋服行业 → Nike 企业公开参考 → 目标企业共享经营骨架。
- 会员运营领域 → Nike 会员运营业务域公开参考 → 目标企业会员运营核心。

每条路线同时建设**主数据模型与字典、数据分析指标体系、本体**，并建立三者关联。两条路线中的门店、商品、账号、会员关系和交易共用身份与定义；Nike 的公开做法用于对照，目标企业政策以其获准资料为依据。

企业基础层是第一层；普通任务中新发现的资料、政策变化或共享缺陷，经任务演进层贡献、核定和修订后并回基础层。四份参考模板作为输入，不增加一个企业正式层。

本批主数据建设交付对象模型、字典、键及身份映射规则、数据质量要求。主记录的实际来源和维护责任一并说明；完整 MDM 主记录治理平台、跨系统自动合并和分发不在本批范围。

### 范围深度

**本批核心**：B01–B07 的共享结构，以及 B08 的实际机制识别、核心概念与测量需求。B04 支撑经营与会员共同理解交易，沿用销售退款经验逐项重核企业规则。B08 若企业实际没有相关机制，记录不适用；机制未知时记录待核，不能写成不存在。

**按实际经营及优先级纳入的扩展**：等级、积分、券、付费会员、订阅、活动、内容、服务等具体制度及事件；留存、迁移、权益效果等需要明确观察期的度量。先确认企业是否存在、哪些优先，再决定细化及计算范围。会员偏好／许可信息只在所选用途需要且属于获准资料范围时使用。

**本批暂不展开**：完整供应链、设计制造、全量库存与财务核算、完整客户终身价值模型、全企业组织图谱。成本／毛利、库存等已有模型或指标可登记复用线索；只有本批所选用途确实依赖时补齐相应资料和口径，独立可推进内容继续。

## 3. 三类资产如何关联及落到产品

每个实际纳入项均有稳定身份、定义、范围、来源及业务有效时间；记录参考项到企业项的采用／修改／排除／新增及依据。主数据对象、事件、指标所需维度与资格规则、本体关系、实际字段映射之间建立可追溯关联。

指标体系同时交付主题／指标族目录、指标间关系及数据需求。准确指标定义、公式和方法仍存放在原 SAP；体系索引和本体引用包 ID、准确版本、指标名及必要场景／方法版本。企业 SAP 项未建立前保留候选身份，避免虚构正式引用或复制一份可独立修改的公式。

实际建设使用已交付的 Studio：企业业务资料作为来源依据，主数据／本体等内容沿原资产保存，指标和方法在原 SAP 专业区维护，由 Studio 统一组织、检查和发布。当前无须为这批建设再立一轮产品重构。

后续在用户资料到位并确认启动后，由建设 Agent 在实际 Studio 任务中并行内化三类资产，逐步形成 Binding 和检查依据；文档只承担范围、决定和证据入口。Host 管归属、权限、会话、持久化及回执；Agent 自主选择已有工具、核对资料和业务含义。人工集中处理范围、资料不能决定的真实业务问题，以及必要发布和验收决定。

普通用户继续在 Case／项目／任务中提出分析或决策需求。Pi Agent 根据企业归属和用途自主查找、按需读取正式原文、准确 SAP 项及限制，选择方法并计算、解释；目录命中、引用出现和实际读取应用分别留证。普通分析无需先进入 Studio 逐项勾选资产，也不要求先维护或查询图。Semantica 的图按需要投影或查询，不能取代原资产权威。

| D06 会员身份与资格 | 账号、会员计划、成员关系、资格状态及变更；已有合规身份映射／跨系统关联规则及样本 | 主体类型、键、关联依据、适用范围和有效期；关联不明、重复、多账号、退出／重入等已知情况；无需提供与所选用途无关的身份明文 |
| D07 交易及会员关联 | 订单头／明细、支付、退货、退款，以及关联会员／账号／计划关系的小样本和说明；实际不存在的事件类型另作说明 | 跨表关联键、事件粒度、状态、时间与时区、金额币种及单位、税费／折扣／分摊、撤销冲销及修订；尽量覆盖所选规则的正常与例外记录 |
| D08 实际参与／权益机制 | 纳入本批的活动、参与、权益资格／发放／领取／使用／失效资料；对应字典、规则和可关联样本 | 事件身份、合格对象／机会、资格与有效期、状态变化、触点和主体关联；未选机制暂不提供 |

提供脱敏样本时，跨表标识应保持一致关联、原粒度和时间先后关系。若进行了改写，附简短说明即可。每批尽量说明来源及版本、提取截止时间、覆盖期间、是否完整及已知缺漏；已有说明可直接复用。

### C 批：支持选定指标的实际计算和独立核验

确定哪些指标本轮要达到可计算后，再按其数据条件补足相应历史、合格总体和对照资料，包括身份／资格有效历史、交易及退款完整性、迟到修订、参与或权益的合格机会，以及已有可信报表或控制总额。

需要的回看期和观察期由核定后的指标决定，不统一要求“近一年”或全历史。例如历史不足时，可以先核定当前资格或当期有效事件，受影响的跨期指标维持不可计算／未验证，并说明截断限制。小样本用于映射和规则核查，不能替代总体覆盖或证明业务结论。

**最先提供的最小包**：D01 范围说明＋已有 D02 会员制度／业务说明＋一份 D03 当前报表或指标说明＋已有 D04 系统字段说明。有 D05–D07 的关联小样本可同时给；缺少其中某项时，先据实际资料确定可推进部分及精确缺口。D08 和 C 批按纳入机制和计算目标后补。

第二家企业的跨企业验证继续作为后续独立阶段：复用本批流程和方法骨架，根据第二家获准资料重新核定范围、规则、映射及正式身份，不默认继承第一家政策。
