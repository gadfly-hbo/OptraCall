# 企业基础层三类资产 v0.2 可点击审核原型

2026-11-12 · 待用户审核 · 暂不产品开发

入口：[index.html](index.html)。可直接用浏览器打开，也可从仓库根目录启动只读静态文件服务器查看。文件均为独立审核原型，不依赖产品 API 或现有 Host 服务。

## 原型边界

- 全部企业、资料、样本、请求、报告及检查结果均为虚构和预置演示。
- 状态仅保留在本页面内存，刷新恢复；不调用模型、计算工具、正式发布、图构建、业务动作或产品 API。
- “成功（演示）”只代表原型分支，不能作为工程、真实模型或专业业务验收。
- Nike 参考详情区分公开事实、建模建议和未知；没有任何真实个人或企业记录。
- 原 Studio 中性界面、紫色操作及浅／深色 tokens 沿原 v0.3 原型复用；当前目录没有修改旧版。

## 建议点击路径

1. **企业基础资产 → 体系总览**：查看主数据、指标体系、本体与数据映射的关联，再打开“会员关系”“原 SAP 指标”等详情。
2. **参考与内化**：查看行业／企业和领域／部门两条路线、四组参考及采用／修改／排除／新增依据。
3. **建设基础资产**：填写自然语言建设目标、默认执行项目及资料范围，进入预置建设任务；可以取消。当前不会真实启动模型。
4. **建设与演进 → 查看／编辑候选**：编辑规则源稿并保存，准确正文及范围保留在本页。旧检查与预览失效。任意自定义稿保持待业务核验，不能凭点击预置检查通过；可保留该稿，或显式另存受控样例，再查看仅适用于受控样例的预置核查。
5. **准确发布预览**：可取消，或“模拟候选在预览后变化”验证失效分支；确认只生成原型分模块结果。
6. **普通分析任务**：查看目录、正文、作者声明与独立核验四种事实；创建新独立任务看到当前合格版本，历史报告保持 1.0.0。
7. **反馈到资产体系**：保存企业共享或仅本案贡献，回到演进查看；只有企业候选可以关联准确候选，并仍待核查、发布及新任务使用。

## 评审情景

页面底部折叠“评审情景（仅供审核）”可切换：

| 情景 | 应观察到的结果 |
| --- | --- |
| 正常建设与发布 | 准确预览、分项结果、后续任务新版本、原任务与报告不换版 |
| 空白企业 | 明确空态及建设入口，不自动认领其他企业资料 |
| 资料缺失 | 缺资格截止字段，不输出计数；可限定发布核定定义 |
| 来源冲突 | 会员资格部分受限，独立门店定义可单独预览 |
| 归档任务只读 | 旧任务禁止保存／发布，新获准维护任务可接续同一资产身份 |
| 发布 UNKNOWN | 确认演示发布后 SAP 分项未知；只读查询同一请求，仍未知，不能盲重发 |
| 发布分项失败 | SAP 明确失败与其他模块成功分列，相关新版用途受限，原合格组合继续 |
| 普通任务部分读取 | 资格规则正文只有一个片段；续读预置片段后，独立核验仍未执行 |
| 准确来源读取失败 | 保留准确 SAP 版本和失败状态；只读重查仍失败，不换 latest、不冒充已读 |
| 仅本案贡献 | 可保存本案候选，不可直接并入企业基础层 |

切换情景会明确重置为对应受控样例，清除本页自定义候选、演示预览与分项结果；不用于处置真实稿件。企业 A／B 切换仅改变可见范围，A 的已留结果保持，B 不显示或继承 A 的资产、报告和发布回执。弹窗 Escape／关闭、未保存返回继续／放弃、键盘焦点与窄屏均属于审核范围。

## 实例含义

准确引用为 `demo-member-foundation@1.0.0::active_memberships`（有效会员关系数），与 `md.program_membership`、资格规则、本体和 Mapping 关联。候选 1.1.0 的“正常＋宽限 → 仅正常”是明确标识的受控政策变化，不把旧规则故意做错；原报告始终保留 r1／1.0.0。

指标定义与公式只在原 SAP 只读专业详情展示，体系索引没有第二套公式编辑器。定义核定、数据映射、可计算、实际使用验证四项独立，点击发布不提升计算或实际验证状态。图表示保持可选。
