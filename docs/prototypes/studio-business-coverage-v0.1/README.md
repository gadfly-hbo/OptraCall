## 设计与边界

- 在原 Studio 企业基础资产页内增加按需查看，沿既有中性白／暗、紫色主动作、侧栏和页签；单一推荐方案，无新顶级平台。
- 全部企业、范围、原文、指纹、版本、状态、工具轨迹及答复均为合成预置。所有更改只在当前页面内存，刷新清空。
- 无产品API、网络数据、模型／SDK调用、真实读取、建企业／项目、发布、贡献或业务写回。页面的“发送／生成／核查／记录／发布”仅演示交互，不是实际回执。
- 现有 business 类型资产body中的可选 reportProfile: "studio-coverage/1" 是**待审契约**。不向原 foundation/1、foundation/2、FoundationItem、SAP0.2 或 SourceRef 增加字段，不新建坐标库。
- 坐标可多值或未标注；默认14格只是关注集，全部36格都可查看。调整关注集只改变当前查看筛选，不修改已存报告或发布资格。
- 候选报告由建设侧查看，普通任务只可能读取合格正式报告。没有报告、只有候选、方法不可读或未标坐标，都不阻断独立可用的原分析。
- 作者四项状态、治理身份和独立使用证据分列；报告或格子数量不形成完成率／健康分。
- 新版盘点报告不替换业务规则或SAP版本；旧报告R01固定r1依据。三类资产和原权威继续承担含义、公式及来源。
- 原稿、旧方案／spec／原型不改。原型不直接进入产品代码。

## 建议审核路径

1. **范围与资料**：看首批“运动鞋服共享经营骨架＋会员运营核心”及六问。点“查看片段”，检查准确定位、多坐标、候选／正式、四项作者状态及独立核验。
2. 打开 What：本样例明确没有储值业务，因此储值账户“不适用”；其理由可见。打开 Who：存在未标坐标的待核观察，不要求先归类。
3. 展开**高级查看**，点“调整查看关注集”。选择R4或R6等默认14格之外的坐标；这只是查看，不能影响资产或发布。
4. **联合核查**：对照合法渠道／期间版本；再看同范围断言疑点。记录演示工作项W01，确认没有自动mark-issue、撤回或政策选择。
5. 打开**映射用途**：定义参考无需每项Binding；数据计算用途确有必需依赖时，缺映射准确显示受限。
6. **普通任务**：直接发送演示问题，查看预置答复和原catalog／准确读取／reason轨迹。无需预先选坐标；工具轨迹不是Host固定执行顺序。
7. 打开原报告R01；生成盘点候选r2后，普通新任务仍只读取正式r1。沿原发布入口模拟发布**报告**r2，再发送新任务可见r2；R01仍r1，规则仍r1、SAP仍1.0.0。
8. 在页底**评审情景**依次切换无报告、仅候选、方法不可读、依据已变、缺映射、同范围争议、搜索无结果、读取中／失败、损坏／未知格式、报告含候选输入。候选输入情景不能确认发布，不得借报告扩大来源资格。
9. 切换亮暗主题，窄屏390px查看，Tab进入对话框，Esc关闭并回到原触发控件。表格在自身容器滚动，不要求全页横向滚动。

## 准备中发现及修正

早期原型把报告可用性绑定在评审情景上，生成r2时重置情景可能让“无报告／过期r1”被错误恢复为当前正式参考。现已把正式报告存在性、当前资格和候选输入资格分别保留：生成候选不创建正式指针、不恢复旧来源资格；未核输入不能借报告发布。正常已有合格r1时可继续使用，新候选r2不自动替代它。该发现仅涉及本合成原型，未改产品。

### F2 扩展复验与完整状态修订

前述18项初核没有覆盖format／unsupported／error／loading经候选生成的共同分支。非作者随后复现格式损坏后生成候选会错误恢复r1供给；初次问题与该扩展失败均保留，前次局部修复不视为全面关闭。

最终修订统一使用独立 formalReadStatus（ready／missing／stale／corrupt／unsupported／error／loading）、候选读取／输入资格和方法读取状态。评审情景只初始化业务状态；生成候选只新增候选及切换当前查看，不修改正式指针或正式读取资格。transport error/loading仅可经显式读取成功恢复；损坏、未知、失效和方法失权不能借重试、候选或隐式成功恢复。新合格发布是另一项明确原发布动作，不能洗白未获资格的输入。

作者以真实界面事件处理函数驱动静态内存检查：13个preset逐一比较候选生成前后普通消费，并检查禁止恢复、新合格发布及R01固定依据，共152条断言通过。该结果不替代随后固定字节上的浏览器、布局或独立复核。

### F3 容器宽度修订

root浏览器在688px观察到默认grid子项的min-content宽度让表格撑宽整页。修订为split/grid直接子项允许收缩、表格滚动容器限于父宽、panel头与动作组换行；没有对body设置隐藏溢出来掩盖。实际688px／390px浏览器回核由root接续，原观察保留。
