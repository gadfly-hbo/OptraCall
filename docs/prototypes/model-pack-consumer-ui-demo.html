失败与边界（如实呈现，不静默）

验货不过＝结构化原因＋不入库；执行失败＝信封回传 Agent 自主纠错；受管任务不注入。

验货门拒绝（导入时）

任一检查不过＝拒绝导入，dataRoot 无半成品，源目录不动。

{
  "ok": false,
  "stage": "purity_scan",
  "reason": "predict.mjs 含禁止调用: require('fs')",
  "hint": "模型包须零依赖纯计算；请在 MPS 重新训练导出"
}

检查顺序：结构/formatVersion → manifest 字段 → 纯度重扫 → 沙箱冒烟。

predict 执行失败（对话中）

信封回传 Agent，由其自主换版本、修输入或如实报告；Host 不代跑、不重试。

{
  "ok": false,
  "model": "member-churn v1",
  "reason": "输入缺少 usage.inputs 声明列: last_login_days",
  "rows_received": 812
}

沙箱不可用＝fail closed 拒绝执行并如实报告，不回落无沙箱运行。

启用边界

modelTools 默认关；两处开启入口（新建任务对话框＋会话内 Pi 能力面板，仅空闲可切换）。

受管 ordinary / protected 任务：不注入
fixed-draft / text-only 资源：不注入
未开启任务：Agent 如实声明不用模型

对齐商圈/天气连接器既有语义；无平行 Runtime、无 SDK 绕过。

快照损坏（人为破坏 dataRoot）

注册表哈希与快照不符＝标记损坏＋引导重新导入，不静默修复。

{
  "name": "order-forecast",
  "version": 1,
  "state": "corrupted",
  "detail": "sha256 与注册记录不一致",
  "action": "请从 MPS 导出目录重新导入该版本"
}

旧版本永久保留可追溯；重装同版本字节一致＝幂等通过。

导入模型包

选择 MPS 导出的包目录（含 predict.mjs / manifest.json / README.md）。校验通过后拷入 dataRoot/models/ 固化快照，源目录随后可删。

仅接受含合法 manifest.json（formatVersion=1）的目录；不读取路径下其他内容。
✓结构与 formatVersion 校验
✓manifest 字段合法性
✓纯度重扫（禁 fs/网络/eval/随机/时钟）
✓沙箱冒烟（node --permission 跑一行）
✓拷入快照＋注册表登记（Staging）
