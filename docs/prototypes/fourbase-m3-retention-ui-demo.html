附件边界：本页未模拟仅附件、无文字正文的既有资料。正式方案沿原合同，已有精确修订有可读正文或原附件即可；不自动OCR。这里人工新建／整理没有附件输入，因此需标题与正文，不把此要求泛化到已有资料。

未模拟：真实身份校验、磁盘写入、跨进程并发、重开持久恢复、存储限额与真实权限。原入口均为本页虚构阅读面板，不代表已经接通产品。没有可信度评分、自动摘要、自动注入或新会话。
