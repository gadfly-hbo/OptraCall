# 报告结构与终检

## 报告模板

```markdown
# {报告标题}

| 项 | 内容 |
| --- | --- |
| 日期 | {YYYY-MM-DD} |
| 研究课题 | {课题关键词} |
| 执行模式 | 完整 / 快速 / 单章 |
| 引用来源 | 共 {N} 个独立来源 |

---

## 目录

{目录条目}

---

## 引言

{300–500 字，带引用；开篇锚定课题重要性，预告 2–3 个核心发现}

---

## 1. {章节1标题}

{章节正文}

---

## 2. {章节2标题}

{章节正文}

---

## 结论

{300–500 字，带引用；综合跨章洞察，回答引言提出的问题，给未来方向}

---

## 参考文献

{去重排序后的来源列表}

---

## 待完善事项（有审稿遗留或来源缺口时保留）

- **第 X 章 {标题}**：经 3 轮审核仍存在 {问题}，建议 {处理方式}
- **来源缺口**：{未覆盖的方面及原因}

---

> 本报告由 AI 深度研究生成（{模式}模式{，快速模式未经独立审稿}）。重要决策请经专业人员核验；所有引用来源请在关键场景下二次核验时效性与真实性。回执来源 ≠ 内容已核实。
```

规则：章节编号连续不跳号；各主要部分用 `---` 分隔；单章模式省略目录/引言/结论，参考文献从本章引用直接抽取；快速模式免责声明中注明"未经审稿"。

## 引言与结论的写法

- 引言：1–2 句锚定课题背景与重要性 → 研究范围（对应大纲）→ 2–3 个核心发现预告；**至少 2–3 处引用**。忌"在当今世界…"式空洞开场、忌只罗列章节名。
- 结论：跨章综合判断 + 3–5 条关键发现（每条 1–2 句）+ 未来研究方向；关键结论仍带引用。忌复制各章小结原文、忌脱离来源的主观断言；章间数据矛盾如实指出，不强行统一。

## 终检清单（组装后逐项过）

| 检查 | 动作 |
| --- | --- |
| 标题层级 | 报告 `#`、章节 `##`、小节 `###` |
| 章节编号 | 连续不跳号 |
| 超链接 | `[文本](URL)` 格式完整闭合；无裸 URL |
| 引用一致性 | 正文引用风格统一 `([标题](URL))`；URL 均出自回执或用户材料 |
| 参考文献 | 去重（同 URL/同标题合并）、排序、条目完整（标题/年份/机构/链接） |
| 来源计数 | 元信息表中来源数与实际一致 |
| 事实/观点 | 措辞区分贯穿全文；无无来源关键事实 |
| 语言一致 | 全文与用户提问语言一致（专有名词除外） |
| 冗余清理 | 无连续多空行、重复段落、残留草稿标记 |
| 待完善事项 | 审稿遗留与来源缺口如实汇总；没有则删除该节 |
| 免责声明 | 结尾保留，快速模式注明未经审稿 |

## 落盘

- 过程笔记（参数卡、来源池、章节草稿、审稿往返）→ 项目 `020_clean`；
- 最终报告（Markdown）→ 项目 `060_reports`，文件名含课题简称与日期（如 `ai-agent-enterprise-research-2026-11-04.md`）。
