# 审稿标准与修订原则

独立审稿优先委派 `deep-research/reviewer`（隔离上下文）。本文件同时供你自审或按意见修订时使用。

## 6 维审查标准

| 维度 | 检查什么 |
| --- | --- |
| 来源充分性 | 独立来源 ≥5、类型 ≥3；引用为 `[标题](URL)` 且 URL 出自回执或提供材料；无无来源的关键事实 |
| 事实准确性 | 事实均有来源；无逻辑矛盾；数字量级合理；年份/地域无错配 |
| 观点均衡性 | 多元观点并陈；无单一来源偏见；反方与争议已覆盖 |
| 内容深度 | 有具体数据、案例、分析；不停留在泛化描述 |
| 结构清晰度 | 论点→论据→分析→小结；无跑题；与章节任务一致 |
| 格式规范性 | 引用格式、标题层级、表格统一规范 |

## 硬性退回条件（任一 → REVISE）

1. 独立来源少于 3 个（来源雷同按不足处理）；
2. 无来源的**关键**事实性陈述（数字、断言、结论）；
3. 明显事实错误或逻辑矛盾；
4. 内容严重偏离章节任务。

## 轮次规则（最多 3 轮）

- 每次委派 reviewer 显式给出 `current_round = N / 3`；
- 第 1 轮全量审查；第 2 轮只核上轮"必须修改"是否解决 + 新引入的严重问题；第 3 轮**强制 PASS**，未解决问题转入"遗留改进建议"；
- 连续 2 轮退回仍不通过 → 第 3 轮强制通过 + 报告"待完善事项"记录"本章经 3 轮审核仍存在 {问题}"；
- 审稿结论以 reviewer 回传为准，不由你代写或美化。

## 修订原则（你或再委派 researcher 执行）

1. **逐条回应**：每条"必须修改"都要解决，或说明不改的理由；
2. **补强而非重写**：在原稿基础上补充改进，审稿未批评的部分保持不动；
3. **补充来源必须真实**：从来源池或新检索补充；找不到真实来源就保留"未检索到公开可核数据"，不编造；
4. **完整交复审**：复审输入 = 新稿全文 + 上轮意见 + 修订说明（逐条对照）；
5. 无法完成的意见（如要求的数据不存在）：在修订说明中如实标注，交由你判断是否接受。

## 审稿陷阱（自查）

- 苛求完美：反复退回格式微调——基本合格即过；
- 强加立场：因观点不同而退回——论据充分且标注来源即合格；
- 空泛反馈："深度不够"不给具体位置——意见必须落到段落/论点；
- 忽略轮次：第 3 轮仍在 REVISE——违反轮次规则。
