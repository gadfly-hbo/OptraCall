# 来源标准与引用规范

## 检索证据的唯一次源

真实检索发生的标志是消息中出现**"本次联网检索来源（供应商回执）"**块。进入报告的来源 URL 只能来自：

1. 供应商回执块中的 URL；
2. 用户提供的材料（注明"用户提供"）。

正文自述的链接、先验记忆中的 URL 一律不算检索证据。没有回执就没有检索——不得写"根据检索结果"。原生检索由 Provider 侧 `web_search` 承担，是否调用、调用几次由你按目标自主决定；检索失败或结果不足时如实说明，不编造补位。

## 来源优先级

学术论文 / 预印本 > 官方机构与政府报告 > 知名咨询与研究机构 > 主流新闻媒体 > 行业博客与自媒体（仅辅助，不作关键论据）。

同一路径下优先：一手数据 > 二手转述；官方原文 > 媒体转引；带方法说明 > 无方法说明。

## 数量与质量目标（自检口径，非凑数门禁）

| 层级 | 目标 | 达不到时 |
| --- | --- | --- |
| 单章 | ≥5 个独立来源，≥3 种类型 | 在该章"缺口声明/审稿"中如实披露，判断是否影响结论 |
| 整份报告 | ≥20 个不同来源 | 报告"待完善事项"中披露 |

数量服务于交叉验证：同一事实有两个独立来源支撑才写为"事实"；只有单一来源时降格为"单一来源称"。

## 时效窗口

| 窗口 | 适用 |
| --- | --- |
| 近 6 个月 | 快速变化领域（前沿 AI、监管动态） |
| 近 1 年 | 技术类课题默认 |
| 近 2 年 | 行业趋势、市场分析默认 |
| 近 5 年 | 学术综述、长期趋势 |
| 不限 | 历史性研究、基础理论 |

窗口外来源仅用于历史对比与背景，须标注年份并说明是否仍有效；历史性对比数据不受窗口限制。

## 引用格式

正文：

```markdown
根据 McKinsey 2026 年报告 ([The State of AI](https://example.com/report))，企业级 AI 采纳率达到 72%。

多项研究表明增长存在地区差异 ([研究A](https://example.com/a), [研究B](https://example.com/b))。
```

- 事实（"数据显示""研究表明"）与观点（"有观点认为""业内看法"）措辞明确区分；
- 每条关键数据注明时点与口径；
- 来源间矛盾如实并列（"A 报告为 X，B 报告为 Y，差异可能源于口径不同"），不强行统一、不择优隐匿。

参考文献列表（报告末尾，去重后按类型或字母排序）：

```markdown
- 标题, 年份, 作者/机构 [来源链接](URL)
```

## 禁止行为

- 不带来源的关键事实性陈述；
- 编造 URL、论文标题、机构数据；
- 仅凭单一来源下重要结论；
- 将博客/自媒体内容作为关键论据；
- 预设立场或选择性引用（只引支持预设结论的来源）。
