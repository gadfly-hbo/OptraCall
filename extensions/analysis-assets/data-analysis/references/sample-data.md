# 合成示例数据与复算步骤

全部数字为合成数据，可直接试用本 skill；文中每个结论旁给出对应复算命令与实际输出要点（运行目录：本 skill 的 `scripts/`）。

## 一、场景与口径

- 场景：某连锁 6 家门店（直营 3 + 加盟 3）2026-02（基期，28 天）与 2026-03（本期，31 天）月度经营。
- 口径：销售额＝成交笔数×客单价（元，含税，未扣退货）；客流＝到店人次；**人均消费＝销售额÷客流**（本例无客单价口径混淆——表内直接给出成交笔数与客单价）。
- 样本量：12 条门店月记录（<30，结论仅供参考）。

## 三、复算步骤（命令 + 实际结果）

### 1. 期间判等长 → 不等长，须按天对齐

```bash
python3 scripts/calc.py period --base-start 2026-02-01 --base-end 2026-02-28 \
  --cur-start 2026-03-01 --cur-end 2026-03-31
```
结果：base_days 28、cur_days 31、equal_length **false**、day_ratio **110.71%**——两期总量不可直比。

### 2. 全渠道总量 vs 日均 → 方向相反

```bash
python3 scripts/calc.py compare --label 全渠道销售额 --base 609500 --current 612950 --base-days 28 --cur-days 31
```
结果：总量 **+0.57%**（+3,450）；日均 **21767.86 → 19772.58，−9.17%**（−1995.28/天）。日历效应本身解释 10.71% 量级——**总量微增、日均实降**，这是期间不等长最容易写反的结论。

### 3. 单店拆解（直营03：总量 −5.00%）

```bash
python3 scripts/calc.py decompose --metric 直营03销售额 --base "成交笔数:1400,客单价:90" --current "成交笔数:1260,客单价:95"
```
结果（剥离顺序：成交笔数→客单价）：总变动 **−6,300**＝笔数效应 **−12,600**（(1260−1400)×90）＋客单价效应 **+6,300**（1260×(95−90)）；闭合差额 0.00。客流拖累被客单价补回一半。

对照（直营01，总量 +6.25%）：`decompose --base "成交笔数:2100,客单价:80" --current "成交笔数:2100,客单价:85"` → +10,500 全部来自客单价（笔数效应 0）。

### 4. 平均的平均 → 分组客单价汇总

```bash
python3 scripts/calc.py weighted --groups "直营01:80:2100,直营02:80:1750,直营03:90:1400,加盟A:70:1050,加盟B:75:800,加盟C:70:600"
```
结果（基期，按成交笔数加权）：算术平均 **77.50** ≠ 加权平均 **79.16**（差 −1.66）。分母＝总成交笔数 7,700。

### 5. 异常检测 → 普跌背景下的"增长"才是离群点

```bash
python3 scripts/calc.py outlier --values "-5,-10,-10,5,-10,-5" --method iqr
```
结果（6 店客流变动%）：Q1 −10.00、Q3 −5.00、IQR 5.00，界 [−17.50, 2.50]；唯一离群＝**加盟A 的 +5.00%（越上界）**。3σ 法因 n=6<30 被拒绝——小样本只能用 IQR，如实写明。

## 四、脏数据对照集（dirty，供体检演示）

```csv
门店,月份,客流,转化率
直营01,2026-01,4200,0.12
直营01,2026-01,4200,0.12
直营01,2026-03,3990,12
合计,2026-01,8400,0.12
```

`python3 scripts/quality_check.py --data dirty.csv --key 门店,月份` → **FAIL（3 error / 1 warning）**：

| 检查 | 结果 |
| --- | --- |
| DA1 完全重复行 | **命中**：第3行与第2行完全重复 |
| DA2 主键重复 | **命中**：['直营01','2026-01'] 重复 |
| DA3 月份缺口 | **命中**：直营01 缺 2026-02（按主体分组） |
| DA4 率列混口径 | **命中**：转化率同时存在 <1 与 >1（0-1 与百分数混用，疑似分母漂移） |
| DA5 合计行 | 未命中（本表数值不吻合；合计行示例见下） |

合计行示例（DA5 命中形态）：

```csv
门店,月份,销售额
直营01,2026-01,1000
直营02,2026-01,2000
合计,2026-01,3000
```
→ `--data 合计表.csv --key 门店,月份` 报 DA5：第4行(合计) 的 销售额 ≈ 其余行之和，疑似合计行（分析前剔除或单列）。
