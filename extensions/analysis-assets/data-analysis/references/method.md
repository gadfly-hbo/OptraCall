# 方法库

本文件是公式与选型参考；计算一律经 `scripts/calc.py` 执行，不手工近似。

## 一、描述统计

- 均值 `Σx÷n`、中位数（奇数取中、偶数取两中平均）、众数；离散用样本标准差 `s = √(Σ(x−x̄)²÷(n−1))` 与 IQR（Q3−Q1）。
- 选型：对称分布看均值±标准差；偏态或含极端值看中位数+IQR。报告须写明用了哪个及为什么。

## 二、两期对比与期间对齐

- 变化率 `Δ% = (本期−基期)÷基期`；基期为 0 时不可定义（脚本拒绝，改用绝对差）。
- **期间不等长先判后比**：天数比 = 本期天数÷基期天数。日均对齐 `日均 = 期间总量÷天数` 后再比。日历效应本身可解释的量级要先说清（如本期只有基期 90.3% 天数，观测到 −9% 的总量降幅几乎全由日历造成），再谈经营原因。
- 天数比例表述必须算完再写（`1 − 53.6% = 46.4%`），不留近似号给读者。

## 三、异常检测

| 方法 | 适用 | 规则 | 门槛 |
| --- | --- | --- | --- |
| 3σ | 近似正态 | \|z\| > 3，`z = (x−x̄)÷s` | 样本量 ≥ 30，否则拒绝并改 IQR |
| IQR | 偏态/小样本 | 越界 `[Q1−1.5×IQR, Q3+1.5×IQR]` | 样本量 ≥ 3 |

- IQR 四分位用 Tukey 法：奇数样本时整体中位数不进入两半。
- 输出必须含：异常值、偏离度、所用方法与参数；IQR 在分布集中（IQR=0）时边界收缩属正常行为，如实呈现。
- 异常值处置：先区分「录入错误」（核实后修正）与「真实业务波动」（保留并分析），不得直接删除。

## 四、指标拆解（顺序剥离法）

乘法指标 `M = f1×f2×…×fn`，按给定顺序依次剥离，第 k 个因子的效应：

```
effect_k = (c_k − b_k) × Π(前序因子本期值) × Π(后序因子基期值)
```

- **构造性精确闭合**：Σeffect_k = 本期总量 − 基期总量，恒等成立（望远镜求和），无需事后配平；脚本仍校验（差额>0.01 退出码 3）。
- **顺序敏感**：先剥离者承担交叉项，顺序不同结果不同；报告必须写明剥离顺序及理由（通常按可控性或业务关注顺序）。
- 加法指标（含减项，减项传负值）：effect_k = c_k − b_k，同样精确闭合。
- 解读：效应占比 = effect ÷ 总变动；总变动接近 0 时占比无意义（脚本不输出）。

## 五、加权与「平均的平均」

组样本数不等时，均值之组的算术平均 ≠ 总体均值；总体均值 = Σ(组均值×组样本数) ÷ Σ组样本数。报告分组汇总一律用加权值并写明分母。

## 六、趋势

最小二乘 `slope = Sxy÷Sxx`，R² = Sxy²÷(Sxx×Syy)。窗口 ≥3。**判读纪律**：R² ≥ 0.7 才可称「方向性明显」；低于阈值只可描述波动，不得宣称趋势。

## 七、相关性

皮尔逊 r（线性）/ 斯皮尔曼 ρ（单调、抗极端值）；\|r\| > 0.7 才值得进一步查。任何相关结论必须带「未做因果检验」声明。

## 八、四类数据工程陷阱 · 检测动作

| 陷阱 | 检测动作 | 工具 |
| --- | --- | --- |
| 连接爆炸 | JOIN 前后各数一遍行数；放大即连接关系有误 | 取数侧人工核对（体检不覆盖 JOIN） |
| 期间不完整 | 天数判等长；同/环比＋「至今/进行中」词触发报告红线 R1 | `calc.py period`、`quality_check.py --report` |
| 平均的平均 | 算术平均 vs 加权平均并排给出差值 | `calc.py weighted` |
| 分母漂移 | 率列同表内 0–1 与 >1 混用即报警；两期分母定义须文字确认 | `quality_check.py --data` DA4＋口径确认 |
