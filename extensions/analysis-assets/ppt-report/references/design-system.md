# OptraCall PPT 版式系统

面向经营分析汇报的固定主版式：一套专业主题 + 页型模板。不追求模板数量，追求一致性与克制。所有代码遵循本文件的取值，不自由发挥。

## 画布

- 尺寸 **13.33 × 7.5 英寸**（16:9 宽屏）。python-pptx：`prs.slide_width = Inches(13.333)`、`prs.slide_height = Inches(7.5)`。
- 精修改既有 deck 时先读 `p:sldSz` 对齐，单页重生成必须同尺寸。
- 页边距：左右 0.8"，上下 0.6"；内容安全区即正文布局边界。

## 色彩系统（严格取值）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| navy | `263442` | 深藏青：封面/封底背景、页眉标题文字、主图形 |
| accent | `B44626` | 铁锈橘：小面积点睛（关键数字、强调条、结论条左边线），**单页 ≤3 处** |
| paper | `F7F6F3` | 暖灰纸感：内容页背景 |
| panel | `FFFFFF` | 白色面板：卡片、数据块底 |
| line | `DEDCD6` | 边框线、分隔线、坐标轴线 |
| ink | `242830` | 正文主文字 |
| muted | `626773` | 次要说明、元数据、脚注、轴标签 |

规则：纯色无渐变、无动画；强调色不得大面积铺底；浅底正文用 ink/navy，深底用白/#D6DDE4。

## 字体与字号

- 中文：`PingFang SC`（macOS）/ `Microsoft YaHei`（Windows），英文数字：`Arial`。python-pptx 需同时设置 latin 与 eastAsia 字体（见 python-pptx-guide 陷阱节）。
- 正文与图注**不用粗体**；粗体只用于标题与关键数字。

| 元素 | 字号(pt) |
| --- | --- |
| 封面主标题 | 40–54 |
| 内容页 headline | 24–30 |
| 章节页标题 | 32–40 |
| 副标题/小节标题 | 16–20 |
| 正文/要点 | 14–16 |
| 图注/来源/页码 | 10–12（不得低于 10） |
| KPI 关键数字 | 36–60 |

层级要求：标题与正文字号差 ≥1.5 倍；同页相邻文字块字号差 ≥20%。

## 页型模板

每页属于且仅属于一种页型。内容页 headline 一律为**结论句**。

### 封面（cover）
navy 满版背景。eyebrow（10–12pt，`D6DDE4`，字距放大，如「01 / 项目定位」）→ 主标题（白，40–54pt，居中偏上）→ accent 短强调条（宽 0.9"，高 0.04"）→ 副标题（`D6DDE4`，16–18pt）。大留白是设计，不是缺陷。

### 目录（toc）
paper 背景。页眉（eyebrow + headline「目录」+ 细分隔线）。3–6 个条目：accent 编号（01/02…）+ 条目标题（16–20pt ink），条目间 0.35–0.5" 等距；可加一行 muted 描述（≤1 行）。

### 章节页（section divider）
navy 或 paper 背景二选一，全 deck 统一。章节编号（accent，大号 48–72pt）+ 章节标题（24–36pt）+ 可选一行 muted 引语。大留白容忍。

### 内容页 · 文本（text）
paper 背景。页眉同目录。要点列表：navy 小方块引导（0.08"）+ 正文 14–16pt，行距 1.4，每页 ≤6 条；关键结论可放底部白卡 + accent 左边线。

### 内容页 · KPI
页眉 + 2–4 张白色圆角卡片（圆角 0.08"）：大数字（36–60pt navy；最关键 1 个用 accent）+ 指标名（muted 11–13pt）。卡片间距 0.3–0.4"。

### 内容页 · 图表（chart）
页眉 + 柱/折线图（主色 navy，对照/异常用 accent，单图 ≤2 色）+ 坐标轴线 line + 轴标签 muted ≥10pt + 底部结论条（白卡 + accent 左边线，一句话）。图表必须有解读句；数据标签缺失图例时补 muted 图例。

### 内容页 · 对比（comparison）
页眉 + 2 张并排白卡：卡头小标签（navy/accent 胶囊）+ 要点列表。对比维度对齐，不混排。

### 结尾（summary/end）
navy 背景。核心建议 1–3 条（白字，编号 accent）+ 一行 muted 来源说明（对应 md 报告名）。

## 密度与留白

- 每页一个视觉焦点；要点 ≤6；KPI 卡 ≤4；图表系列 ≤2。
- 内容页留白率目标 ≥30%；不要把版面塞满。
- 页码：内容页右下（10pt muted，`NN / 总页数`）；封面/封底不加。
- 同一 deck 页型风格统一；相邻内容页可换布局（文本/KPI/图表/对比交替），不换色系。
