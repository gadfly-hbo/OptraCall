# 目标测算黄金案例

期望值由 target-forecast 原仓实现（业务基线 `df5acd6`，引擎 forecast-engine-1.1 + pandas）在固定合成输入上计算生成；`ingest.py selftest` 与 `forecast.py selftest` 逐项对照（数值容差 1e-9——去 pandas 化的纯 Python 求和次序差异远小于该容差；blocker 消息要求逐字一致）。

## 1. 引擎黄金（engine-expected.json）

确定性合成输入（无随机）：

- 18 个月（2025-01 ~ 2026-06）× 2 平台：天猫（模式A形态，无 UV）与私域（模式B形态，含 UV 线性增长）；
- 月度指标按线性趋势构造（新客 120+2i、老客 300+3i、客单 150+i / 200+i、复购 1.2+0.01i），GMV = 新老客公式派生；
- 货维度结构 5 行（上衣爆款/腰部、裤装腰部、连衣裙尾部、外套新品）；
- caliber 用原仓 config.yaml 默认（基线 12 月、目标 12 月、梯队 0.78/0.20、新品 90 天、平台内排）；
- 情景 = 原仓三档（保守/基准/挑战，人五杠杆+场三杠杆+梯队增速）。

覆盖校验点：两平台 baseline（加权均值/月均/年化标记/UV 启用）、季节占比、人/场/货三视角 12 月投影、主口径选择（天猫=人、私域=场）、全渠道汇总 36 行（3 情景×12 月，客单/转化率分子分母重算、无 UV 列规则）、平台年度（目标 vs 基期年化与增速）、确定性（同输入两次运行逐字节一致）。

## 2. 导入黄金（ingest-expected.json）

手构订单明细 6 行（覆盖：同订单跨品类两行、跨月复购、滚动窗口外回归记新客、多件数）：

- 明细 → 订单级 → 新老客（365 天窗口，U2 隔 402 天回归记新客）→ 月度统一指标 4 个月；
- 货维度结构：基期窗口（12 月）过滤后 2 行（裤装/爆款、配饰/新品——新品按首次售卖 ≤90 天判定）；
- 聚合表 2 行 → 模式B统一指标（GMV 人公式派生、新客订单数缺省、UV 透传）；
- 4 类 blocker 消息逐字对照（重复月份定位行号、非正金额含净额口径说明、订单身份冲突列出全部行号、日期不可解析）。
