# 轻量方案比较（Decision Analysis 用法）

> 本文件同时是**回本与期间换算权威算式在本 skill 内的唯一维护处**（见文末）；入口 SKILL 与模板不再重复展开。

## 权威算式（本 skill 内唯一维护处）

**简单回收期门槛与达标判定**：

- **公式**（口径：简单回收期，且无另计新增固定成本）：**月增量贡献额门槛 ＝ 本情景总投入 ÷ 目标回收月数**；**月新增销售额门槛 ＝ 月增量贡献额门槛 ÷ 同口径的有效增量贡献率**。贡献率缺失则销售额门槛保留未知；贡献率非正（≤0）时该式不能推出可行的正销售额门槛，如实说明。
- 试点投入已经按试点范围计算时，**直接用该投入计算试点门槛**；若需要将结果外推到扩围范围，**单列扩围情景**，用该情景自己的投入、期间和贡献率重算。
- **达标判定用同一口径**：用实际或预计的**同范围、同期间月增量贡献额**对**月增量贡献额门槛**，或用**月新增销售额**对**月新增销售额门槛**——不用门槛对租金、变动成本等其他口径。租金、变动成本按其口径进入投入或贡献测算，**同一成本只计一次**；整段试行的累计贡献额先按可核验的期间口径换算，再与月度门槛比较。
- 缺关键输入或换算依据时，保留未知并**暂不判定达标**。

**期间换算（日均↔月度）**：按同一对象范围内的**实际营业日数或可核验期间明细**换算，写明换算依据与结果单位；两者皆缺 → 换算结果保留未知，不得拿日均值直接比月度门槛。

## 一、先列全选项

候选方案表至少包含：用户提出的选项＋**不行动**（维持现状，写清后果）＋**暂缓**（等什么信息、等到何时）＋**小范围试行**（范围、周期、判定标准）——只在与任务相关时列入，并说明取舍。避免"伪二选一"。

## 二、后果表（每个方案一行）

| 方案 | 预期收益（依据） | 主要代价 | 主要风险/不确定 | 关键前提 |
| --- | --- | --- | --- | --- |

填写纪律：

- **收益与代价写依据**：数字必须出自测算/分析 skill 输出或用户材料（注明出处）；没有数字依据就写定性判断及其来源；
- **不伪造精确性**：缺依据时用"区间/情景/高-中-低"表达，标注"估计"或"未知"；禁止凭空概率、效用值、权重打分；
- **前提列全**：方案成立依赖的条件（供给到位、口径不变、政策延续），这是"假设与未知"模块的输入。

## 三、比较方式按证据强度选择

| 证据情况 | 比较方式 |
| --- | --- |
| 关键数字可由既有 skill 算出 | 先算再比（如 coupon-forecast 的发券测算、roi-forecast 的投放测算） |
| 只有部分数字 | 已知部分定量、其余定性并列，标明边界 |
| 基本没有数字 | 结构化定性比较（后果表＋关键差异点），或明确"信息不足以比较"并列缺口 |

## 四、取舍与建议的写法

- 建议默认**条件式**："在 X 前提下倾向方案 A；若 X 不成立/Y 出现，倾向 B 或暂缓"；
- 明说牺牲了什么（选 A 放弃了 B 的什么）、适用条件是什么；
- 涉及价值取舍（利润 vs 增长、短期 vs 长期）而用户未表态时，**列出取舍问用户**，不代答；
- 允许结论是"当前信息不足以推荐"＋获取缺口信息的具体计划。

## 五、移交边界

需要专业量化（预测模型、概率建模、敏感性计算）时移交对应 skill 或建议另行任务；本文件的方法止于结构化比较与诚实表达。
